# ZZMI Mod Fixer rules

The embedded hash rules, Jane Doe mapping data, Dialyn mapping data, and ZZMI logo are derived from:

- Project: ZZZ-Mod-Fixer
- Source: https://github.com/Vonksdesu/ZZZ-Mod-Fixer
- Embedded release: `zzz-mod-fixer-v2.1.0`
- Embedded commit: `f34da9cbc5d998cdecc9c4ba1d6e2a0302cf5adf`
- Source-code license: MIT License

Nahida Desktop executes no Python from that project. The source data is parsed into a validated, compressed rule pack and interpreted by the native Go implementation.
