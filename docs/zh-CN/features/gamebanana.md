# GameBanana

Nahida Desktop 支持直接在应用内浏览和下载 GameBanana 模组，无需另外打开网页浏览器。

本页说明如何在 GameBanana 页面中浏览并下载模组。

## 开始使用

![图片](/features/gamebanana/login1.png)

登录是可选的。即使没有 GameBanana 账号，也可以浏览模组并下载不需要登录的模组。

![图片](/features/gamebanana/login2.png)

只有在需要时才会显示 GameBanana 登录窗口，例如点击 GameBanana 工具栏中的登录按钮或给模组点赞时。

你可以选择自己偏好的登录方式，例如 Username 或 Email。

![图片](/features/index/gamebanana-ko.png)

登录成功后，登录窗口会自动关闭，工具栏中会显示你的账号。

## 浏览

![图片](/features/gamebanana/browsing.gif)

在 GameBanana 页面中，你可以通过以下方式浏览模组：

- 在左上角选择要浏览的游戏。
- 在右侧选择需要的分类。
- 点击模组卡片进入详情页。

## 下载

![图片](/features/gamebanana/download.gif)

在模组详情页右侧的下载卡片中，可以查看该模组的文件列表。

点击要下载的文件，选择下载方式后，下载就会开始。

下载完成后，该模组的代表图片也会自动一并下载，并保存到解压后的模组文件夹中。
