# GameBanana

无需打开网页浏览器，直接在应用内浏览和下载 GameBanana 模组。

## 登录

登录是可选的。即使没有 GameBanana 账号，也可以浏览模组并下载不需要登录的模组。

只有在需要登录时才会显示登录窗口，例如在 GameBanana 页面中点击登录按钮或给模组点赞时。

::: info
登录窗口使用 Microsoft Edge WebView2 Runtime。安装程序会一并安装它；使用便携版可执行文件时，需要事先安装该运行时。
:::

## 浏览

选择游戏和分类，然后点击模组即可打开其详情页。模组管理器支持的所有游戏均可浏览，包括《异环》。

## 下载

模组详情页会列出该模组的文件。点击文件并选择下载位置后即开始下载。下载任务会显示在传输页面中。

下载完成后，压缩包会解压到所选的模组文件夹中，模组的缩略图也会作为预览保存到该文件夹。
