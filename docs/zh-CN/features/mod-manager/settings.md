# 模组设置

在 设置 → 模组 中设置模组管理器的行为。

## 模组管理

| 设置 | 默认值 | 说明 |
|---|---|---|
| `压缩包解压路径` | `移除顶层文件夹` | 只有一个顶层文件夹的压缩包的解压方式。 |
| `解压后删除压缩包` | 开启 | 将压缩包解压到模组文件夹后删除源压缩包。 |
| `移动文件夹而非复制` | 开启 | 将文件夹拖入模组文件夹时移动而不是复制。 |
| `自动检查模组是否需要修复` | 开启 | 检查下载或添加的模组是否需要修复，并发出通知。 |
| `启用时复制 ShaderFixes` | 开启 | 启用模组时，将模组中的 ShaderFixes 文件复制到导入器的 ShaderFixes 文件夹。 |
| `禁用模组前缀格式` | `DISABLED (空格)` | 禁用模组时添加到文件夹名称前的前缀。启用时会识别两种格式。 |
| `在子文件夹中搜索模组预览` | 关闭 | 侧边栏文件夹没有预览时，在其中的模组文件夹里查找预览。 |
| `切换状态预设的存储位置` | `未选择` | [切换状态预设](/zh-CN/features/mod-manager/presets#toggle-presets) 的存储位置。更改后会移动现有预设。 |
| `自动选择下载目标文件夹` | 关闭 | 自动选择名称与下载内容相似的模组文件夹。可选择适用的下载来源（`GameBanana`、`Nahida Live`、`Hui`、`网盘`），默认值为 `GameBanana`。 |

`压缩包解压路径` 的选项如下：

- `移除顶层文件夹`：移除顶层文件夹并解压其中的内容。示例：`mod.zip/a/b/mod.ini` → `b/mod.ini`
- `保留压缩包路径`：保留压缩包内的路径。示例：`mod.zip/a/b/mod.ini` → `a/b/mod.ini`
- `每次询问`：每次添加模组时在 `选择解压路径` 对话框中选择。

## 布局 {#layout}

| 设置 | 默认值 | 说明 |
|---|---|---|
| `侧边栏布局` | `行列表` | 将侧边栏显示为 `行列表` 或正方形 `预览网格`。 |
| `为没有预览的模组显示模型预览` | 开启 | 在网格视图中，为没有图片或视频的模组显示当前切换状态的模型图像。 |
| `模组网格布局` | `响应式` | 网格视图决定卡片宽度和列数的方式。 |

`模组网格布局` 的选项如下：

- `响应式`：根据 `响应式基准卡片宽度`（240–640，默认值 400）计算可用宽度内可容纳的列数。
- `固定卡片宽度`：固定卡片宽度（240–640，默认值 360），只改变列数。
- `固定列数`：在可能的情况下使用指定的列数（1–8，默认值 4）。

## 模组压缩

压缩模组文件以节省磁盘空间。使用 `启用模组压缩` 开关开启或关闭，并会显示进度。

- `压缩方式`：默认值为 `XPRESS4K`。
  - `Zstd`：只压缩已禁用模组中的大文件。启用模组时会先还原原文件。
  - `XPRESS4K`：用 Windows 文件压缩缩小所有模组文件。压缩后仍可直接使用模组。
- `压缩大小阈值`：`Zstd` 压缩的最小文件大小。范围为 1–64 MiB，默认值为 1 MiB。
