# 模组工具

模组工具针对单个模组或所选模组运行。大多数工具从模组菜单的 `工具` 分区或网格视图卡片上的 `模组工具` 按钮打开。在异环游戏中，`工具` 分区仅显示 `Nahida Agent`。

## 工具列表

| 工具 | 适用游戏 | 说明 |
|---|---|---|
| `Nahida Agent` | 全部 | 以所选模组为对象打开 Nahida Agent。 |
| [`模型查看器`](/zh-CN/features/mod-manager/model-viewer) | 异环以外 | 显示模组的 3D 模型和切换状态。在卡片上使用 `在模型查看器中打开` 按钮打开。 |
| `纹理缩放器` | 全部 | 调整模组 DDS 纹理的尺寸并保存到原文件。 |
| `XXMI 菜单制作器` | 全部 | 根据模组的切换项生成游戏内菜单。在工具界面中打开。 |
| `体型修改 (测试版)` | 全部 | 根据绘制的区域或骨骼权重调整模组的网格。 |
| `触摸配置 (测试版)` | 全部 | 设置触摸区域，将模组转换为可响应触摸的版本。 |
| `Vulkan 描边修正` | EFMI | 参见 [Vulkan 描边修正](#vulkan-outline-fix)。 |
| `液体喷射点 (测试版)` | EFMI、GIMI、SRMI、WWMI、ZZMI | 在模组的网格上设置液体喷射点，并将其接入 INI。 |
| `查找冲突模组` | 全部 | 参见 [查找冲突模组](#find-conflict)。 |
| [`切换状态预设`](/zh-CN/features/mod-manager/presets#toggle-presets) | 异环以外 | 仅在模组菜单中显示。 |

## 合并模组 (测试版) {#merge}

将多个模组合并为一个模组，可在游戏中用按键切换。适用于 GIMI、SRMI、ZZMI、HIMI、WWMI、EFMI 游戏。

1. 在模组列表顶部的 `更多选项` 菜单中选择 `合并模组 (测试版)`。
2. 点击两个或更多模组将其选中，然后点击 `下一步`。点击 `取消合并` 或按 `Esc` 可退出合并模式。
3. 在 `合并模组` 对话框中设置以下项目，然后点击 `合并`。
   - `名称`：合并后模组的名称。
   - `下一个按键` / `上一个按键`：在游戏中切换模组的按键。
   - `保存位置`：选择 `当前位置` 或 `新文件夹`。
   - `合并方式`：选择 `经典` 或 `命名空间`。如果所选模组中有无法使用经典合并的项目，则只能选择 `命名空间`。
   - `包含原装槽位`：将未应用模组的状态加入切换对象。仅在 `命名空间` 方式下可用。
   - 模组列表：使用上下按钮更改切换顺序。点击 `与下一个模组编组` 会将该模组与下一个模组编为一个子分组，点击 `取消编组` 会解除子分组。

## 查找冲突模组 {#find-conflict}

保持所选模组启用，每次禁用一半的其他模组，以找出与该模组冲突的模组。如果该模组已禁用，请先启用它。

## 修复 {#fix}

从模组菜单的 `修复` 分区或卡片的 `模组工具` 菜单运行修复工具。运行结果显示在日志对话框中，需要输入的工具可在日志对话框底部输入。

- `预设`、`修复工具`：对模组运行在工具界面的 Fix Tool Manager 中注册的预设和修复脚本。运行 Python 修复工具需要安装 Python。
- **Wuwa Mod Fixer**：在 WWMI 游戏和导入器为 `无` 的游戏中显示。首次运行时安装，有新版本时会提示更新。在 `修复模组` 选项卡中选择选项并运行，在 `回滚` 选项卡中恢复备份。
- **ZZMI Mod Fixer**：在 ZZMI 游戏中显示。包含 `Hash Fix`、`Jane Remap`、`Dialyn Remap` 和 `回滚` 选项卡。

也可以从侧边栏文件夹菜单的 `工具` 或模组列表顶部 `更多选项` 菜单的 `工具`，对整个文件夹运行 Wuwa Mod Fixer 和 ZZMI Mod Fixer。

在 [模组设置](/zh-CN/features/mod-manager/settings) 中启用 `自动检查模组是否需要修复` 后，下载或添加的模组需要修复时会显示通知。在通知中选择 `打开修复工具` 会打开相应的修复工具。

## Vulkan 描边修正 {#vulkan-outline-fix}

仅适用于明日方舟：终末地 (EFMI) 模组。在 Vulkan 下，模组的部分部件会在描边通道中再次绘制，显示为不透明。此工具按 INI 文件列出这些部件，选择要从描边通道中排除的部件后应用。

- `还原`：还原为原始文件。
- 应用后手动修改过文件时，会显示 `已手动修改`。要再次应用或还原，请选择 `将当前文件作为原始文件`。

应用后，请在游戏中按 `F10` 重新加载模组。

## 设置角色 {#set-character}

为侧边栏文件夹设置角色后，该文件夹及其子文件夹中的模组会在 [模型查看器](/zh-CN/features/mod-manager/model-viewer) 中使用该角色的卡通风格、动作和原始数据。详情参见 [角色数据](/zh-CN/features/mod-manager/character-data)。

1. 在侧边栏中右键点击文件夹，选择 `设置角色…`。
2. 选择 `游戏` 和 `角色`，然后点击 `保存`。

要取消设置，请在同一对话框中点击 `清除`。

## 其他模组菜单项目

- `重命名`：重命名模组文件夹。
- `打开 CMD`：在模组文件夹中打开命令提示符。
- `在 GameBanana 中查看`：打开从 GameBanana 下载的模组的 GameBanana 页面。
