# 预设

模组管理器有两种预设。

- **预设**：保存游戏中启用了哪些模组。
- **切换状态预设**：保存单个模组的切换值。

## 预设

预设选择器位于侧边栏底部的游戏选择器旁。

- **保存**：点击预设选择器旁的 `+` 按钮（`新建预设`），输入名称和 `说明（可选）`。当前启用的模组配置会被保存。
- **应用和删除**：在预设选择器中选择预设后，会在对话框中显示预设名称和说明。选择 `应用` 或 `删除`。

应用预设时，如果有找不到或无法更改状态的模组，会在通知中显示数量。

名称仅相差 `DISABLED` 前缀的文件夹会被视为同一个模组。存在这类文件夹时保存预设，会显示 `发现重复模组项` 对话框。选择 `重命名已禁用的重复文件夹并继续` 会先重命名已禁用的文件夹，再保存预设。

旧版本创建的预设会标记为 `旧版`，无法应用。请删除后重新创建。

## 切换状态预设 {#toggle-presets}

切换状态预设会为单个模组的切换值命名并保存，之后可以再次应用。

### 打开方式

- 右键点击模组并选择 `切换状态预设`。
- 在网格视图的卡片上，点击 INI 列表顶部的切换状态预设按钮。会显示已保存的预设和 `管理预设…`。
- 在 [模型查看器](/zh-CN/features/mod-manager/model-viewer) 的 `切换` 菜单中选择 `保存为预设` 或 `应用预设`。

仅适用于有 INI 文件的模组，异环模组无法使用。

### 存储位置

首次使用切换状态预设时，需要选择 `切换状态预设的存储位置`。

- `模组文件夹 (nhd.json)`：保存在模组文件夹的 `nhd.json` 中。重命名或移动文件夹后预设仍会保留，共享文件夹时也会一并共享预设。
- `应用数据库`：保存在应用数据库中。不会更改模组文件夹，但重命名或移动模组文件夹后将找不到预设。

可以在切换状态预设对话框的 `存储位置` 或 [模组设置](/zh-CN/features/mod-manager/settings) 的 `切换状态预设的存储位置` 中更改存储位置。更改后，现有预设会移到新位置。

### 保存和应用

在切换状态预设对话框中输入预设名称，然后选择 `保存当前值`。已保存的预设可以在列表中应用、重命名或删除。

- **读取值的位置**：游戏正在运行且已连接到应用时，从正在运行的游戏读取值。否则，从模组的 INI 文件和 `d3dx_user.ini` 读取值。
- **应用**：将预设的值写入模组的 INI 文件。游戏正在运行且已连接到应用时，也会立即应用到正在运行的游戏。

::: warning
要保存或应用切换状态预设，需要在 [XXMI](/zh-CN/others/set-up-xxmi) 中设置为使用内置启动器和 myparsleycat XXMI 库启动游戏。否则会显示 `需要内置启动器和 myparsleycat 库`，保存和应用将被禁用。
:::
