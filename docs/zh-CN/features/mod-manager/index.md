# 模组管理器

模组管理器为每个已注册的游戏启用和禁用模组、将模组整理为分组，并管理预览和预设。

页面分为左侧边栏和右侧模组列表。游戏选择器和预设选择器位于侧边栏底部。

## 添加游戏

点击游戏选择器旁的 `+` 按钮即可打开添加游戏对话框。

- **游戏名称**：显示在游戏选择器中的名称。
- **Importer**：选择游戏加载模组的方式。
  - XXMI Importer（`GIMI`、`SRMI`、`WWMI`、`ZZMI`、`HIMI`、`EFMI`）：使用该 Importer 的 Mods 文件夹作为模组文件夹。[连接 XXMI](/zh-CN/others/set-up-xxmi) 后才会列出 Importer。
  - `NTE`：选择《异环》的安装文件夹。也可以选择自定义模组文件夹，游戏的 Mods 文件夹会链接到该文件夹。Nahida Desktop 会安装游戏加载模组所需的文件。
  - `无`：选择任意文件夹作为模组文件夹。无法从 Nahida Desktop 启动该游戏。

之后如需修改游戏，请打开游戏选择器并点击游戏旁的铅笔按钮。在游戏设置对话框中还可以更改游戏的显示顺序或删除游戏。

## 文件夹结构

推荐的模组文件夹结构如下：

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
侧边栏显示模组文件夹下的第一层文件夹。建议不要将模组直接放在模组文件夹中，而是放入 `Character`、`Enemy`、`NPC` 等分类文件夹。

- 推荐：`Mods\Character\SomeCharacterMod`
- 不推荐：`Mods\SomeCharacterMod`
:::

### 子分组

侧边栏中的文件夹可以在其下方展开显示子文件夹。在侧边栏中右键点击文件夹并选择 `探索子文件夹` 即可显示子文件夹，选择 `指定为子文件夹` 则会一直显示。点击已显示或已指定子文件夹的文件夹会将其折叠或展开，点击其他文件夹则会选中该文件夹。

按住 `Ctrl` 点击文件夹会将其展开并选中。按住 `Alt` 点击文件夹会折叠或展开其父文件夹。

模组列表中的文件夹也可以视为子分组：右键点击该文件夹并选择 `指定为子分组`。如需撤销，请在侧边栏文件夹菜单中选择 `取消手动子分组指定`。

### 分类依据

侧边栏 `更多选项` 菜单中的 `分类依据` 可以按你定义的分类而不是按文件夹对游戏的文件夹进行分组。选择 `管理分类…` 创建分类，然后在侧边栏中右键点击文件夹，通过 `分类` 进行指定。

## 添加模组

在侧边栏中选中某个文件夹后，可以通过以下方式添加模组：

- 从 [GameBanana](/zh-CN/features/gamebanana) 下载模组。
- 将模组文件夹或压缩包拖放到模组列表中。
- 点击模组列表上方的 `...` 按钮，选择 `下载`，然后输入要下载文件的 URL。

## 搜索

按 `Ctrl+F` 可搜索当前游戏的模组。韩文名称也可以按初声（首辅音）匹配。

## 预览

模组管理器会将模组文件夹中名为 `preview` 的图片或视频文件（不区分大小写）用作该模组的预览。如果没有这样的文件，则使用文件夹中第一个受支持的媒体文件。

::: info
如果在 设置 → 模组 中启用了 `在子文件夹中搜索模组预览`，也会搜索子文件夹。
:::

如果在 设置 → 模组 中启用了 `为没有预览的模组显示模型预览`，没有预览的模组会在网格中显示其当前切换状态的模型图像。

### 设置或替换预览

- 对于侧边栏中的文件夹，将图片或视频文件拖放到该文件夹上。
- 对于模组，先复制图片或视频文件，然后右键点击模组并选择 `预览` 下的 `粘贴`。没有预览的模组还会在预览区域显示 `粘贴` 按钮。
- 在[模型查看器](/zh-CN/features/mod-manager/model-viewer)中选择 `其他` → `捕获并设为预览`。

同一菜单中的 `删除预览` 可删除当前预览。

## 预设

预设用于保存和恢复模组的启用状态。点击预设选择器旁的 `+` 按钮可保存当前状态；选择某个预设即可应用或删除它。

## 切换状态预设 {#toggle-presets}

切换状态预设会保存单个模组的切换项数值。右键点击模组并选择 `切换状态预设`，即可保存当前数值或应用已保存的预设。预设可以保存在模组文件夹（`nhd.json`）中，也可以保存在应用数据库中。

从运行中的游戏读取数值需要内置启动器和 myparsleycat XXMI 库。否则会从模组的 INI 文件和 `d3dx_user.ini` 中读取数值。

## 启动游戏

在游戏选择器中选择游戏，然后点击播放按钮即可加载模组并启动游戏。XXMI 游戏会使用在 [XXMI](/zh-CN/others/set-up-xxmi) 页面中选择的启动器。对于《异环》，首次启动时需要设置游戏的启动器路径。
