# 模组管理器

模组管理器按已注册的游戏启用、禁用模组，并按文件夹整理模组。[预览](/zh-CN/features/mod-manager/previews)、[预设](/zh-CN/features/mod-manager/presets)、[模组工具](/zh-CN/features/mod-manager/mod-tools) 和 [模型查看器](/zh-CN/features/mod-manager/model-viewer) 也从此界面打开。

## 界面布局

界面分为左侧的侧边栏和右侧的模组列表。

- **侧边栏**：显示模组文件夹下的直接子文件夹，每个文件夹都会显示已启用模组数和模组总数。顶部是文件夹搜索框和 `更多选项` 菜单，底部是游戏和预设选择器。
- **模组列表**：显示侧边栏中所选文件夹的模组。正在下载的模组和已启用的模组排在前面。

拖动侧边栏与模组列表之间的边界可调整侧边栏宽度。边界获得焦点时，也可以使用 `←`/`→`、`Shift+←`/`Shift+→` 和 `Home`/`End` 调整。

### 模组列表顶部

| 项目 | 说明 |
|---|---|
| 搜索框 | 搜索所选文件夹中的模组。参见 [搜索](#search)。 |
| 排序 | 选择 `名称`、`日期` 或 `大小` 作为排序依据。旁边的 `排序顺序` 按钮可在升序和降序之间切换。 |
| `列表视图` / `网格视图` | 切换模组列表的显示方式。 |
| `打开文件夹` | 在文件资源管理器中打开所选文件夹。 |
| `更多选项` | 显示 `全部启用`、`全部禁用`、`合并模组 (测试版)`、`下载` 和 `工具`。`合并模组 (测试版)` 仅在 GIMI、SRMI、ZZMI、HIMI、WWMI、EFMI 游戏中显示，`工具` 仅在支持 Wuwa Mod Fixer 或 ZZMI Mod Fixer 的游戏中显示。 |

### 列表视图和网格视图

- **列表视图**：显示 `名称`、`大小` 和 `日期` 列。点击列标题会按该列排序，再次点击会反转顺序。
- **网格视图**：以卡片显示模组。卡片宽度和列数在 [模组设置](/zh-CN/features/mod-manager/settings#layout) 的 `模组网格布局` 中设置。

卡片颜色表示模组状态：绿色为已启用，红色为已禁用，黄色为已启用但导入器中缺少必需的依赖。

卡片标题栏有 `Nahida Agent`、`模组工具`、`在模型查看器中打开`、`删除` 和 `打开文件夹` 按钮。已应用体型修改、触摸配置或液体喷射点的模组会显示相应图标。

卡片右侧列出模组的 INI 文件和切换段落。切换段落的按键可按 [更改按键](#keys) 中的方法更改。`打开 INI 文件` 可打开 INI 文件，`收起 INI 列表` 可收起列表。

## 游戏 {#games}

### 添加游戏

点击游戏选择器旁的 `+` 按钮（`添加游戏`）打开添加游戏对话框。

- **游戏名称**：在游戏选择器中显示的名称。
- **导入器**：选择游戏加载模组的方式。默认值为 `无`。
  - `无`：选择任意文件夹作为 `模组文件夹路径`。无法从 Nahida Desktop 启动游戏。
  - XXMI 导入器（`GIMI`、`SRMI`、`WWMI`、`ZZMI`、`HIMI`、`EFMI`）：使用该导入器的 Mods 文件夹作为模组文件夹。未安装的导入器会标记为 `未安装`，且无法选择。[连接 XXMI](/zh-CN/others/set-up-xxmi) 之前会显示 `打开导入器设置` 按钮。
  - `NTE`：选择 `NTE 安装文件夹`。游戏名称固定为 `异环`。选择 `自定义模组文件夹` 后，游戏的 Mods 文件夹会链接到该文件夹。Nahida Desktop 会安装游戏加载模组所需的文件。

### 游戏设置

打开游戏选择器，点击游戏旁的铅笔按钮（`游戏设置`）。在对话框中可以更改导入器和模组文件夹路径，并通过 `显示顺序` 更改游戏在选择器中的位置。游戏名称无法更改。

选择 `删除游戏` 会将游戏从列表中删除。该游戏的预设也会一并删除，此操作无法撤销。

### 启动游戏

在游戏选择器中选择游戏，然后点击 `启动游戏` 按钮，即可在应用模组的状态下启动游戏。

- XXMI 游戏使用 [XXMI](/zh-CN/others/set-up-xxmi) 页面中选择的启动器。启动前如果发现会妨碍模组生效的游戏设置或未压缩的纹理，会显示确认对话框。
- 异环首次启动时，需要在 `指定启动器路径` 对话框中设置游戏启动器的路径。
- 导入器为 `无` 的游戏无法启动。

## 文件夹结构

推荐的模组文件夹结构如下。

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
侧边栏显示模组文件夹下的直接子文件夹。建议不要将模组直接放在模组文件夹中，而是放在 `Character`、`Enemy`、`NPC` 等分类文件夹内。

- 推荐：`Mods\Character\SomeCharacterMod`
- 不推荐：`Mods\SomeCharacterMod`
:::

## 侧边栏

### 文件夹菜单

在侧边栏中右键点击文件夹会显示以下项目。

| 项目 | 说明 |
|---|---|
| `全部启用` / `全部禁用` | 启用或禁用文件夹中的所有模组。 |
| `启用文件夹` / `禁用文件夹` | 启用或禁用文件夹本身。 |
| `在文件资源管理器中打开` | 在文件资源管理器中打开文件夹。 |
| `新建文件夹` | 在文件夹内新建文件夹。 |
| `删除` | 将文件夹移到回收站。 |
| `展开子文件夹` / `始终展开子文件夹` | 参见 [子分组](#subgroups)。 |
| `设置角色…` | 设置文件夹中模组使用的角色。参见 [设置角色](/zh-CN/features/mod-manager/mod-tools#set-character)。 |
| `分类` | 将文件夹分配到分类依据的分组。参见 [分类依据](#group-by)。 |
| `工具` | 对整个文件夹运行 Wuwa Mod Fixer 或 ZZMI Mod Fixer。仅在支持的游戏中显示。 |

### 更多选项菜单

侧边栏顶部的 `更多选项` 菜单包含以下项目。

- `新建文件夹`：在模组文件夹下新建文件夹。
- `文件夹排序`：选择 `名称`、`模组数量` 或 `已启用模组数量` 作为排序依据，并选择 `升序` 或 `降序`。
- `分类依据`：参见 [分类依据](#group-by)。
- `隐藏空文件夹`：隐藏没有模组的文件夹。
- `切换到预览网格` / `切换到行列表`：将侧边栏显示为正方形预览网格或行列表。

`文件夹排序` 和 `隐藏空文件夹` 会在应用重启后重置。

### 子分组 {#subgroups}

侧边栏中的文件夹可以在其下方展开显示子文件夹。右键点击文件夹并选择 `展开子文件夹` 可显示子文件夹；选择 `始终展开子文件夹` 后，应用重启后也会保持展开。

点击已展开子文件夹的文件夹会折叠或展开它，点击其他文件夹则会选中该文件夹。按住 `Ctrl` 点击文件夹会展开并选中它。按住 `Alt` 点击文件夹会折叠或展开其父文件夹。

模组列表中的文件夹也可以作为子分组。右键点击该文件夹并选择 `指定为子分组` 后，即使父文件夹已折叠，它也会显示在侧边栏中。要取消，请在侧边栏的文件夹菜单中选择 `取消指定为子分组`。

### 分类依据 {#group-by}

使用 `更多选项` 菜单中的 `分类依据`，可以按自定义的分类对侧边栏中的文件夹进行分组。

1. 选择 `分类依据` → `管理分类…`，然后点击 `新建分类依据` 创建分类依据及其分组。
2. 在侧边栏中右键点击文件夹，通过 `分类` 将其分配到分组。
3. 在 `分类依据` 中选择创建的分类依据后，侧边栏会按分组显示。未分配分组的文件夹显示在 `未分类` 中。

选择 `分类依据` → `文件夹` 可恢复按文件夹显示。

## 添加模组

在侧边栏中选中文件夹后，可以通过以下方式添加模组：

- 从 [GameBanana](/zh-CN/features/gamebanana) 下载模组。在 `选择路径` 对话框中选择 `模组管理器` 后，可在 `确认下载` 界面中设置文件名和下载位置。
- 将模组文件夹或压缩包（`.zip`、`.rar`、`.7z`）拖放到模组列表中。压缩包会自动解压。
- 在模组列表顶部的 `更多选项` 菜单中选择 `下载`，然后在 `通过 URL 下载` 对话框中输入文件的直接下载链接。仅支持 http 和 https URL，不能使用网页 URL。

只有一个顶层文件夹的压缩包如何解压，在 [模组设置](/zh-CN/features/mod-manager/settings) 的 `压缩包解压路径` 中设置。选择 `每次询问` 后，每次添加时都会显示 `选择解压路径` 对话框。

## 启用和禁用模组

- 点击模组可启用或禁用它。
- 按住 `Ctrl` 点击模组，或在模组获得焦点时按 `Ctrl+Enter`，会禁用同一文件夹中的其他所有模组，只启用该模组。如果该模组已启用，则会禁用它。
- 模组搜索结果只有一个时按 `Enter`，会对该模组执行相同操作并清除搜索内容。

启用导入器中缺少必需依赖的模组时，会显示 `缺少必需的依赖` 对话框。选择 `忽略并启用` 会直接启用。

## 搜索 {#search}

侧边栏顶部是文件夹搜索框，模组列表顶部是模组搜索框。按 `Ctrl+F` 会移到文件夹搜索框，在已选择文件夹时再按一次会移到模组搜索框。

- **文件夹搜索**：显示名称包含搜索内容的文件夹。只有一个文件夹匹配时会自动选中它。
- **模组搜索**：搜索所选文件夹中的模组。韩文名称也可以通过初声（辅音）和正在输入的字匹配。

## 更改按键 {#keys}

卡片的 INI 列表会为每个切换段落显示切换到下一个值的按键和切换到上一个值的按键。未设置的按键显示为 `添加按键` 或 `添加上一个按键`。

点击按键会打开按键设置对话框。按下要设置的按键组合，或在 `手动编辑` 中以 `ctrl alt no_shift vk_up` 的格式输入。

异环模组会显示输入按键列表，而不是 INI 列表。只能设置一个不带修饰键的按键，且不能设置该模组已在使用的按键。

## 模组菜单

右键点击模组会显示以下项目。部分项目会因游戏或模组而不显示。

| 分区 | 项目 |
|---|---|
| （顶部） | `在 GameBanana 中查看` |
| `预览` | `用预览查看器打开`、`粘贴`、`删除预览`（[预览](/zh-CN/features/mod-manager/previews)） |
| `修复` | `预设`、`修复工具`、Wuwa Mod Fixer、ZZMI Mod Fixer（[模组工具](/zh-CN/features/mod-manager/mod-tools#fix)） |
| `模组` | `打开 CMD`、`打开文件夹`、`指定为子分组`、`重命名` |
| `工具` | `Nahida Agent`、`模型查看器`、`切换状态预设` 以及其他 [模组工具](/zh-CN/features/mod-manager/mod-tools) |
| （底部） | `删除`：将模组移到回收站。 |
