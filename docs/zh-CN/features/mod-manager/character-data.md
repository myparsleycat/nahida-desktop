# 角色数据

模型查看器使用为模组设置的角色的游戏数据，提供以下功能。

- **角色动作**：在模组上播放角色的游戏动作。
- **游戏原始数据**：用游戏原始数据补充模组未包含的面部、头发和贴图。
- **表情**：为原始面部应用表情和眨眼。
- **按角色的卡通风格**：使用角色的材质值显示卡通着色。

支持的游戏为原神 (GIMI)、崩坏：星穹铁道 (SRMI)、绝区零 (ZZMI)、鸣潮 (WWMI) 和明日方舟：终末地 (EFMI)。仅适用于提供了数据的角色。

## 设置角色

在模型查看器中选择 `模型` → `设置角色…`，选择游戏和角色，然后点击 `保存`。设置保存在当前模组文件夹的 `nhd.json` 中，重新打开模组时也会生效。选择 `清除模组角色设置` 后，将重新使用文件夹设置的角色。

要为文件夹中的模组设置默认角色，请按以下步骤操作。

1. 在模组管理器的侧边栏中右键点击文件夹，选择 `设置角色…`。
2. 选择 `游戏` 和 `角色`，然后点击 `保存`。

如果没有为模组单独设置角色，则使用最近的上级文件夹中设置的角色。在 [Blender 实时预览](/zh-CN/features/mod-manager/blender-live-preview) 中，在连接列表里选择角色。

## 下载

角色数据会在首次使用时从 nahida.live 服务器下载，之后使用已保存的文件。下载期间，[播放控制器](/zh-CN/features/mod-manager/model-viewer#playback) 上会显示进度。

## 角色动作 {#character-motion}

开启 `模型` 菜单中的 `角色动作` 后，会在模组上播放角色的游戏动作。当所设置的角色有动作数据且模组网格有骨骼权重时显示，默认开启。

- 动作显示在播放控制器的单独一行中，从待机动作片段开始播放。在片段菜单中选择其他片段时，会从当前姿势平滑过渡。
- 模组本身有动画时，会与模组动画一起播放。
- 点击动作行上的 `关闭角色动作` 按钮，只会在当前查看器中关闭动作。

## 游戏原始数据 {#original-data}

开启 `模型` 菜单中的 `游戏原始数据` 后，会将游戏原始数据与模组一起显示。当所设置的角色有原始数据时显示，默认开启。

- 用原始模型显示模组交由游戏绘制的面部和头部部位。模组中有面部贴图时，会将其应用到原始面部。
- 用原始贴图填充模组网格中空缺的贴图槽。
- 在 `缺失部位` 子菜单中逐个显示或隐藏模组中没有的原始部位。游戏会持续绘制的头发部位从一开始就会显示。

## 表情 {#expression}

游戏原始数据已开启且显示的部位有表情数据时，`模型` 菜单中会显示 `表情` 子菜单。

- 从 `默认`、`微笑`、`生气`、`困扰`、`惊讶`、`单眼眨眼`、`闭眼` 中选择表情。只会列出可应用于当前显示部位的表情。
- `眨眼`：开启或关闭自动眨眼。

角色动作片段包含表情时，会播放片段中的表情。在 `表情` 中选择 `默认` 以外的表情时，所选表情优先。

## 按角色的卡通风格 {#toon-style}

已设置角色的模组会在 [卡通风格](/zh-CN/features/mod-manager/model-viewer#toon-style) 子菜单顶部显示 `{角色名}的风格`，并使用角色的材质值显示卡通着色。

- 在 `着色` 子菜单中，取自角色材质的值会标记为 `角色材质`。
- 在原神中，`阴影色阶` 的 `自动（{角色名}）` 会使用该角色的色阶。
- 在卡通风格中更改的值按角色保存。`灯光跟随相机` 和原神纹理文件夹按游戏保存。
- 点击 `重置角色风格` 会重置为该角色保存的值。
