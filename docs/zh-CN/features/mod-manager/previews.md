# 预览

模组管理器会为模组和侧边栏文件夹显示图片或视频预览。

支持的文件格式为 `png`、`jpg`、`jpeg`、`gif`、`webp`、`bmp`、`avif`、`avifs`、`mp4`、`webm`、`avi`、`mkv`、`mov`。视频会静音循环播放。

## 模组预览

模组管理器按以下顺序查找用作模组预览的文件：

1. 模组文件夹中直接存放的文件
2. 子文件夹中的文件
3. 已禁用（`DISABLED`）子文件夹中的文件

同一位置有多个文件时，依次选择文件名以 `preview` 开头的文件、文件名包含 `preview` 的文件、其他文件。不区分大小写。文件名包含 `normal`、`light`、`material` 或 `diffuse` 的文件会被视为纹理并排除。

模组有多张图片时，网格视图的预览上会显示 `上一张预览图片` 和 `下一张预览图片` 按钮。所选图片保存在模组文件夹的 `nhd.json` 中，下次也会显示。

## 文件夹预览

侧边栏文件夹的预览使用该文件夹中直接存放的图片或视频文件。将侧边栏显示为 `预览网格` 时，文件夹预览会以较大尺寸显示。

::: info
在 [模组设置](/zh-CN/features/mod-manager/settings) 中启用 `在子文件夹中搜索模组预览` 后，文件夹没有预览时也会在其中的模组文件夹里查找预览。
:::

## 查看预览

- `放大查看`：在应用窗口上方放大显示预览。在网格视图中右键点击预览即可选择；在列表视图中点击缩略图。
- `用预览查看器打开`：使用 Windows 中关联的程序打开预览文件。可在模组菜单的 `预览` 分区或网格视图的预览菜单中选择。

## 设置或替换预览

- **模组**：将图片文件、图片 URL 或图片复制到剪贴板，然后右键点击模组，在 `预览` 分区中选择 `粘贴`。在网格视图中，没有预览的模组的预览区域也会显示 `粘贴` 按钮。无法粘贴视频文件。
- **侧边栏文件夹**：将一个图片或视频文件拖放到侧边栏的文件夹上。
- **模型查看器**：在 [模型查看器](/zh-CN/features/mod-manager/model-viewer) 中选择 `其他` → `捕获并设为预览`。

如果已有预览，替换前会显示确认消息。

在模组菜单的 `预览` 分区中选择 `删除预览`，会将当前预览文件移到回收站。

## 模型预览 {#model-preview}

在 [模组设置](/zh-CN/features/mod-manager/settings#layout) 中启用 `为没有预览的模组显示模型预览` 后，网格视图中没有图片或视频的模组会显示当前切换状态的模型图像。异环模组不会显示。

右键点击模型预览可选择 `在模型查看器中打开` 和 `粘贴`。
