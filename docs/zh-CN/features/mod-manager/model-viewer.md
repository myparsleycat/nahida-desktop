# 模型查看器

模型查看器在不启动游戏的情况下显示模组的模型、贴图和切换状态。

::: warning
部分模组可能无法在查看器中打开，或者模型、贴图显示异常。
:::

## 支持的游戏

- 原神 (GIMI)
- 崩坏：星穹铁道 (SRMI)
- 绝区零 (ZZMI)
- 鸣潮 (WWMI、RabbitFX)
- 明日方舟：终末地 (EFMI)

不支持异环模组。

## 打开模型查看器

- 右键点击模组，在 `工具` 分区中选择 `模型查看器`。
- 在网格视图的模组卡片上点击 `在模型查看器中打开` 按钮（立方体图标）。
- 在网格视图中右键点击 [模型预览](/zh-CN/features/mod-manager/previews#model-preview)，选择 `在模型查看器中打开`。
- 在 Windows 文件资源管理器中右键点击模组文件夹，选择 `使用模型查看器打开`。此项仅在安装版中显示，模型查看器会在单独的窗口中打开。
- 在 [Blender 实时预览](/zh-CN/features/mod-manager/blender-live-preview) 中选择 `在模型查看器中打开`。

## 操作

- **旋转**：按住鼠标左键拖动。
- **平移**：按住鼠标右键或中键拖动，或按住 `Shift` 用左键拖动。
- **缩放**：使用鼠标滚轮。
- **按轴查看**：点击视口右上角坐标轴指示器的轴端，会从该轴方向查看模型。
- **形态**：有多个形态的模组会在视口左上角显示 `形态` 列表。选择形态会只显示该形态，选择 `全部` 会显示所有形态。

## 菜单栏

### 模型

- `旋转`：使用 `向左旋转 90°`、`向右旋转 90°`、`向上旋转 90°`、`向下旋转 90°`、`翻转 180°` 旋转模型。
- `重置`：将模型的旋转和相机恢复到初始状态。
- `设置角色…`：为当前模组设置角色。选择 `清除模组角色设置` 后，将重新使用文件夹设置的角色。
- `角色动作`、`游戏原始数据`、`缺失部位`、`表情`：显示所选角色和模型支持的项目。参见 [角色数据](/zh-CN/features/mod-manager/character-data)。

### 纹理

- `双面渲染`：同时渲染每个多边形的正反两面。

### 渲染

- `色调映射`：从 `中性`、`ACES Filmic`、`无` 中选择。
- `环境光`：从 `工作室`、`柔和`、`无` 中选择。
- `曝光`：使用 `-0.1`、`+0.1` 按钮或输入框在 0–4 范围内更改曝光。点击 `重置` 恢复默认值。
- `卡通阴影`：开启或关闭卡通着色。
- 卡通风格子菜单：根据游戏显示为 `原神卡通风格`、`星穹铁道卡通风格`、`绝区零卡通风格`、`鸣潮卡通风格` 或 `卡通风格`（终末地）。参见 [卡通风格](#toon-style)。
- `法线贴图`：在有法线贴图的模组中开启或关闭法线贴图。

### 切换

在有切换项的模组中显示。

- `保存到 INI`：将当前切换值写入模组的 INI 文件。如果加载了该模组的游戏正在运行且已连接到应用，也会应用到游戏。
- `重置`：恢复为 INI 文件中的默认值。
- `保存为预设` / `应用预设`：将当前值保存为 [切换状态预设](/zh-CN/features/mod-manager/presets#toggle-presets)，或应用已保存的预设。应用预设会写入 INI 文件，并应用到已连接的游戏。
- `在游戏中预览悬停的值`：在正在运行的游戏中显示切换查看器里鼠标悬停的值。
- `在查看器中显示覆盖层`：在查看器中显示模组的游戏内切换覆盖层。关闭后，覆盖层会显示在切换查看器顶部。
- `重置覆盖层位置和大小`：将查看器中覆盖层的位置和大小恢复到初始状态。

拖动查看器中的覆盖层可移动其位置，使用 `Ctrl` + 鼠标滚轮或右下角可调整大小。

### 其他

- `捕获并设为预览`：将视口中央以透明背景的正方形 `preview.png` 保存到模组文件夹。如果模组已有预览，替换前会显示确认消息。
- `保存为 PNG`：将当前画面以视口尺寸的 1 倍、2 倍或 4 倍分辨率保存为透明背景的 PNG 文件。子菜单的各项会显示保存后的尺寸，保存位置在保存对话框中指定。

## 卡通风格 {#toon-style}

在 `渲染` 菜单的卡通风格子菜单中更改以下项目。

- `描边`、`自阴影`、`灯光跟随相机`
- `面部平面着色`：仅在终末地中显示。
- `着色`：调整 `阴影阈值`、`阴影亮度`、`描边颜色` 等各游戏的着色值。点击 `重置着色` 恢复默认值。
- 原神还会显示以下项目：
  - `原神纹理文件夹...`：指定包含原神卡通纹理的文件夹。使用 `清除纹理文件夹` 取消指定。
  - `阴影色阶`：从 `自动`、`内置` 或纹理文件夹中的色阶中选择。
  - `面部阴影图`：显示面部时，从 `自动`、`少年`、`少女`、`成女`、`萝莉`、`成男` 中选择。

已设置角色的模组会使用该角色的卡通风格，更改的值也按角色保存。其他模组按游戏保存。参见 [角色数据](/zh-CN/features/mod-manager/character-data#toon-style)。

## 切换查看器

对于有切换项的模组，右侧的切换查看器会列出每个切换项。更改值后模型会按该状态重新绘制，鼠标悬停在值上会预览应用该值后的模型。

- 在当前组合下无效的值会被禁用。鼠标悬停时会显示需要一并更改的变量，点击 `应用此组合` 会一并更改所需的变量。
- 仅更改查看器不渲染的纹理或效果的值会显示在 `不在查看器中显示` 中，这些值仍会保存到预设中。
- 拖动分隔条可调整面板大小，点击可显示或隐藏面板。分隔条获得焦点时，按 `Enter` 或 `Space` 显示或隐藏面板，按 `←`/`→` 调整大小。

## 播放控制器 {#playback}

模组包含动画或正在播放 [角色动作](/zh-CN/features/mod-manager/character-data#character-motion) 时，视口底部会显示播放控制器。角色数据的下载状态和 [贴图选择](#texture-choice) 项目也会显示在此控制器上。

- 模组动画和角色动作分别显示在各自的行中。每行可以 `播放`/`暂停`、选择片段、`跳到开头`、`跳到结尾` 和设置播放速度（0.25×–2×）。
- 拖动帧滑块可跳到指定帧。滑块获得焦点时，按 `←`/`→` 逐帧移动，按 `Home`/`End` 跳到开头和结尾。
- 在播放速度菜单中开启 `帧插值`，会在帧之间插值以平滑播放。
- 拖动控制器左侧的手柄（`移动控制器`）可移动控制器。双击手柄，或在手柄获得焦点时按 `Home`，可恢复到原来的位置。

## 贴图选择 {#texture-choice}

INI 按哈希替换贴图的模组无法确定部分部位使用的贴图，这些部位会以游戏原始贴图显示。存在这类部位时，播放控制器上会显示 `N 个部位使用游戏原始贴图`。

点击后会显示以下项目。

- `高亮显示`：高亮显示使用游戏原始贴图的部位。
- `贴图选择`：为每个部位选择 `游戏原始贴图` 或同一模型其他部位的贴图。所选内容保存在模组文件夹的 `nhd.json` 中，也会用于网格视图的模型预览。

## 游戏联动

当模组的导入器使用内置启动器和 myparsleycat XXMI 库时，可以使用 `保存为预设`、`应用预设` 和 `在游戏中预览悬停的值`。加载了该模组的游戏正在运行时，可以通过切换查看器顶部的 `应用到游戏` 将当前值应用到游戏。
