# 模型查看器

![图片](/features/mod-manager/model-viewer/0.png)

使用模型查看器，你可以在不启动游戏的情况下预览模组的模型、贴图和切换状态。

::: warning
此功能仍在开发中。部分模组可能无法在查看器中打开，或者模型、贴图显示异常。
:::

## 支持的游戏

目前支持以下游戏的模组：

- `原神`
- `崩坏：星穹铁道`
- `绝区零`
- `鸣潮`

::: info
与其他游戏相比，`鸣潮` 目前有更多模组可能无法正常显示。
:::

## 设置资源路径

如果要在模型查看器中打开 `原神`、`崩坏：星穹铁道`、`绝区零` 等 HoYoverse 系列游戏的模组，需要先设置资源路径。

关于资源准备和路径设置的方法，请参考 [静态 GLB 转换器](/zh-CN/features/mod-tools/static-glb-converter) 中的 [资源](/zh-CN/features/mod-tools/static-glb-converter#资源) 一节。

## 打开模型查看器

![图片](/features/mod-manager/model-viewer/1.png)
在卡片布局中，点击模组卡片标题栏里的模型查看器按钮即可打开查看器。

![图片](/features/mod-manager/model-viewer/2.png)
在列表布局中，右键点击模组后选择 `模型查看器` 菜单即可。

## 顶部菜单栏

- **模型**：提供旋转模型、重置模型、重置相机等基本操作。
- **贴图**：修改与贴图相关的显示选项。
  - `Double Sided`：同时渲染多边形的正面和背面。
- **渲染**：切换渲染方式，以不同方式查看模型状态。
- **切换**：保存或重置当前切换状态。
  - `保存到 INI`：将切换查看器中当前选择的状态写入 INI。
  - `重置`：将切换状态恢复为 INI 中的默认值。
- **其他**：提供当前模组的额外操作。
  - `捕获并设为预览`：将当前可见的查看器画面按居中 1:1 正方形 PNG 进行捕获，并保存为当前模组文件夹中的 `preview.png`。

## 从查看器捕获预览

如果你想把当前查看器画面用作模组预览，请打开 `其他` → `捕获并设为预览`。

捕获内容只包含当前激活的 3D 查看器区域。菜单栏和右侧切换面板不会出现在图片中。

如果模组中已经存在 `preview.*` 文件，在用新的 `preview.png` 替换之前会先弹出确认提示。

## 右侧切换查看器

对于包含切换项的模组，你可以在右侧切换查看器中直接修改状态。更改数值后，模型会按对应状态重新渲染。

![图片](/features/mod-manager/model-viewer/3.png)
如果模组使用游戏内切换查看器，相关的 UI 资源也可能一并显示。

![图片](/features/mod-manager/model-viewer/4.gif)
如果模组使用滑块，切换查看器中也会显示可交互的滑块控件。
