# 模型查看器

模型查看器在不启动游戏的情况下显示模组的模型、贴图和切换状态。

::: warning
部分模组可能无法在查看器中打开，或者模型、贴图显示异常。
:::

## 支持的游戏

- `原神` (GIMI)
- `崩坏：星穹铁道` (SRMI)
- `绝区零` (ZZMI)
- `鸣潮` (WWMI)
- `明日方舟：终末地` (EFMI)

## 打开模型查看器

在模组管理器中右键点击模组，然后选择 `模型查看器`；也可以在网格布局的模组卡片上点击 `在模型查看器中打开` 按钮（立方体图标）。

## 菜单栏

- **模型**：旋转模型，以及重置模型或相机。
- **纹理**：`双面渲染` 会同时渲染每个多边形的正反两面。
- **渲染**：更改色调映射、环境光和曝光，以及开启或关闭法线贴图。对于支持的游戏，可以通过 `卡通阴影` 和该游戏的卡通风格子菜单调整卡通着色，包括描边和自阴影。
- **切换**：仅在模组包含切换项时显示。
  - `保存到 INI`：将当前切换值写入模组的 INI 文件。
  - `重置`：恢复为 INI 文件中的默认值。
  - `保存为预设` / `应用预设`：将当前数值保存为[切换状态预设](/zh-CN/features/mod-manager/#toggle-presets)，或应用已有的预设。
  - `在游戏中预览悬停的值`：在运行中的游戏里显示光标所指的值。
  - `在查看器中显示覆盖层`：在查看器中显示模组的游戏内切换覆盖层。拖动可移动覆盖层，使用 `Ctrl` + 鼠标滚轮或拖动其右下角可调整大小。
- **其他**：
  - `捕获并设为预览`：将视口保存为模组文件夹中的正方形 `preview.png`。如果模组已有预览，查看器会在替换前进行确认。

## 游戏联动

当模组的 Importer 使用内置启动器和 myparsleycat XXMI 库时，可以使用 `保存为预设`、`应用预设` 和 `在游戏中预览悬停的值`。此类游戏运行时，切换查看器顶部的 `应用到游戏` 会将当前数值应用到游戏中。

## 切换查看器

对于包含切换项的模组，右侧的切换查看器会列出每个切换项。更改数值后，模型会按对应状态重新绘制。拖动分隔条可调整面板大小，点击分隔条可显示或隐藏面板。

仅改变贴图或查看器不绘制的效果的数值会标记为 `不在查看器中显示`；这些数值仍会保存到预设中。

## 动画播放

如果模组包含动画，查看器底部将显示播放栏。播放栏可用于播放或暂停动画、选择片段、更改播放速度和跳转到指定帧。
