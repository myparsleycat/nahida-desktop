# 设置

打开导航栏底部的 `设置`。左侧列出各个分区，列表下方显示应用版本和 `检查更新`。

大多数设置在更改后立即保存。代理、GitHub 令牌和 Nahida Agent 设置需要分别点击各自的 `保存` 按钮。

`模组` 分区见 [模组设置](/zh-CN/features/mod-manager/settings)。XXMI 设置位于 XXMI 页面，见 [连接 XXMI](/zh-CN/others/set-up-xxmi)。

## 常规 {#general}

### 应用程序

| 设置 | 默认值 | 说明 |
|---|---|---|
| `登录时启动` | 关闭 | 登录 Windows 时启动应用。仅在安装版中显示。 |
| `提权助手` | 关闭 | 以管理员权限启动一个单独的助手，用于处理需要管理员权限的操作。应用启动时 Windows 会显示 UAC 提示。 |
| `后台运行` | 开启 | 关闭所有窗口后应用仍在后台运行。 |
| `点击标题栏活动徽章以打开` | 开启 | 点击标题栏中的活动徽章时打开相关页面。关闭后可以拖动徽章来移动窗口。 |
| `Mica 背景效果` | 开启 | 窗口背景使用 Windows Mica 效果。更改后会重新打开窗口。仅在 Windows 支持 Mica 时显示。 |
| `模糊效果` | 开启 | 模糊菜单、对话框、通知和覆盖层后方的内容。界面卡顿时请关闭。 |
| `语言` | Windows 语言 | 可选 `한국어`、`English`、`日本語`、`中文`。如果 Windows 显示语言为其中之一，默认使用该语言，否则使用英语。 |
| `主题` | `系统默认` | 可选 `系统默认`、`浅色`、`深色`。 |
| `起始页` | `模组管理器` | 应用启动时显示的页面。可选 `传输`、`GameBanana`、`模组管理器`、`网盘`、`共享网盘`。`网盘` 和 `共享网盘` 需要登录 nahida.live。 |
| `日志级别` | `Warn` | 写入日志的最低级别。可选 `Trace`、`Debug`、`Info`、`Warn`、`Error`、`Fatal`。 |

[持久保存切换状态](/zh-CN/features/mod-tools/persist-toggles) 和 Toggle Viewer 生成器中的 `自动生成 Toggle Viewer` 需要应用保持运行。开启其中任意一项时也会开启 `后台运行`；在其中任意一项开启时关闭 `后台运行` 会显示确认提示。

### 更新

| 设置 | 默认值 | 说明 |
|---|---|---|
| `自动更新` | `自动更新` | 应用更新的处理方式。 |
| `包含预发布版本` | 关闭 | 将 GitHub 预发布版本也作为应用更新提供。草稿版本不包括在内。 |
| `更新状态` | | 显示当前更新状态。有可用更新或更新已下载时，显示 `下载更新` 或 `安装更新`。 |

`自动更新` 的选项如下：

- `自动更新`：在启动时和每小时检查更新，并自动下载。
- `更新提醒`：自动检查更新，仅在你选择时下载。
- `关闭自动更新`：不自动检查或下载更新。

点击分区列表下方的 `检查更新` 可立即检查。

## 账户 {#account}

显示已登录的 nahida.live 账户。

- `登录`：未登录时显示。
- `我的账户`：打开 nahida.live 上的账户页面。
- `退出登录`：退出账户。

无法连接服务器时，点击 `重试` 重新检查连接。

## 传输 {#transfer}

[传输](/zh-CN/features/#transfers) 页面的设置。

| 设置 | 默认值 | 说明 |
|---|---|---|
| `下载并发数` | 32 | 网盘传输中同时下载的文件数。范围为 16–64。 |
| `上传并发数` | 8 | 网盘传输中同时上传的文件数。范围为 4–16。 |

## 网络 {#network}

### 代理

将应用发出的所有外部请求通过代理发送。关闭时使用 Windows 系统代理设置。应用启动的浏览器、游戏和脚本不受影响。

| 设置 | 说明 |
|---|---|
| `启用代理` | 开启或关闭代理。 |
| `类型` | 可选 `HTTP`、`SOCKS5`、`SOCKS5h`。`SOCKS5` 在本地解析目标名称，`SOCKS5h` 在代理端解析。 |
| `主机（不含协议）` | 代理主机，不含协议、路径和端口。 |
| `端口` | 1 到 65535 之间的整数。 |
| `用户名（可选）` | 设置密码时必填。 |
| `密码（可选）` | `删除密码` 会在保存时删除已保存的密码，`保留已保存的密码` 则保留。 |

点击 `保存` 保存。代理更改在重启应用后生效，可在 `需要重启` 对话框中选择 `重启`。

如果无法读取已保存的代理配置，在输入有效配置或关闭代理、保存并重启之前，外部请求会被阻止。

### GitHub 令牌

没有令牌时，GitHub API 请求限制为每个 IP 地址每小时 60 次。使用个人访问令牌后提高到每小时 5,000 次。应用只读取公开仓库，因此细粒度令牌不需要额外权限。

1. 点击 `在 GitHub 上创建令牌` 创建令牌。
2. 在 `个人访问令牌` 中输入令牌，然后点击 `保存`。

令牌针对当前 Windows 用户加密保存。点击 `删除令牌` 删除。如果 GitHub 拒绝已保存的令牌，或当前 Windows 用户无法解密令牌，在输入新令牌之前请求将不带身份验证发送。

## Nahida Agent {#nahida-agent}

设置 Nahida Agent 使用的模型。设置提供商和模型后，导航栏中会显示 Nahida Agent。

### LLM 提供商

| 设置 | 说明 |
|---|---|
| `提供商` | 选择模型列表中的内置提供商或 `自定义`。已保存凭据的提供商标有 `已连接`。 |
| `模型` | 从列表中选择模型或输入模型 ID。字段下方显示模型列表日期，点击 `刷新模型列表` 更新。 |
| `推理` | 推理级别。内置提供商只列出模型支持的级别。 |
| `无需询问即可运行智能体脚本` | 运行智能体编写的 Python 和 PowerShell 脚本时不再逐次请求批准。脚本以你的 Windows 账户权限运行，且不限于智能体的文件夹。 |
| `API 密钥` | 可选 `保留当前值`（或 `保留已配置密钥`）、`替换`、`清除`。支持 ChatGPT 登录的提供商还提供 `ChatGPT Pro/Plus`：点击 `使用 ChatGPT 登录` 并在浏览器中完成登录。浏览器未打开时，使用 `复制链接`。 |

选择 `自定义` 时还会显示以下设置。内置提供商从模型列表获取这些值。

| 设置 | 说明 |
|---|---|
| `协议` | 可选 `OpenAI Responses`、`OpenAI-compatible`、`Anthropic Messages`。 |
| `端点` | API 基础 URL。 |
| `模型支持图像输入` | 将附加的图像和工具返回的截图发送给模型。仅在模型支持图像输入时开启。 |
| `上下文窗口`、`最大输出令牌` | 模型的令牌上限。 |
| `自定义请求头` | 仅随发往自定义端点的请求发送的请求头。勾选 `加密保存` 会加密该值。 |

`测试连接` 会发送测试请求并显示模型和延迟。点击 `保存` 保存提供商设置。

### MCP

添加智能体可作为工具使用的 MCP 服务器。已启用的 MCP 工具会自动运行，并可能拥有 Nahida 文件沙箱之外的权限。

点击 `添加服务器` 并选择 `传输方式`：

- `stdio`：输入 `可执行文件`、`参数（每行一个）` 和 `工作目录`。
- `Streamable HTTP`：输入服务器 URL。
- `Blender (内置)`：通过本地套接字连接 Blender MCP 插件。请先在 Blender 的插件偏好设置中启动桥接服务器。

点击 `添加条目` 添加名称和值，勾选 `加密保存` 会加密该值。开启 `已启用` 后点击 `保存`。已保存服务器的 `测试连接` 会显示服务器提供的工具数量。

### 技能

列出内置技能和用户技能。技能在模型请求时加载。`打开用户技能文件夹` 打开用户技能所在的文件夹，`重新加载` 重新读取该文件夹。

## 高级设置 {#advanced}

以键和值显示所有已保存的设置。使用 `搜索设置键...` 按键筛选，使用 `编辑` 按钮修改原始值。

::: warning
在此输入的值会按原样保存。错误的值可能改变应用的行为。
:::

代理和 GitHub 令牌不在列表中，请在 [网络](#network) 中修改。键中包含 `password`、`token`、`secret`、`credentials` 或 `api_key` 的值显示为 `********`。

## 问题反馈 {#report-a-problem}

向开发者发送问题报告。

| 项目 | 说明 |
|---|---|
| `分类` | 可选 `Desktop 应用问题`、`Nahida 服务问题`、`XXMI 库问题`。 |
| `内容` | 发生了什么问题以及如何复现。必填。 |
| `附件` | `添加文件` 可附加图像、视频、文本文件和 zip 压缩包。`添加模组文件夹` 可附加出现问题的模组文件夹，需要登录 nahida.live，网盘不接受的文件类型会被排除。 |
| `附加日志` | 默认开启。附加应用日志，PC 用户名等敏感信息会被匿名化。 |

长度和附件上限从服务器加载，并显示在各字段旁边。点击 `发送` 发送报告；发送过程中可点击 `取消` 中止。
