# 功能

本节介绍左侧导航栏中的各个页面。

## 传输

显示下载和上传任务的状态，支持暂停、继续和重试传输。并发数和下载带宽限制可在 设置 → Transfer 中设置。

## [GameBanana](/zh-CN/features/gamebanana)

无需打开网页浏览器即可浏览并下载 GameBanana 模组。登录是可选的，仅在点赞等账号操作时才需要登录。

## [模组管理器](/zh-CN/features/mod-manager/)

为每个已注册的游戏启用、禁用、整理和预览模组。它还可以管理模组预设和切换状态预设，并为所选模组打开模组工具，包括[模型查看器](/zh-CN/features/mod-manager/model-viewer)。

## Tools

列出不针对单个模组的通用工具：

- [4001 Fixer](/zh-CN/features/mod-tools/dll-builder)
- [持久保存切换状态](/zh-CN/features/mod-tools/persist-toggles)
- XXMI 菜单制作器
- Toggle Viewer 生成器
- Fix Tool Manager
- 二分查找
- 体型修改（测试版）
- 触摸配置（测试版）

模型查看器、纹理缩放器、液体喷射点等作用于单个模组的工具，需要在模组管理器中通过该模组的右键菜单打开。

## Nahida Agent

与你的模组配合使用的应用内助手。在 设置 → Nahida Agent 中配置提供方和模型后，它会显示在导航栏中。

## [XXMI](/zh-CN/others/set-up-xxmi)

选择通过内置启动器还是已安装的 XXMI Launcher 启动游戏，并管理 Importer 包、XXMI 库、ReShade 以及各游戏的设置。

## 网盘、共享网盘和备份

向 Nahida Drive 上传文件或从中下载文件，将共享网盘链接导入你的网盘，并按计划备份模组文件夹。使用 nahida.live 账号登录后才会显示这些页面。
