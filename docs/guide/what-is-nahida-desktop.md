# What Is Nahida Desktop?

Nahida Desktop is a Windows mod manager for games that use the XXMI importers (GIMI, SRMI, WWMI, ZZMI, HIMI, and EFMI) and for Neverness to Everness.

It manages mods, launches games through XXMI, browses and downloads GameBanana mods, and includes tools for viewing, editing, and fixing mods. With a nahida.live account, Nahida Drive and Backup are also available.

The source code is available on [GitHub](https://github.com/myparsleycat/nahida-desktop) under the [GNU GPLv3](https://github.com/myparsleycat/nahida-desktop/blob/main/LICENSE) license.
