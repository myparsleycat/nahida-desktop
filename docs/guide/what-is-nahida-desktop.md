# What Is Nahida Desktop?

Nahida Desktop is a mod manager designed to make 3DMigoto-based mods easier and faster to manage.

In addition to core mod management, it provides a range of convenience features such as Nahida Live, GameBanana integration, and tools that help with mod conversion and installation.

Nahida Desktop is an open-source project. You can review the source code or contribute on the [official repository](https://github.com/myparsleycat/nahida-desktop), and it is distributed under the [GNU GPLv3](https://github.com/myparsleycat/nahida-desktop/blob/main/LICENSE) license.
