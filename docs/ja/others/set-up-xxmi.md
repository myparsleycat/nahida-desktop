# XXMI の設定

ナビゲーションレールの XXMI ページでは、ゲームの起動方法を選択し、XXMI Importer を管理します。XXMI 対応ゲームを MODマネージャーに追加する前や、XXMI が必要なツールを使う前に設定してください。

## ゲームランチャーを選択

XXMI ページ上部の `ゲームランチャー` で、次のいずれかを選択します。

- **内蔵**: Nahida Desktop が Importer パッケージと XXMI ライブラリのインストールと更新を自ら行い、ゲームを起動します。
- **XXMI Launcher**: Nahida Desktop はインストール済みの XXMI Launcher を使用します。

切り替えても、両方の設定は保持されます。

## 内蔵ランチャー

1. `インポーターのルートフォルダー` を設定します。各 Importer は、このフォルダー内の個別のサブフォルダーにインストールされます。
2. Importer がまだ構成されていない状態で XXMI Launcher のインストールが見つかった場合は、その設定をインポートできます。パッケージと XXMI ライブラリは新たにインストールされます。`Mods` と `d3dx_user.ini` は、XXMI Launcher のフォルダーに残すか新しい Importer フォルダーへ移動するかを選択します。
3. サイドバーで Importer を選択し、`一般` タブでゲームフォルダーを設定してから、`パッケージ` タブでパッケージをインストールします。

各 Importer のページには次のタブがあります。

- **一般**: ゲームフォルダー、MOD フォルダー、Importer のアイコン、ゲームの起動方法（直接起動、Steam、Epic Games、カスタムコマンド）、DLL 注入のオプション。
- **パッケージ**: Importer パッケージと XXMI ライブラリのバージョン。ライブラリの提供元には SpectrumQT または myparsleycat のフォークを選択できます。
- **ゲーム設定**（GIMI、SRMI、HIMI、WWMI のみ）: FPS 制限の解除、HDR、テクスチャ品質など、ゲームごとのオプション。原神では GI FPS Unlocker を使用します。
- **詳細設定**: ハンティングモード、安全でないモード、ログレベル、MOD のキー割り当て、カスタムコマンドなどの 3DMigoto オプション。
- **d3dx.ini**: `d3dx.ini` の設定を編集します。
- **ツール**: Quick Start デスクトップショートカットの作成、ランタイムまたはパッケージの修復、MOD の INI ファイルの最適化を行います。また、ログモードをオンにして、問題報告用のログとクラッシュダンプを収集できます。
- **ランタイム**（ランタイムがある Importer のみ）: ツールがゲームの Mods フォルダーにインストールするグローバル MOD。起動時に自動で更新されます。

`ReShade` ページでは、ReShade と公式エフェクトパッケージをインストールし、共有プリセットフォルダーを設定します。

`管理` では、保留中の更新、全体設定、起動前の確認、キャッシュの削除を表示し、内蔵ランチャーをリセットできます。

### DLL インジェクター

Importer ページの `一般` タブにある `DLL インジェクター` は、ランタイム DLL の読み込み方法を選択します。

- `従来のランチャー方式`: 既定値です。ランタイム自身のフックまたはローダーで読み込みます。
- `Native`: フックを使わず、64ビットのゲームにランタイムと追加DLLを直接注入します。

`注入方式` が `Bypass` の場合は、追加DLLのみを注入します。

`Native` は XXMI ローダー（`3dmloader.dll`）や Legacy 3DMigoto ローダーを必要としないため、Legacy ランタイムでも XXMI ライブラリなしで追加DLLを注入できます。64ビットのゲームでのみ動作し、ゲームプロセスと各 DLL の読み込みを `ゲーム起動の制限時間（秒）` まで待機します。

## XXMI Launcher

1. `XXMIパス` に XXMI Launcher のフォルダーを入力し、`保存` をクリックします。インストール先を変更していない場合、通常は次のパスです。

   ```txt
   %AppData%\XXMI Launcher
   ```

2. インストール場所がわからない場合は、`自動検索` をクリックします。

::: warning
`自動検索` は、すべてのドライブから XXMI Launcher を探します。複数インストールされている場合は別のインストールが選択されることがあるため、検出されたパスを確認してください。
:::

パスを保存すると、有効な Importer が表示され、XXMI DLL と Importer パッケージのバージョンを変更できるようになります。

## 起動前の確認

どちらのランチャーでも、ゲームの起動前に問題がないかを確認できます。確認対象は、原神のキャラクター動的解像度、NVIDIA スムーズモーション、3DMigoto のログ出力、未圧縮のテクスチャです。

## XXMI が必要な機能

- MODマネージャーからの XXMI ゲームの起動（異環のゲームには XXMI は不要です）
- [4001 Fixer](/ja/features/mod-tools/dll-builder)
- [トグルの永続保存](/ja/features/mod-tools/persist-toggles)
- Toggle Viewer ジェネレーター
