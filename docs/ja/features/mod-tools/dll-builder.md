# 4001 Fixer

原神の `4001` エラー（不正プログラムの検出）は、XXMI に同梱されている標準の DLL の代わりに `XXMI-Libs-Package` のソースからビルドした DLL を使うと解消される場合が多くあります。

`4001 Fixer` は、代替の `d3d11.dll` をビルドするか、既存の DLL に PE パディングの多様化を適用します。

## 必要なビルドツールをインストール

ビルドツールは手動でインストールする必要があります。Git を別途インストールする必要はありません。Nahida Desktop が初回ビルド時にポータブル版 Git（MinGit、約 40MB）をダウンロードし、アプリデータフォルダー内で使用します。

1. [Visual Studio Build Tools 2022](https://aka.ms/vs/17/release/vs_BuildTools.exe) をダウンロードして実行します。
2. 個別コンポーネントで次の項目を選択してインストールします。
   - **MSVC v143 - VS 2022 C++ x64/x86 ビルドツール (最新)**
   - **Windows 11 SDK (10.0.22621.0)**

::: warning
ビルドツールのインストールには約 4.4GB のディスク容量が必要です。
:::

## XXMI を設定

この機能を使うには、先に XXMI を設定する必要があります。詳しくは [XXMI の設定](/ja/others/set-up-xxmi) を参照してください。

## DLL をビルド

ビルド画面には次のオプションがあります。

- **プロバイダー**: ビルドする `XXMI-Libs-Package` リポジトリを選択します。`myparsleycat` は `XXMI-Libs-Package-Forked` フォークをビルドします。
- **バージョン**: ビルドする XXMI ライブラリのバージョンを選択します。
- **対象 GIMI Importer**: ビルドした DLL を適用する GIMI Importer を選択します。`4001` エラーは原神でのみ発生するため、GIMI Importer のみが表示されます。

**ビルド開始** ボタンをクリックするとビルドが始まります。Windows SDK のヘッダー（`crtdbg.h` など）や必要な SDK バージョンが見つからずにビルドが失敗した場合は、インストールまたは修復の案内が表示されます。SDK がインストール済みの場合は、Visual Studio Installer で該当するインストールを修復するか、**Visual Studio のパス** に Visual Studio または Build Tools 2022 のインストールフォルダー、またはその `vcvars64.bat` を指定してください。

## DLL パディング多様化

**DLL パディング多様化** タブは、選択した GIMI Importer の `d3d11.dll` のレイアウトを変えずに、PE パディングのバイトを多様化します。適用前に同じフォルダーに `pepd` バックアップファイルを作成し、多様化した DLL が適用されている間は復元の操作を表示します。

## システムフォルダーと管理者権限

GIMI Importer が `C:\Program Files\` などの保護された場所にある場合、DLL のインストール時に Windows の UAC プロンプトが表示されます。プロンプトを拒否すると操作は失敗します。ゲームが `d3d11.dll` を使用中の場合はファイルを置き換えられないため、先にゲームを終了してください。

## 安全でないモード

**安全でないモード** がオフの場合、XXMI は公式提供ではない DLL に対して警告を表示します。4001 Fixer で DLL を適用すると、GIMI Importer の安全でないモードが自動的にオンになります。それでも `d3d11.dll` の署名が無効であるという警告が表示される場合は、手動でオンにしてください。

- **内蔵ランチャー**: XXMI ページで GIMI Importer を開き、`詳細設定` タブで `安全でないモード` をオンにします。
- **XXMI Launcher**: XXMI Launcher の設定で Unsafe Mode をオンにします。

その後、ゲームを再起動します。内蔵ランチャーで署名済みの DLL に戻すには、Importer の `パッケージ` タブで `公式 DLL に戻す` をクリックします。
