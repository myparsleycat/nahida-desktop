# トグルの永続保存

3DMigoto は、`persist` として指定されたトグル変数の値を MOD の INI ファイルではなく `d3dx_user.ini` に保存します。そのため、MOD を無効化した状態で Reload (`F10`) を実行すると値が削除される場合があり、MOD を再度有効化すると MOD の INI ファイルの既定値が適用されます。

## 機能の説明

この機能をオンにすると、Nahida Desktop は各 Importer の `d3dx_user.ini` の変更を監視し、保存されたトグル値を対応する MOD の INI ファイルに反映します。MOD を無効化したり再読み込みしたりしても、トグルの状態は維持されます。

## コピーした MOD と namespace

値を書き込む INI は、各変数を宣言した INI の namespace（`namespace = ...` で明示した名前を含む）で探します。複数の INI が同じ namespace 内で同じ変数を宣言している場合、その変数は保存せず、競合したファイルのパスをログに記録します。無効化された MOD はこの検査の対象外です。

フォルダー名を変更しても、明示した namespace は変わりません。コピーした MOD のトグル状態を独立させるには、各コピーに異なる namespace を設定し、help・メニュー INI の参照も変更する必要があります。Nahida Desktop は namespace や参照を変更しません。

## 有効にする

Tools ページで `トグルの永続保存` を開き、スイッチをオンにします。スイッチの下のログには、保存された値とスキップされた変数が表示されます。

::: warning
この機能を使うには、先に XXMI を設定する必要があります。詳しくは [XXMI の設定](/ja/others/set-up-xxmi) を参照してください。
:::
