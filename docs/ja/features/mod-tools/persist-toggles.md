# トグル状態の永続保存

3DMigoto は `persist` として指定されたトグル変数の状態を `d3dx_user.ini` に保存するため、ゲームを再起動しても以前のトグル状態を維持できます。

ただし、この値は MOD の INI ファイルではなく `d3dx_user.ini` にのみ保存されます。そのため、MOD を無効化した状態で Reload (`F10`) を実行すると、そのトグル値が削除される場合があります。後で MOD を再度有効化したとき、以前の状態ではなく MOD の INI ファイルにある既定値が適用されることがあります。

## 機能の説明

この機能を有効にすると、Nahida Desktop は各 Importer の `d3dx_user.ini` の変更を監視します。

ゲーム内でトグルを変更し、Reload (`F10`) によって `d3dx_user.ini` が更新されると、Nahida Desktop は `d3dx_user.ini` に保存されたトグル値を対応する MOD の INI ファイルへ自動的に反映します。

その結果、MOD を無効化した後や再読み込み後でも、以前のトグル状態を維持できます。

## 使用前の確認事項

::: warning
この機能を使うには、先に XXMI パスを設定する必要があります。  
詳しくは [XXMI の設定](/ja/others/set-up-xxmi) を参照してください。
:::
