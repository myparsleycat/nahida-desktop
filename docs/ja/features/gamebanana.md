# GameBanana

Nahida Desktop では、Web ブラウザを開かずにアプリ内から GameBanana の MOD を閲覧し、ダウンロードできます。

このページでは、GameBanana ページで MOD を探してダウンロードする方法を説明します。

## はじめに

![画像](/features/gamebanana/login1.png)

この機能を使うには、まず GameBanana にログインする必要があります。

![画像](/features/gamebanana/login2.png)

左側のサイドバーから GameBanana ページへ移動すると、認証が必要な場合は GameBanana のログイン画面が表示されます。

Username や Email など、好きなログイン方法を選んでログインできます。

![画像](/features/index/gamebanana-ko.png)

ログインが正常に完了すると、ログイン画面は自動的に閉じ、GameBanana ページのメイン画面が表示されます。

## 閲覧

![画像](/features/gamebanana/browsing.gif)

GameBanana ページでは、次の方法で MOD を探せます。

- 左上で閲覧したいゲームを選択します。
- 右側で目的のカテゴリを選択します。
- MOD カードをクリックして詳細ページへ移動します。

## ダウンロード

![画像](/features/gamebanana/download.gif)

MOD 詳細ページの右側にあるダウンロードカードで、その MOD のファイル一覧を確認できます。

ダウンロードしたいファイルをクリックし、ダウンロード方法を選ぶとダウンロードが始まります。

ダウンロードが完了すると、MOD の代表画像も自動で一緒にダウンロードされ、展開された MOD フォルダーに保存されます。
