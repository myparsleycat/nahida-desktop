# GameBanana

Web ブラウザを開かずに、アプリ内で GameBanana の MOD を閲覧してダウンロードします。

## ログイン

ログインは任意です。GameBanana アカウントがなくても MOD の閲覧と、ログインが不要な MOD のダウンロードができます。

ログイン画面は、GameBanana ページのログインボタンを押したときや MOD にいいねするときなど、ログインが必要な場合にのみ表示されます。

::: info
ログイン画面には Microsoft Edge WebView2 Runtime を使用します。インストーラー版ではインストール時に導入されます。ポータブル版では、あらかじめインストールされている必要があります。
:::

## 閲覧

ゲームとカテゴリを選択し、MOD をクリックすると詳細ページが開きます。異環を含め、MODマネージャーが対応するすべてのゲームを閲覧できます。

## ダウンロード

MOD 詳細ページには、その MOD のファイルが一覧表示されます。ファイルをクリックしてダウンロード先を選ぶと、ダウンロードが始まります。ダウンロードは転送ページに表示されます。

ダウンロードが完了すると、アーカイブは選択した MOD フォルダーに展開され、MOD のサムネイルがプレビューとして同じフォルダーに保存されます。
