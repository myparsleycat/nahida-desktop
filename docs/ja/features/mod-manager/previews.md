# プレビュー

MODマネージャーは、MOD とサイドバーのフォルダーに画像または動画のプレビューを表示します。

対応するファイル形式は `png`、`jpg`、`jpeg`、`gif`、`webp`、`bmp`、`avif`、`avifs`、`mp4`、`webm`、`avi`、`mkv`、`mov` です。動画は音声なしでループ再生されます。

## MOD のプレビュー

MODマネージャーは、MOD のプレビューに使うファイルを次の順序で探します。

1. MOD フォルダー直下のファイル
2. サブフォルダー内のファイル
3. 無効化された（`DISABLED`）サブフォルダー内のファイル

同じ場所に複数のファイルがある場合は、ファイル名が `preview` で始まるファイル、ファイル名に `preview` を含むファイル、その他のファイルの順に選択します。大文字と小文字は区別しません。ファイル名に `normal`、`light`、`material`、`diffuse` を含むファイルはテクスチャとみなして除外します。

MOD に画像が複数ある場合は、グリッド表示のプレビューに `前のプレビュー画像` と `次のプレビュー画像` ボタンが表示されます。選択した画像は MOD フォルダーの `nhd.json` に保存され、次回も表示されます。

## フォルダーのプレビュー

サイドバーのフォルダーのプレビューには、フォルダー直下の画像または動画ファイルを使用します。サイドバーを `プレビューグリッド` で表示すると、フォルダーのプレビューが大きく表示されます。

::: info
[MOD 設定](/ja/features/mod-manager/settings) の `サブフォルダーからMODプレビューを検索` を有効にすると、フォルダーにプレビューがない場合にフォルダー内の MOD フォルダーからもプレビューを探します。
:::

## プレビューを表示

- `拡大表示`: プレビューをアプリのウィンドウ上に大きく表示します。グリッド表示でプレビューを右クリックして選択します。リスト表示ではサムネイルをクリックします。
- `プレビュービューアーで開く`: プレビューファイルを Windows で関連付けられたプログラムで開きます。MOD メニューの `プレビュー` セクション、またはグリッド表示のプレビューのメニューから選択します。

## プレビューを設定または差し替え

- **MOD**: 画像ファイル、画像の URL、または画像をクリップボードにコピーしてから MOD を右クリックし、`プレビュー` セクションの `貼り付け` を選択します。グリッド表示では、プレビューがない MOD のプレビュー領域にも `貼り付け` ボタンが表示されます。動画ファイルは貼り付けできません。
- **サイドバーのフォルダー**: 画像または動画ファイルを 1 つ、サイドバーのフォルダーにドラッグ＆ドロップします。
- **モデルビューアー**: [モデルビューアー](/ja/features/mod-manager/model-viewer) で `その他` → `キャプチャしてプレビューに設定` を選択します。

既存のプレビューがある場合は、上書きする前に確認メッセージが表示されます。

MOD メニューの `プレビュー` セクションで `プレビューを削除` を選択すると、現在のプレビューファイルがごみ箱に移動します。

## モデルプレビュー {#model-preview}

[MOD 設定](/ja/features/mod-manager/settings#layout) の `プレビューがないMODにモデルプレビューを表示` が有効な場合、グリッド表示で画像や動画がない MOD には、現在のトグル状態のモデル画像が表示されます。異環の MOD には表示されません。

モデルプレビューを右クリックすると、`モデルビューアーで開く` と `貼り付け` を選択できます。
