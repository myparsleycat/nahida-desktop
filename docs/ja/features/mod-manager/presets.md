# プリセット

MODマネージャーには 2 種類のプリセットがあります。

- **プリセット**: ゲームでどの MOD が有効になっているかを保存します。
- **トグルプリセット**: 1 つの MOD のトグル値を保存します。

## プリセット

プリセットの選択欄は、サイドバー下部のゲームの選択欄の横にあります。

- **保存**: プリセットの選択欄の横にある `+` ボタン（`新規プリセット作成`）をクリックし、名前と `説明（任意）` を入力します。現在有効になっている MOD の構成が保存されます。
- **適用と削除**: プリセットの選択欄でプリセットを選択すると、プリセット名と説明がダイアログに表示されます。`適用` または `削除` を選択します。

プリセットを適用したときに見つからない MOD や状態を変更できなかった MOD があると、その数が通知に表示されます。

`DISABLED` 接頭辞の有無だけが異なるフォルダーは同じ MOD として扱われます。このようなフォルダーがある状態でプリセットを保存すると、`重複したMOD項目が見つかりました` ダイアログが表示されます。`無効な重複フォルダーの名前を変更して続行` を選択すると、無効なフォルダーの名前を変更してからプリセットを保存します。

以前のバージョンで作成したプリセットには `旧形式` と表示され、適用できません。削除してから作り直してください。

## トグルプリセット {#toggle-presets}

トグルプリセットは、1 つの MOD のトグル値に名前を付けて保存し、保存した値を再び適用します。

### 開き方

- MOD を右クリックして `トグルプリセット` を選択します。
- グリッド表示のカードで、INI リスト上部のトグルプリセットボタンをクリックします。保存済みのプリセットと `プリセットを管理…` が表示されます。
- [モデルビューアー](/ja/features/mod-manager/model-viewer) の `トグル` メニューで `プリセットとして保存` または `プリセットを適用` を選択します。

INI ファイルがある MOD でのみ使用でき、異環の MOD では使用できません。

### 保存先

トグルプリセットを初めて使うときに `トグルプリセットの保存先` を選択します。

- `MOD フォルダー (nhd.json)`: MOD フォルダーの `nhd.json` に保存します。フォルダーの名前変更や移動後もプリセットは維持され、フォルダーの共有時にはプリセットも一緒に共有されます。
- `アプリのデータベース`: アプリのデータベースに保存します。MOD フォルダーは変更しませんが、MOD フォルダーの名前を変更したり移動したりすると、プリセットを見つけられなくなります。

保存先は、トグルプリセットのダイアログの `保存先`、または [MOD 設定](/ja/features/mod-manager/settings) の `トグルプリセットの保存先` で変更します。変更すると、既存のプリセットが新しい保存先に移動します。

### 保存と適用

トグルプリセットのダイアログでプリセット名を入力し、`現在の値を保存` を選択します。保存したプリセットは、一覧から適用、名前の変更、削除ができます。

- **値の読み取り元**: ゲームが実行中でアプリと接続されている場合は、実行中のゲームから値を読み取ります。それ以外の場合は、MOD の INI ファイルと `d3dx_user.ini` から値を読み取ります。
- **適用**: プリセットの値を MOD の INI ファイルに書き込みます。ゲームが実行中でアプリと接続されている場合は、実行中のゲームにもすぐに適用します。

::: warning
トグルプリセットを保存または適用するには、内蔵ランチャーと myparsleycat の XXMI ライブラリでゲームを起動するように [XXMI](/ja/others/set-up-xxmi) を設定する必要があります。そうでない場合は `内蔵ランチャーと myparsleycat ライブラリが必要です` と表示され、保存と適用は無効になります。
:::
