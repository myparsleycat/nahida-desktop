# MODマネージャー

MODマネージャーでは、登録したゲームごとに MOD の有効化と無効化、グループへの整理、プレビューとプリセットの管理を行います。

ページは左側のサイドバーと右側の MOD リストに分かれています。ゲームとプリセットの選択欄はサイドバーの下部にあります。

## ゲームを追加

ゲームの選択欄の横にある `+` ボタンをクリックすると、`ゲーム追加` ダイアログが開きます。

- **ゲーム名**: ゲームの選択欄に表示される名前です。
- **Importer**: ゲームが MOD を読み込む方法を選択します。
  - XXMI Importer（`GIMI`、`SRMI`、`WWMI`、`ZZMI`、`HIMI`、`EFMI`）: Importer の Mods フォルダーが MOD フォルダーとして使われます。Importer は [XXMI を設定](/ja/others/set-up-xxmi) すると一覧に表示されます。
  - `NTE`: 異環のインストールフォルダーを選択します。カスタム MOD フォルダーも選択でき、その場合はゲームの Mods フォルダーがそのフォルダーにリンクされます。ゲームが MOD を読み込むのに必要なファイルは Nahida Desktop がインストールします。
  - `なし`: 任意のフォルダーを MOD フォルダーとして選択します。Nahida Desktop からゲームを起動することはできません。

後からゲームを変更するには、ゲームの選択欄を開き、ゲームの横にある鉛筆ボタンをクリックします。`ゲーム設定` ダイアログでは、ゲームの表示順の変更とゲームの削除もできます。

## フォルダー構成

推奨される MOD フォルダー構成は次のとおりです。

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
サイドバーには MOD フォルダー直下のフォルダーが表示されます。MOD は MOD フォルダーに直接置かず、`Character`、`Enemy`、`NPC` のような分類フォルダーの中に置くことを推奨します。

- 推奨: `Mods\Character\SomeCharacterMod`
- 非推奨: `Mods\SomeCharacterMod`
:::

### サブグループ

サイドバーのフォルダーは、サブフォルダーをその下に展開して表示できます。サイドバーでフォルダーを右クリックし、`サブフォルダーを探索` を選択するとサブフォルダーが表示され、`サブフォルダーとして指定` を選択すると常に表示されます。サブフォルダーが表示中または指定済みのフォルダーをクリックすると折りたたみ/展開され、それ以外のフォルダーをクリックするとそのフォルダーが選択されます。

`Ctrl` を押しながらフォルダーをクリックすると、フォルダーが展開されて選択されます。`Alt` を押しながらフォルダーをクリックすると、親フォルダーを折りたたみ/展開できます。

MOD リストのフォルダーもサブグループとして扱えます。そのフォルダーを右クリックして `サブグループとして指定` を選択します。解除するには、サイドバーのフォルダーメニューで `手動サブグループ指定を解除` を選択します。

### 分類基準

サイドバーの `その他` メニューにある `分類基準` を使うと、ゲームのフォルダーをフォルダー単位ではなく、自分で定義した分類ごとにまとめられます。`分類を管理…` を選択して分類を作成し、サイドバーでフォルダーを右クリックして `分類` から割り当てます。

## MOD を追加

サイドバーでフォルダーを選択した状態で、次の方法から MOD を追加できます。

- [GameBanana](/ja/features/gamebanana) から MOD をダウンロードします。
- MOD フォルダーまたはアーカイブを MOD リストにドラッグ＆ドロップします。
- MOD リスト上部の `...` ボタンをクリックし、`ダウンロード` を選択して、ダウンロードするファイルの URL を入力します。

## 検索

`Ctrl+F` を押すと、現在のゲームの MOD を検索できます。韓国語の名前は初声（子音）でも一致します。

## プレビュー

MODマネージャーは、MOD フォルダー内でファイル名が `preview` の画像または動画ファイルを大文字小文字を区別せずに探し、MOD のプレビューとして使用します。見つからない場合は、フォルダー内で最初に見つかった対応メディアファイルを使用します。

::: info
設定 → MOD の `サブフォルダーからMODプレビューを検索` が有効な場合は、サブフォルダーも検索します。
:::

設定 → MOD の `プレビューがないMODにモデルプレビューを表示` が有効な場合、プレビューがない MOD には、現在のトグル状態のモデル画像がグリッドに表示されます。

### プレビューを設定または差し替え

- サイドバーのフォルダーには、画像または動画ファイルをドラッグ＆ドロップします。
- MOD の場合は、画像または動画ファイルをコピーしてから MOD を右クリックし、`プレビュー` の `貼り付け` を選択します。プレビューがない MOD では、プレビュー領域にも `貼り付け` ボタンが表示されます。
- [モデルビューアー](/ja/features/mod-manager/model-viewer) で `その他` → `キャプチャしてプレビューに設定` を選択します。

同じメニューの `プレビューを削除` で、現在のプレビューを削除できます。

## プリセット

プリセットは、有効になっている MOD の構成を保存して復元します。プリセットの選択欄の横にある `+` ボタンをクリックすると現在の状態を保存でき、プリセットを選択すると適用または削除できます。

## トグルプリセット {#toggle-presets}

トグルプリセットは、1 つの MOD のトグル値を保存します。MOD を右クリックして `トグルプリセット` を選択すると、現在の値の保存や保存済みプリセットの適用ができます。プリセットは MOD フォルダー（`nhd.json`）またはアプリのデータベースに保存できます。

実行中のゲームから値を読み取るには、内蔵ランチャーと myparsleycat の XXMI ライブラリが必要です。それ以外の場合は、MOD の INI ファイルと `d3dx_user.ini` から値を読み取ります。

## ゲームを起動

ゲームの選択欄でゲームを選択し、再生ボタンをクリックすると、MOD を適用した状態でゲームを起動できます。XXMI 対応ゲームは、[XXMI](/ja/others/set-up-xxmi) ページで選択したランチャーを使用します。異環の場合は、初回起動時にゲームのランチャーのパスを設定します。
