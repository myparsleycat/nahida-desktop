# MODマネージャー

MODマネージャーでは、登録したゲームごとに MOD を有効化・無効化し、フォルダー単位で整理します。[プレビュー](/ja/features/mod-manager/previews)、[プリセット](/ja/features/mod-manager/presets)、[MOD ツール](/ja/features/mod-manager/mod-tools)、[モデルビューアー](/ja/features/mod-manager/model-viewer) もこの画面から開きます。

## 画面構成

画面は左側のサイドバーと右側の MOD リストに分かれています。

- **サイドバー**: MOD フォルダー直下のフォルダーが表示されます。各フォルダーには有効な MOD 数と全 MOD 数が表示されます。上部にフォルダー検索欄と `その他` メニューがあり、下部にゲームとプリセットの選択欄があります。
- **MOD リスト**: サイドバーで選択したフォルダーの MOD が表示されます。ダウンロード中の MOD と有効な MOD が先に表示されます。

サイドバーと MOD リストの境界をドラッグすると、サイドバーの幅を変更できます。境界にフォーカスがあるときは `←`/`→`、`Shift+←`/`Shift+→`、`Home`/`End` でも変更できます。

### MOD リスト上部

| 項目 | 説明 |
|---|---|
| 検索欄 | 選択したフォルダーの MOD を検索します。[検索](#search) を参照してください。 |
| 並べ替え | `名前`、`日付`、`サイズ` から並べ替えの基準を選択します。横の `並び順` ボタンで昇順と降順を切り替えます。 |
| `リスト表示` / `グリッド表示` | MOD リストの表示方法を切り替えます。 |
| `フォルダーを開く` | 選択したフォルダーをエクスプローラーで開きます。 |
| `その他` | `すべて有効化`、`すべて無効化`、`MODを結合 (ベータ)`、`ダウンロード`、`ツール` を表示します。`MODを結合 (ベータ)` は GIMI、SRMI、ZZMI、HIMI、WWMI、EFMI のゲームでのみ、`ツール` は Wuwa Mod Fixer または ZZMI Mod Fixer に対応するゲームでのみ表示されます。 |

### リスト表示とグリッド表示

- **リスト表示**: `名前`、`サイズ`、`日付` の列を表示します。列見出しをクリックするとその基準で並べ替え、もう一度クリックすると順序を反転します。
- **グリッド表示**: MOD をカードで表示します。カードの幅と列数は [MOD 設定](/ja/features/mod-manager/settings#layout) の `MODグリッドレイアウト` で指定します。

カードの色は MOD の状態を表します。緑は有効、赤は無効、黄色は有効だが必要な依存関係がインポーターにない状態です。

カードの見出しには `Nahida Agent`、`MOD ツール`、`モデルビューアーで開く`、`削除`、`フォルダーを開く` ボタンがあります。体型変更、タッチプロファイル、液体噴射ポイントを適用した MOD には、対応するアイコンが表示されます。

カードの右側には MOD の INI ファイルとトグルセクションの一覧が表示されます。トグルセクションのキーは [キーの変更](#keys) で説明する方法で変更します。`INI ファイルを開く` で INI ファイルを開き、`INI リストを折りたたむ` で一覧を折りたたみます。

## ゲーム {#games}

### ゲームを追加

ゲームの選択欄の横にある `+` ボタン（`ゲーム追加`）をクリックすると、ゲーム追加ダイアログが開きます。

- **ゲーム名**: ゲームの選択欄に表示される名前です。
- **インポーター**: ゲームが MOD を読み込む方法を選択します。既定値は `なし` です。
  - `なし`: 任意のフォルダーを `MODフォルダーのパス` として選択します。Nahida Desktop からゲームを起動することはできません。
  - XXMI インポーター（`GIMI`、`SRMI`、`WWMI`、`ZZMI`、`HIMI`、`EFMI`）: インポーターの Mods フォルダーが MOD フォルダーとして使われます。インストールされていないインポーターには `未インストール` と表示され、選択できません。[XXMI を設定](/ja/others/set-up-xxmi) する前は `インポーター設定を開く` ボタンが表示されます。
  - `NTE`: `NTE インストールフォルダー` を選択します。ゲーム名は `異環` に固定されます。`カスタム MOD フォルダー` を選択すると、ゲームの Mods フォルダーがそのフォルダーにリンクされます。ゲームが MOD を読み込むのに必要なファイルは Nahida Desktop がインストールします。

### ゲーム設定

ゲームの選択欄を開き、ゲームの横にある鉛筆ボタン（`ゲーム設定`）をクリックします。ダイアログではインポーターと MOD フォルダーのパスを変更し、`表示順` でゲームの選択欄での順番を変更します。ゲーム名は変更できません。

`ゲーム削除` を選択すると、ゲームが一覧から削除されます。そのゲームのプリセットも削除され、この操作は元に戻せません。

### ゲームを起動

ゲームの選択欄でゲームを選択し、`ゲームを起動` ボタンをクリックすると、MOD を適用した状態でゲームを起動できます。

- XXMI 対応ゲームは、[XXMI](/ja/others/set-up-xxmi) ページで選択したランチャーを使用します。起動前に MOD の適用を妨げるゲーム設定や未圧縮のテクスチャが見つかると、確認ダイアログが表示されます。
- 異環の場合は、初回起動時に `ランチャーパスを指定` ダイアログでゲームのランチャーのパスを設定します。
- インポーターが `なし` のゲームは起動できません。

## フォルダー構成

推奨される MOD フォルダー構成は次のとおりです。

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
サイドバーには MOD フォルダー直下のフォルダーが表示されます。MOD は MOD フォルダーに直接置かず、`Character`、`Enemy`、`NPC` のような分類フォルダーの中に置くことを推奨します。

- 推奨: `Mods\Character\SomeCharacterMod`
- 非推奨: `Mods\SomeCharacterMod`
:::

## サイドバー

### フォルダーメニュー

サイドバーでフォルダーを右クリックすると、次の項目が表示されます。

| 項目 | 説明 |
|---|---|
| `すべて有効化` / `すべて無効化` | フォルダー内のすべての MOD を有効化または無効化します。 |
| `フォルダーを有効化` / `フォルダーを無効化` | フォルダー自体を有効化または無効化します。 |
| `ファイルエクスプローラーで開く` | フォルダーをエクスプローラーで開きます。 |
| `新しいフォルダーを作成` | フォルダー内に新しいフォルダーを作成します。 |
| `削除` | フォルダーをごみ箱に移動します。 |
| `サブフォルダーを展開` / `サブフォルダーを常に展開` | [サブグループ](#subgroups) を参照してください。 |
| `キャラクターを設定…` | フォルダーの MOD に使うキャラクターを設定します。[キャラクターを設定](/ja/features/mod-manager/mod-tools#set-character) を参照してください。 |
| `分類` | フォルダーを分類基準のグループに割り当てます。[分類基準](#group-by) を参照してください。 |
| `ツール` | フォルダー全体に Wuwa Mod Fixer または ZZMI Mod Fixer を実行します。対応するゲームでのみ表示されます。 |

### その他メニュー

サイドバー上部の `その他` メニューには次の項目があります。

- `新しいフォルダーを作成`: MOD フォルダー直下に新しいフォルダーを作成します。
- `フォルダーを並べ替え`: `名前`、`MOD 数`、`有効な MOD 数` から並べ替えの基準を選び、`昇順` または `降順` を選択します。
- `分類基準`: [分類基準](#group-by) を参照してください。
- `空のフォルダーを非表示`: MOD がないフォルダーを非表示にします。
- `プレビューグリッドに切り替え` / `行リストに切り替え`: サイドバーを正方形のプレビューグリッドまたは行リストで表示します。

`フォルダーを並べ替え` と `空のフォルダーを非表示` は、アプリを再起動するとリセットされます。

### サブグループ {#subgroups}

サイドバーのフォルダーは、サブフォルダーをその下に展開して表示できます。フォルダーを右クリックして `サブフォルダーを展開` を選択するとサブフォルダーが表示され、`サブフォルダーを常に展開` を選択するとアプリを再起動しても表示されたままになります。

サブフォルダーが展開されたフォルダーをクリックすると折りたたみ/展開され、それ以外のフォルダーをクリックするとそのフォルダーが選択されます。`Ctrl` を押しながらフォルダーをクリックすると、フォルダーが展開されて選択されます。`Alt` を押しながらフォルダーをクリックすると、親フォルダーを折りたたみ/展開できます。

MOD リストのフォルダーもサブグループとして扱えます。そのフォルダーを右クリックして `サブグループとして指定` を選択すると、親フォルダーが折りたたまれていてもサイドバーに表示されます。解除するには、サイドバーのフォルダーメニューで `手動サブグループ指定を解除` を選択します。

### 分類基準 {#group-by}

`その他` メニューの `分類基準` を使うと、サイドバーのフォルダーを自分で定義した分類ごとにまとめられます。

1. `分類基準` → `分類を管理…` を選択し、`新しい分類基準` で分類基準とグループを作成します。
2. サイドバーでフォルダーを右クリックし、`分類` からグループに割り当てます。
3. `分類基準` で作成した分類基準を選択すると、サイドバーがグループごとに分かれます。グループに割り当てられていないフォルダーは `未分類` に表示されます。

`分類基準` → `フォルダー` を選択すると、フォルダー単位の表示に戻ります。

## MOD を追加

サイドバーでフォルダーを選択した状態で、次の方法から MOD を追加できます。

- [GameBanana](/ja/features/gamebanana) から MOD をダウンロードします。`パス選択` ダイアログで `MODマネージャー` を選択すると、`ダウンロード確認` 画面でファイル名とダウンロード先を指定します。
- MOD フォルダーまたはアーカイブ（`.zip`、`.rar`、`.7z`）を MOD リストにドラッグ＆ドロップします。アーカイブは自動的に解凍されます。
- MOD リスト上部の `その他` メニューで `ダウンロード` を選択し、`URLからダウンロード` ダイアログにファイルの直接ダウンロード URL を入力します。http と https の URL のみ対応しており、Web ページの URL は使用できません。

最上位フォルダーが 1 つだけのアーカイブの解凍方法は、[MOD 設定](/ja/features/mod-manager/settings) の `解凍パス方式` で指定します。`毎回確認` を選択すると、追加するたびに `解凍パスを選択` ダイアログが表示されます。

## MOD の有効化と無効化

- MOD をクリックすると有効化または無効化します。
- `Ctrl` を押しながら MOD をクリックするか、MOD にフォーカスがあるときに `Ctrl+Enter` を押すと、同じフォルダーの他の MOD をすべて無効化し、その MOD だけを有効化します。その MOD がすでに有効な場合は無効化します。
- MOD の検索結果が 1 件だけのときに `Enter` を押すと、その MOD に同じ操作を適用し、検索語を消去します。

必要な依存関係がインポーターにない MOD を有効化すると、`必要な依存関係がありません` ダイアログが表示されます。`無視して有効にする` を選択すると、そのまま有効化します。

## 検索 {#search}

サイドバー上部にフォルダーの検索欄が、MOD リスト上部に MOD の検索欄があります。`Ctrl+F` を押すとフォルダーの検索欄に移動し、フォルダーを選択している状態でもう一度押すと MOD の検索欄に移動します。

- **フォルダー検索**: 名前に検索語を含むフォルダーを表示します。一致するフォルダーが 1 つだけの場合は自動的に選択されます。
- **MOD 検索**: 選択したフォルダー内の MOD を検索します。韓国語の名前は初声（子音）や入力途中の文字でも一致します。

## キーの変更 {#keys}

カードの INI リストには、トグルセクションごとに次の値に切り替えるキーと前の値に切り替えるキーが表示されます。設定されていないキーは `キーを追加` または `戻るキーを追加` と表示されます。

キーをクリックすると、キーの変更ダイアログが開きます。設定するキーの組み合わせを押すか、`手動で編集` に `ctrl alt no_shift vk_up` の形式で入力します。

異環の MOD では、INI リストの代わりに入力キーの一覧が表示されます。修飾キーなしでキーを 1 つだけ設定でき、同じ MOD ですでに使用しているキーは設定できません。

## MOD メニュー

MOD を右クリックすると、次の項目が表示されます。一部の項目はゲームや MOD によって表示されません。

| セクション | 項目 |
|---|---|
| （上部） | `GameBananaで表示` |
| `プレビュー` | `プレビュービューアーで開く`、`貼り付け`、`プレビューを削除`（[プレビュー](/ja/features/mod-manager/previews)） |
| `修正` | `プリセット`、`修正ツール`、Wuwa Mod Fixer、ZZMI Mod Fixer（[MOD ツール](/ja/features/mod-manager/mod-tools#fix)） |
| `MOD` | `CMDを開く`、`フォルダーを開く`、`サブグループとして指定`、`名前を変更` |
| `ツール` | `Nahida Agent`、`モデルビューアー`、`トグルプリセット`、その他の [MOD ツール](/ja/features/mod-manager/mod-tools) |
| （下部） | `削除`: MOD をごみ箱に移動します。 |
