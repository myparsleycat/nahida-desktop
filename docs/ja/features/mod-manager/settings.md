# MOD 設定

設定 → MOD で MODマネージャーの動作を指定します。

## MOD管理

| 設定 | 既定値 | 説明 |
|---|---|---|
| `解凍パス方式` | `最上位フォルダーを除去` | 最上位フォルダーが 1 つだけのアーカイブの解凍方法です。 |
| `解凍後に削除` | オン | アーカイブを MOD フォルダーに解凍した後、元のアーカイブを削除します。 |
| `コピーの代わりに移動` | オン | フォルダーを MOD フォルダーにドロップするとき、コピーせずに移動します。 |
| `MODに必要な修正を自動検査` | オン | ダウンロードまたは追加した MOD に修正が必要かを検査し、通知します。 |
| `有効化時にShaderFixesをコピー` | オン | MOD を有効化するとき、MOD 内の ShaderFixes ファイルをインポーターの ShaderFixes フォルダーにコピーします。 |
| `無効化MOD接頭辞の形式` | `DISABLED (スペース)` | MOD を無効化するときにフォルダー名の前に付ける接頭辞です。有効化時は両方の形式を認識します。 |
| `サブフォルダーからMODプレビューを検索` | オフ | サイドバーのフォルダーにプレビューがない場合、フォルダー内の MOD フォルダーからプレビューを探します。 |
| `トグルプリセットの保存先` | `未選択` | [トグルプリセット](/ja/features/mod-manager/presets#toggle-presets) の保存先です。変更すると既存のプリセットを移動します。 |
| `ダウンロード先フォルダーを自動選択` | オフ | ダウンロード名に似た名前の MOD フォルダーを自動的に選択します。適用するダウンロード元（`GameBanana`、`Nahida Live`、`Hui`、`ドライブ`）を選択でき、既定値は `GameBanana` です。 |

`解凍パス方式` のオプションは次のとおりです。

- `最上位フォルダーを除去`: 最上位フォルダーを除去して中身を解凍します。例: `mod.zip/a/b/mod.ini` → `b/mod.ini`
- `アーカイブ内のパスを維持`: アーカイブ内のパスをそのまま維持します。例: `mod.zip/a/b/mod.ini` → `a/b/mod.ini`
- `毎回確認`: MOD を追加するたびに `解凍パスを選択` ダイアログで選択します。

## レイアウト {#layout}

| 設定 | 既定値 | 説明 |
|---|---|---|
| `サイドバーレイアウト` | `行リスト` | サイドバーを `行リスト` または正方形の `プレビューグリッド` で表示します。 |
| `プレビューがないMODにモデルプレビューを表示` | オン | グリッド表示で画像や動画がない MOD に、現在のトグル状態のモデル画像を表示します。 |
| `MODグリッドレイアウト` | `レスポンシブ` | グリッド表示のカード幅と列数を決める方法です。 |

`MODグリッドレイアウト` のオプションは次のとおりです。

- `レスポンシブ`: `レスポンシブ基準カード幅`（240〜640、既定値 400）を基準に、画面の幅に収まる列数を計算します。
- `カード幅固定`: カード幅（240〜640、既定値 360）を固定し、列数だけを変更します。
- `列数固定`: 可能な場合は指定した列数（1〜8、既定値 4）を使用します。

## MOD圧縮

MOD ファイルを圧縮してディスク容量を節約します。`MOD圧縮を有効化` スイッチでオン/オフを切り替え、進行状況も表示されます。

- `圧縮方式`: 既定値は `XPRESS4K` です。
  - `Zstd`: 無効化した MOD の大きなファイルだけを圧縮します。MOD を有効にすると、先に元のファイルへ戻します。
  - `XPRESS4K`: Windows のファイル圧縮機能ですべての MOD ファイルを圧縮します。圧縮したままでも MOD を使用できます。
- `圧縮サイズのしきい値`: `Zstd` で圧縮するファイルの最小サイズです。範囲は 1〜64 MiB で、既定値は 1 MiB です。
