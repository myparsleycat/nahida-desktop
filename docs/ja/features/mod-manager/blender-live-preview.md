# Blender ライブプレビュー

Blender ライブプレビューは、Blender で編集中の XXMI MOD を、エクスポートせずに編集内容のとおり [モデルビューアー](/ja/features/mod-manager/model-viewer) に表示します。原神 (GIMI)、崩壊：スターレイル (SRMI)、ゼンレスゾーンゼロ (ZZMI) の MOD に対応しています。

ツール画面で `Blender ライブプレビュー (ベータ)` を選択して開きます。

::: info
Blender 3.6 以降と Nahida Live Link アドオンが必要です。
:::

## アドオンのインストール

`アドオン(同梱バージョン X)` には、PC で見つかった Blender 3.6 以降のインストール一覧と、各 Blender のアドオンの状態が表示されます。一覧が最新でない場合は `再読み込み` を押します。

- `インストール`、`更新`、`再インストール`: アプリに同梱されたバージョンのアドオンをインストールし、Blender で有効にします。インストールに成功すると、Blender ライブプレビューがオンになります。
- `削除`: アドオンを削除します。

次の場合はインストールできません。

- そのバージョンの Blender が実行中の場合: Blender を終了してから再試行します。
- 別の場所にアドオンがインストールされている場合: 先に Blender でそのアドオンを削除します。
- アドオンのフォルダーが別のフォルダーにリンクされている場合: リンク先で更新します。

Blender の実行ファイルが見つからない場合は、アドオンのファイルだけがインストールされます。Blender の 編集 > プリファレンス > アドオン で Nahida Live Link を有効にしてください。

## 接続

1. 画面上部のスイッチで Blender ライブプレビューをオンにします。
2. Blender で Nahida Live Link アドオンが有効になっていると、`接続中の Blender` の一覧に Blender が表示されます。
3. 接続中の Blender で次の項目を設定し、`モデルビューアーで開く` をクリックします。
   - `ゲーム`: MOD のゲームを選択します。シーンからゲームがわかる場合は自動的に設定されます。
   - `ゲームモーションに使うキャラクター`: [キャラクターデータ](/ja/features/mod-manager/character-data) に使うキャラクターを選択します。オブジェクト名からキャラクターを推定してあらかじめ選択します。

接続中のアドオンがアプリに同梱されたバージョンより古い場合は、警告と更新ボタンが表示されます。

## リアルタイム反映

モデルビューアーを開いている間、Blender で編集したメッシュとテクスチャがすぐにビューアーに反映されます。オブジェクトを追加するなど構造が変わった場合は、シーンを再読み込みします。
