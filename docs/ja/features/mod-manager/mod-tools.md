# MOD ツール

MOD ツールは、1 つの MOD または選択した MOD を対象に動作します。ほとんどは MOD メニューの `ツール` セクション、またはグリッド表示のカードの `MOD ツール` ボタンから開きます。異環のゲームでは、`ツール` セクションに `Nahida Agent` のみが表示されます。

## ツール一覧

| ツール | 対象ゲーム | 説明 |
|---|---|---|
| `Nahida Agent` | すべて | 選択した MOD を対象に Nahida Agent を開きます。 |
| [`モデルビューアー`](/ja/features/mod-manager/model-viewer) | 異環以外 | MOD の 3D モデルとトグル状態を表示します。カードでは `モデルビューアーで開く` ボタンで開きます。 |
| `テクスチャ リサイザー` | すべて | MOD の DDS テクスチャのサイズを変更し、元のファイルに保存します。 |
| `XXMI メニューメーカー` | すべて | MOD のトグルからゲーム内メニューを生成します。ツール画面で開きます。 |
| `体型変更 (ベータ)` | すべて | 塗った領域やボーンウェイトを基準に MOD のメッシュを調整します。 |
| `タッチプロファイル (ベータ)` | すべて | タッチ領域を設定し、タッチに反応する MOD に変換します。 |
| `Vulkan アウトライン補正` | EFMI | [Vulkan アウトライン補正](#vulkan-outline-fix) を参照してください。 |
| `液体噴射ポイント (ベータ)` | EFMI、GIMI、SRMI、WWMI、ZZMI | MOD のメッシュに液体噴射ポイントを設定し、INI に組み込みます。 |
| `競合する MOD を探す` | すべて | [競合する MOD を探す](#find-conflict) を参照してください。 |
| [`トグルプリセット`](/ja/features/mod-manager/presets#toggle-presets) | 異環以外 | MOD メニューにのみ表示されます。 |

## MODを結合 (ベータ) {#merge}

複数の MOD を 1 つの MOD にまとめ、ゲーム内でキーを使って切り替えられるようにします。GIMI、SRMI、ZZMI、HIMI、WWMI、EFMI のゲームで使用できます。

1. MOD リスト上部の `その他` メニューで `MODを結合 (ベータ)` を選択します。
2. 結合する MOD を 2 つ以上クリックして選択し、`次へ` をクリックします。`結合をキャンセル` または `Esc` で結合モードを終了します。
3. `MODを結合` ダイアログで次の項目を設定し、`結合` をクリックします。
   - `名前`: 結合した MOD の名前です。
   - `次へキー` / `戻るキー`: ゲーム内で MOD を切り替えるキーです。
   - `保存先`: `現在の場所` または `新しいフォルダー` を選択します。
   - `結合方式`: `通常` または `ネームスペース` を選択します。通常結合を使用できない MOD が含まれている場合は、`ネームスペース` のみ選択できます。
   - `バニラスロットを含める`: MOD を適用していない状態を切り替え対象に追加します。`ネームスペース` 方式でのみ使用できます。
   - MOD 一覧: 上下のボタンで切り替えの順番を変更します。`次のMODとグループ化` を押すと、その MOD と次の MOD を 1 つのサブグループにまとめ、`グループ解除` を押すとサブグループを解除します。

## 競合する MOD を探す {#find-conflict}

選択した MOD を有効にしたまま、他の MOD を半分ずつ無効化して、この MOD と競合する MOD を特定します。MOD が無効になっている場合は、先に有効にしてください。

## 修正 {#fix}

MOD メニューの `修正` セクション、またはカードの `MOD ツール` メニューから修正ツールを実行します。実行結果はログダイアログに表示され、入力が必要なツールはログダイアログの下部で入力します。

- `プリセット`、`修正ツール`: ツール画面の Fix Tool Manager に登録したプリセットと修正スクリプトを MOD に実行します。Python 修正ツールの実行には Python が必要です。
- **Wuwa Mod Fixer**: WWMI のゲームと、インポーターが `なし` のゲームで表示されます。初回実行時にインストールし、新しいバージョンがあると更新を案内します。`MOD 修正` タブでオプションを選んで実行し、`ロールバック` タブでバックアップに戻します。
- **ZZMI Mod Fixer**: ZZMI のゲームで表示されます。`Hash Fix`、`Jane Remap`、`Dialyn Remap`、`ロールバック` タブがあります。

Wuwa Mod Fixer と ZZMI Mod Fixer は、サイドバーのフォルダーメニューの `ツール` や、MOD リスト上部の `その他` メニューの `ツール` からフォルダー全体に実行することもできます。

[MOD 設定](/ja/features/mod-manager/settings) の `MODに必要な修正を自動検査` が有効な場合、ダウンロードまたは追加した MOD に修正が必要なときに通知が表示されます。通知の `Fixerを開く` を選択すると、対応する Fixer が開きます。

## Vulkan アウトライン補正 {#vulkan-outline-fix}

アークナイツ：エンドフィールド (EFMI) の MOD 専用です。Vulkan では、MOD の一部のパーツがアウトラインパスでもう一度描画され、不透明に見えます。このツールは INI ファイルごとに該当するパーツを表示し、アウトラインパスから外すパーツを選んで適用します。

- `元に戻す`: 元のファイルに戻します。
- 適用後にファイルを手動で編集した場合は `手動で編集済み` と表示されます。再適用や元に戻すには `現在のファイルを元にする` を選択します。

適用したら、ゲーム内で `F10` を押して MOD を再読み込みします。

## キャラクターを設定 {#set-character}

サイドバーのフォルダーにキャラクターを設定すると、そのフォルダーとサブフォルダーの MOD は [モデルビューアー](/ja/features/mod-manager/model-viewer) でそのキャラクターのトゥーンスタイル、モーション、元データを使用します。詳しくは [キャラクターデータ](/ja/features/mod-manager/character-data) を参照してください。

1. サイドバーでフォルダーを右クリックし、`キャラクターを設定…` を選択します。
2. `ゲーム` と `キャラクター` を選択し、`保存` をクリックします。

設定を解除するには、同じダイアログで `クリア` をクリックします。

## その他の MOD メニュー項目

- `名前を変更`: MOD フォルダーの名前を変更します。
- `CMDを開く`: MOD フォルダーでコマンドプロンプトを開きます。
- `GameBananaで表示`: GameBanana からダウンロードした MOD の GameBanana ページを開きます。
