# モデルビューアー

モデルビューアーでは、ゲームを起動せずに MOD のモデル、テクスチャ、トグル状態を確認できます。

::: warning
一部の MOD はビューアーで開けなかったり、モデルやテクスチャが正しく表示されなかったりする場合があります。
:::

## 対応ゲーム

- `原神`（GIMI）
- `崩壊：スターレイル`（SRMI）
- `ゼンレスゾーンゼロ`（ZZMI）
- `鳴潮`（WWMI）
- `アークナイツ：エンドフィールド`（EFMI）

## モデルビューアーを開く

MODマネージャーで MOD を右クリックして `モデルビューアー` を選択するか、グリッドレイアウトの MOD カードにある `モデルビューアーで開く` ボタン（キューブのアイコン）をクリックします。

## メニューバー

- **モデル**: モデルを回転し、モデルまたはカメラをリセットします。
- **テクスチャ**: `両面表示` は各ポリゴンの両面を描画します。
- **レンダリング**: トーンマッピング、環境、露出を変更し、法線マップのオン/オフを切り替えます。対応ゲームでは、`トゥーンシャドウ` とゲームごとのトゥーンスタイルのサブメニューで、輪郭線やセルフシャドウを含むトゥーンシェーディングを変更できます。
- **トグル**: トグルがある MOD で表示されます。
  - `INI に保存`: 現在のトグル値を MOD の INI ファイルに書き込みます。
  - `リセット`: INI ファイルのデフォルト値に戻します。
  - `プリセットとして保存` / `プリセットを適用`: 現在の値を [トグルプリセット](/ja/features/mod-manager/#toggle-presets) として保存するか、保存済みのプリセットを適用します。
  - `ホバーした値をゲームでプレビュー`: カーソルを合わせた値を実行中のゲームに表示します。
  - `ビューアーにオーバーレイを表示`: MOD のゲーム内トグルオーバーレイをビューアー内に表示します。ドラッグで移動でき、`Ctrl` + マウスホイールまたは右下隅のドラッグでサイズを変更できます。
- **その他**:
  - `キャプチャしてプレビューに設定`: ビューポートを正方形の `preview.png` として MOD フォルダーに保存します。MOD にすでにプレビューがある場合は、置き換える前に確認メッセージが表示されます。

## ゲーム連携

MOD の Importer が内蔵ランチャーと myparsleycat の XXMI ライブラリを使用している場合、`プリセットとして保存`、`プリセットを適用`、`ホバーした値をゲームでプレビュー` を利用できます。そのゲームの実行中は、トグルビューアー上部の `ゲームに適用` で現在の値をゲームに適用します。

## トグルビューアー

トグルがある MOD では、右側のトグルビューアーに各トグルが一覧表示されます。値を変更すると、その状態でモデルが再描画されます。スプリッターをドラッグするとパネルのサイズを変更でき、クリックするとパネルの表示/非表示を切り替えられます。

テクスチャのみを変更する値や、ビューアーが描画しないエフェクトのみを変更する値には `ビューアーに表示されない` と表示されます。これらの値もプリセットには保存されます。

## アニメーション再生

MOD にアニメーションが含まれている場合、ビューアーの下部に再生バーが表示されます。再生バーでは、アニメーションの再生と一時停止、クリップの選択、再生速度の変更、フレームの移動ができます。
