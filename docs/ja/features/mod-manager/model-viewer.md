# モデルビューアー

モデルビューアーでは、ゲームを起動せずに MOD のモデル、テクスチャ、トグル状態を確認できます。

::: warning
一部の MOD はビューアーで開けない場合や、モデルやテクスチャが正しく表示されない場合があります。
:::

## 対応ゲーム

- 原神 (GIMI)
- 崩壊：スターレイル (SRMI)
- ゼンレスゾーンゼロ (ZZMI)
- 鳴潮 (WWMI、RabbitFX)
- アークナイツ：エンドフィールド (EFMI)

異環の MOD には対応していません。

## モデルビューアーを開く

- MOD を右クリックし、`ツール` セクションの `モデルビューアー` を選択します。
- グリッド表示の MOD カードで `モデルビューアーで開く` ボタン（立方体アイコン）をクリックします。
- グリッド表示の [モデルプレビュー](/ja/features/mod-manager/previews#model-preview) を右クリックし、`モデルビューアーで開く` を選択します。
- Windows のエクスプローラーで MOD フォルダーを右クリックし、`モデルビューアーで開く` を選択します。インストール版でのみ表示され、モデルビューアーが別ウィンドウで開きます。
- [Blender ライブプレビュー](/ja/features/mod-manager/blender-live-preview) で `モデルビューアーで開く` を選択します。

## 操作

- **回転**: マウスの左ボタンでドラッグします。
- **移動**: マウスの右ボタンまたは中ボタンでドラッグするか、`Shift` を押しながら左ボタンでドラッグします。
- **拡大・縮小**: マウスホイールを使います。
- **軸方向から表示**: ビューポート右上の軸表示で軸の端をクリックすると、その軸方向からモデルを表示します。
- **フォーム**: フォームが複数ある MOD では、ビューポート左上に `フォーム` 一覧が表示されます。フォームを選択するとそのフォームだけを表示し、`すべて` を選択するとすべてのフォームを表示します。

## メニューバー

### モデル

- `回転`: `左に 90°`、`右に 90°`、`上に 90°`、`下に 90°`、`180° 反転` でモデルを回転します。
- `リセット`: モデルの回転とカメラを最初の状態に戻します。
- `キャラクターを設定…`: 現在の MOD にキャラクターを設定します。`MOD の設定を解除` を選ぶと、フォルダーに設定されたキャラクターに戻ります。
- `キャラクターモーション`、`ゲームの元データ`、`不足しているパーツ`、`表情`: 設定されたキャラクターとモデルが対応している項目が表示されます。[キャラクターデータ](/ja/features/mod-manager/character-data) を参照してください。

### テクスチャ

- `両面表示`: 各ポリゴンの両面を描画します。

### レンダリング

- `トーンマッピング`: `ニュートラル`、`ACES Filmic`、`なし` から選択します。
- `環境光`: `スタジオ`、`ソフト`、`なし` から選択します。
- `露出`: `-0.1`、`+0.1` ボタンまたは入力欄で露出を 0〜4 の範囲で変更します。`リセット` で既定値に戻します。
- `トゥーンシャドウ`: トゥーンシェーディングのオン/オフを切り替えます。
- トゥーンスタイルのサブメニュー: ゲームに応じて `原神トゥーンスタイル`、`スターレイル トゥーンスタイル`、`ゼンレスゾーンゼロ トゥーンスタイル`、`鳴潮 トゥーンスタイル`、`トゥーンスタイル`（エンドフィールド）と表示されます。[トゥーンスタイル](#toon-style) を参照してください。
- `法線マップ`: 法線マップがある MOD で法線マップのオン/オフを切り替えます。

### トグル

トグルがある MOD で表示されます。

- `INI に保存`: 現在のトグル値を MOD の INI ファイルに書き込みます。MOD を読み込んだゲームが実行中でアプリと接続されている場合は、ゲームにも適用します。
- `リセット`: INI ファイルの既定値に戻します。
- `プリセットとして保存` / `プリセットを適用`: 現在の値を [トグルプリセット](/ja/features/mod-manager/presets#toggle-presets) として保存するか、保存済みのプリセットを適用します。プリセットを適用すると INI ファイルに書き込み、接続中のゲームにも適用します。
- `ホバーした値をゲームでプレビュー`: トグルビューアーでマウスを合わせた値を実行中のゲームに表示します。
- `ビューアーにオーバーレイを表示`: MOD のゲーム内トグルオーバーレイをビューアー内に表示します。オフにすると、オーバーレイはトグルビューアーの上部に表示されます。
- `オーバーレイの位置とサイズをリセット`: ビューアー内のオーバーレイの位置とサイズを最初の状態に戻します。

ビューアー内のオーバーレイはドラッグで移動し、`Ctrl` + マウスホイールまたは右下の角でサイズを変更します。

### その他

- `キャプチャしてプレビューに設定`: ビューポートの中央を透明背景の正方形の `preview.png` として MOD フォルダーに保存します。MOD にすでにプレビューがある場合は、置き換える前に確認メッセージが表示されます。
- `PNG で保存`: 現在の表示を、ビューポートサイズの 1 倍、2 倍、または 4 倍の解像度で透明背景の PNG ファイルとして保存します。サブメニューの各項目に保存されるサイズが表示され、保存先は保存ダイアログで指定します。

## トゥーンスタイル {#toon-style}

`レンダリング` メニューのトゥーンスタイルのサブメニューで、次の項目を変更します。

- `アウトライン`、`セルフシャドウ`、`ライトをカメラに追従`
- `顔のフラットシェーディング`: エンドフィールドでのみ表示されます。
- `シェーディング`: `影のしきい値`、`影の明るさ`、`アウトラインの色` などのゲームごとのシェーディング値を調整します。`シェーディングをリセット` で既定値に戻します。
- 原神では次の項目も表示されます。
  - `原神テクスチャフォルダー...`: 原神のトゥーンテクスチャがあるフォルダーを指定します。`テクスチャフォルダーを解除` で指定を解除します。
  - `影ランプ`: `自動`、`内蔵`、またはテクスチャフォルダー内のランプから選択します。
  - `顔の影マップ`: 顔が表示される場合に `自動`、`少年`、`少女`、`成女`、`ロリ`、`成男` から選択します。

キャラクターが設定された MOD はそのキャラクターのトゥーンスタイルを使用し、変更した値もキャラクターごとに保存されます。それ以外の MOD はゲームごとに保存されます。[キャラクターデータ](/ja/features/mod-manager/character-data#toon-style) を参照してください。

## トグルビューアー

トグルがある MOD では、右側のトグルビューアーに各トグルが表示されます。値を変更するとその状態に合わせてモデルが再描画され、値にマウスを合わせるとその値を適用したモデルをプレビューします。

- 現在の組み合わせで効果がない値は無効になります。値にマウスを合わせると一緒に変更する必要がある変数が表示され、`この組み合わせを適用` で必要な変数をまとめて変更します。
- ビューアーが描画しないテクスチャやエフェクトだけを変更する値は `ビューアーに表示されない` に表示されます。これらの値もプリセットには保存されます。
- 区切り線をドラッグしてパネルのサイズを変更するか、クリックしてパネルの表示と非表示を切り替えます。区切り線にフォーカスがあるときは、`Enter` または `Space` で表示と非表示を切り替え、`←`/`→` でサイズを変更します。

## 再生コントローラー {#playback}

MOD にアニメーションがある場合や [キャラクターモーション](/ja/features/mod-manager/character-data#character-motion) を再生している場合、ビューポート下部に再生コントローラーが表示されます。キャラクターデータのダウンロード状態と [テクスチャの選択](#texture-choice) 項目もこのコントローラーに表示されます。

- MOD のアニメーションとキャラクターモーションはそれぞれ別の行に表示されます。各行で `再生`/`一時停止`、クリップの選択、`先頭へ`、`末尾へ`、再生速度（0.25×〜2×）を操作します。
- フレームスライダーをドラッグして目的のフレームに移動します。スライダーにフォーカスがあるときは、`←`/`→` で 1 フレームずつ、`Home`/`End` で先頭と末尾に移動します。
- 再生速度メニューの `フレーム補間` をオンにすると、フレーム間を補間して滑らかに再生します。
- コントローラー左側のつまみ（`コントローラーを移動`）をドラッグしてコントローラーを移動します。つまみをダブルクリックするか、つまみにフォーカスがあるときに `Home` を押すと、元の位置に戻ります。

## テクスチャの選択 {#texture-choice}

INI がテクスチャをハッシュで置き換える MOD では、一部の部位がどのテクスチャを使うか特定できず、その部位はゲーム本来のテクスチャで表示されます。このような部位があると、再生コントローラーに `ゲーム本来のテクスチャを使う部位 N 個` と表示されます。

これをクリックすると、次の項目が表示されます。

- `強調表示`: ゲーム本来のテクスチャを使う部位を強調します。
- `テクスチャの選択`: 部位ごとに `ゲーム本来のテクスチャ` または同じモデルの別の部位のテクスチャを選択します。選択は MOD フォルダーの `nhd.json` に保存され、グリッド表示のモデルプレビューにも使われます。

## ゲーム連携

MOD のインポーターが内蔵ランチャーと myparsleycat の XXMI ライブラリを使用している場合、`プリセットとして保存`、`プリセットを適用`、`ホバーした値をゲームでプレビュー` を使用できます。その MOD を読み込んだゲームが実行中の場合は、トグルビューアー上部の `ゲームに適用` で現在の値をゲームに適用します。
