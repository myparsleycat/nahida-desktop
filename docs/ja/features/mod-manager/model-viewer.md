# モデルビューア

![画像](/features/mod-manager/model-viewer/0.png)

モデルビューアを使うと、ゲームを起動しなくても MOD のモデル、テクスチャ、トグル状態を事前に確認できます。

::: warning
この機能はまだ開発中です。一部の MOD はビューアで開けなかったり、モデルやテクスチャが正しく表示されなかったりする場合があります。
:::

## 対応ゲーム

現在、次のゲームの MOD に対応しています。

- `原神`
- `崩壊：スターレイル`
- `ゼンレスゾーンゼロ`
- `鳴潮`

::: info
`鳴潮` は、ほかのゲームと比べて正しく表示されない MOD がやや多めです。
:::

## アセットパスの設定

`原神`、`崩壊：スターレイル`、`ゼンレスゾーンゼロ` のような HoYoverse 系ゲームの MOD をモデルビューアで開くには、先にアセットパスを設定する必要があります。

アセットの準備方法とパスの設定方法については、[静的 GLB 変換](/ja/features/mod-tools/static-glb-converter) の [アセット](/ja/features/mod-tools/static-glb-converter#アセット) を参照してください。

## モデルビューアを開く

![画像](/features/mod-manager/model-viewer/1.png)
カードレイアウトでは、MOD カードのヘッダーにあるモデルビューアボタンを押すとビューアを開けます。

![画像](/features/mod-manager/model-viewer/2.png)
リストレイアウトでは、MOD を右クリックして `モデルビューア` メニューを選択します。

## 上部メニューバー

- **モデル**: モデルの回転、モデルのリセット、カメラのリセットなどの基本操作を行えます。
- **テクスチャ**: テクスチャに関する表示オプションを変更します。
  - `Double Sided`: ポリゴンの表面と裏面の両方を描画します。
- **レンダリング**: レンダリング方式を切り替え、別の見え方でモデルの状態を確認できます。
- **トグル**: 現在のトグル状態を保存または初期化します。
  - `INI に保存`: トグルビューアで選択した現在の状態を INI に反映します。
  - `初期化`: トグル状態を INI のデフォルト値に戻します。
- **その他**: 現在の MOD に対する追加操作を行えます。
  - `キャプチャしてプレビューに設定`: 現在表示されているビューア画面を中央基準の 1:1 正方形 PNG としてキャプチャし、現在の MOD フォルダに `preview.png` として保存します。

## ビューアからプレビューをキャプチャする

現在のビューア画面を MOD のプレビューに使いたい場合は、`その他` → `キャプチャしてプレビューに設定` を選択します。

キャプチャに含まれるのはアクティブな 3D ビューア領域のみです。メニューバーや右側のトグルパネルは画像に含まれません。

MOD に既に `preview.*` ファイルがある場合は、新しい `preview.png` に置き換える前に確認メッセージが表示されます。

## 右側のトグルビューア

トグルを含む MOD は、右側のトグルビューアで状態を直接切り替えられます。値を変更すると、その状態に合わせてモデルが再描画されます。

![画像](/features/mod-manager/model-viewer/3.png)
ゲーム内トグルビューアを使う MOD であれば、関連する UI アセットも一緒に表示されることがあります。

![画像](/features/mod-manager/model-viewer/4.gif)
スライダーを使う MOD であれば、トグルビューアにも操作可能なスライダーが表示されます。

## アニメーション再生

MOD にアニメーションが含まれている場合、ビューアの下部にアニメーション再生パネルが表示されます。

再生コントロールを使用してアニメーションを再生、一時停止、またはリセットでき、スライダーをドラッグして特定のフレームに移動できます。
