# キャラクターデータ

モデルビューアーは、MOD に設定されたキャラクターのゲームデータを使って次の機能を提供します。

- **キャラクターモーション**: ゲームのキャラクターモーションを MOD で再生します。
- **ゲームの元データ**: MOD に含まれていない顔、髪、テクスチャをゲームの元データで補います。
- **表情**: 元の顔に表情とまばたきを適用します。
- **キャラクター別のトゥーンスタイル**: キャラクターの素材の値でトゥーンシェーディングを表示します。

対応ゲームは、原神 (GIMI)、崩壊：スターレイル (SRMI)、ゼンレスゾーンゼロ (ZZMI)、鳴潮 (WWMI)、アークナイツ：エンドフィールド (EFMI) です。データが提供されているキャラクターでのみ使用できます。

## キャラクターを設定

モデルビューアーで `モデル` → `キャラクターを設定…` を開き、ゲームとキャラクターを選択して `保存` をクリックします。設定は現在の MOD フォルダーの `nhd.json` に保存され、MOD を開き直したときにも適用されます。`MOD の設定を解除` を選ぶと、フォルダーに設定されたキャラクターに戻ります。

フォルダー内の MOD に適用する既定のキャラクターを設定するには、次の手順を行います。

1. MODマネージャーのサイドバーでフォルダーを右クリックし、`キャラクターを設定…` を選択します。
2. `ゲーム` と `キャラクター` を選択し、`保存` をクリックします。

MOD にキャラクターが個別に設定されていない場合は、最も近い上位フォルダーに設定されたキャラクターを使用します。[Blender ライブプレビュー](/ja/features/mod-manager/blender-live-preview) では、接続一覧でキャラクターを選択します。

## ダウンロード

キャラクターデータは初めて使うときに nahida.live のサーバーからダウンロードされ、以降は保存済みのファイルを使用します。ダウンロード中は [再生コントローラー](/ja/features/mod-manager/model-viewer#playback) に進行状況が表示されます。

## キャラクターモーション {#character-motion}

`モデル` メニューの `キャラクターモーション` をオンにすると、キャラクターのゲームモーションを MOD で再生します。設定されたキャラクターにモーションデータがあり、MOD のメッシュにボーンウェイトがある場合に表示され、既定でオンになっています。

- モーションは再生コントローラーの別の行に表示され、待機モーションのクリップから再生します。クリップメニューで別のクリップを選択すると、現在の姿勢から滑らかに切り替わります。
- MOD 自体にアニメーションがある場合は、MOD のアニメーションと一緒に再生されます。
- モーションの行の `キャラクターモーションをオフ` ボタンを押すと、現在のビューアーでのみモーションをオフにします。

## ゲームの元データ {#original-data}

`モデル` メニューの `ゲームの元データ` をオンにすると、ゲームの元データを MOD と一緒に表示します。設定されたキャラクターに元データがある場合に表示され、既定でオンになっています。

- MOD がゲームに任せている顔と頭の部位を元のモデルで表示します。MOD に顔のテクスチャがある場合は、元の顔に適用します。
- MOD のメッシュの空いているテクスチャスロットを元のテクスチャで補います。
- `不足しているパーツ` サブメニューで、MOD にない元の部位を個別に表示または非表示にします。ゲームが描画し続ける髪の部位は最初から表示されます。

## 表情 {#expression}

ゲームの元データがオンで、表示中の部位に表情データがある場合、`モデル` メニューに `表情` サブメニューが表示されます。

- `デフォルト`、`笑顔`、`怒り`、`困り顔`、`驚き`、`ウインク`、`目を閉じる` から表情を選択します。表示中の部位に適用できる表情だけが表示されます。
- `まばたき`: 自動のまばたきをオン/オフします。

キャラクターモーションのクリップに表情が含まれている場合は、クリップの表情を再生します。`表情` で `デフォルト` 以外の表情を選択すると、選択した表情が優先されます。

## キャラクター別のトゥーンスタイル {#toon-style}

キャラクターが設定された MOD では、[トゥーンスタイル](/ja/features/mod-manager/model-viewer#toon-style) のサブメニュー上部に `{キャラクター名}のスタイル` が表示され、キャラクターの素材の値でトゥーンシェーディングを表示します。

- `シェーディング` サブメニューでは、キャラクターの素材から取得した値に `キャラクター素材` と表示されます。
- 原神では、`影ランプ` の `自動（{キャラクター名}）` がそのキャラクターのランプを使用します。
- トゥーンスタイルで変更した値はキャラクターごとに保存されます。`ライトをカメラに追従` と原神のテクスチャフォルダーはゲームごとに保存されます。
- `キャラクタースタイルをリセット` を押すと、そのキャラクターに保存した値をリセットします。
