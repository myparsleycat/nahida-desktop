# 설정

내비게이션 레일 아래쪽의 `설정`을 엽니다. 섹션 목록은 왼쪽에 있으며, 목록 아래에 앱 버전과 `업데이트 확인`이 표시됩니다.

대부분의 설정은 변경하는 즉시 저장됩니다. 프록시, GitHub 토큰, 나히다 에이전트 설정은 각각의 `저장` 버튼으로 저장합니다.

`모드` 섹션은 [모드 설정](/ko/features/mod-manager/settings)에서 설명합니다. XXMI 설정은 XXMI 페이지에 있으며, [XXMI 연결하기](/ko/others/set-up-xxmi)를 참고하세요.

## 일반 {#general}

### 애플리케이션

| 설정 | 기본값 | 설명 |
|---|---|---|
| `로그인할 때 실행` | 꺼짐 | Windows에 로그인하면 앱을 시작합니다. 설치 버전에서만 표시됩니다. |
| `권한 상승 헬퍼` | 꺼짐 | 관리자 권한이 필요한 작업을 처리하는 별도의 헬퍼를 관리자 권한으로 시작합니다. 앱을 시작할 때 Windows UAC 확인 창이 표시됩니다. |
| `백그라운드 실행` | 켜짐 | 모든 창을 닫아도 앱을 백그라운드에서 계속 실행합니다. |
| `타이틀바 작업 배지 클릭으로 이동` | 켜짐 | 타이틀바의 작업 배지를 클릭하면 관련 페이지를 엽니다. 끄면 배지를 잡고 창을 이동할 수 있습니다. |
| `Mica 배경 효과` | 켜짐 | 창 배경에 Windows Mica 효과를 사용합니다. 변경하면 창을 다시 엽니다. Windows가 Mica를 지원할 때만 표시됩니다. |
| `블러 효과` | 켜짐 | 메뉴, 다이얼로그, 알림, 오버레이 뒤의 내용을 흐리게 표시합니다. 화면이 느리면 끄세요. |
| `언어` | Windows 언어 | `한국어`, `English`, `日本語`, `中文` 중에서 선택합니다. 기본값은 Windows 표시 언어가 이 중 하나이면 그 언어이고, 그 외에는 영어입니다. |
| `테마` | `시스템 기본값` | `시스템 기본값`, `밝게`, `어둡게` 중에서 선택합니다. |
| `시작 페이지` | `모드 매니저` | 앱을 시작할 때 표시할 페이지입니다. `전송`, `GameBanana`, `모드 매니저`, `드라이브`, `공유 드라이브` 중에서 선택합니다. `드라이브`와 `공유 드라이브`는 nahida.live 로그인이 필요합니다. |
| `로그 수준` | `Warn` | 로그에 기록할 최저 수준입니다. `Trace`, `Debug`, `Info`, `Warn`, `Error`, `Fatal` 중에서 선택합니다. |

[토글 영구 저장](/ko/features/mod-tools/persist-toggles)과 Toggle Viewer 생성기의 `Toggle Viewer 자동 생성`은 앱이 계속 실행되어야 합니다. 둘 중 하나를 켜면 `백그라운드 실행`도 켜지며, 둘 중 하나가 켜진 상태에서 `백그라운드 실행`을 끄면 확인 창이 표시됩니다.

### 정렬

| 설정 | 기본값 | 설명 |
|---|---|---|
| `이름 정렬 정책` | `자연 정렬 + 공백 무시` | 목록을 이름순으로 정렬할 때 공백과 숫자를 처리하는 방식입니다. 드라이브, 모드 사이드바와 모드 목록, 프리셋, Fix Tool 등 이름순으로 정렬하는 모든 목록에 적용됩니다. |

- `자연 정렬 + 공백 무시`: 숫자를 값으로 비교하고, 공백을 뺀 이름으로 먼저 비교합니다.
- `기본 자연 정렬`: 숫자를 값으로 비교합니다.

### 업데이트

| 설정 | 기본값 | 설명 |
|---|---|---|
| `자동 업데이트` | `자동 업데이트` | 앱 업데이트 처리 방식입니다. |
| `사전 릴리스 포함` | 꺼짐 | GitHub 사전 릴리스도 앱 업데이트로 제공합니다. 초안 릴리스는 제외됩니다. |
| `업데이트 상태` | | 현재 업데이트 상태를 표시합니다. 업데이트가 있거나 다운로드되면 `업데이트 다운로드` 또는 `업데이트 설치`가 표시됩니다. |

`자동 업데이트`의 옵션은 다음과 같습니다.

- `자동 업데이트`: 시작할 때와 1시간마다 업데이트를 확인하고 자동으로 다운로드합니다.
- `업데이트 알림`: 업데이트를 자동으로 확인하고, 다운로드는 사용자가 선택할 때만 합니다.
- `자동 업데이트 끔`: 업데이트를 자동으로 확인하거나 다운로드하지 않습니다.

섹션 목록 아래의 `업데이트 확인`을 누르면 즉시 확인합니다.

## 네트워크 {#network}

### 프록시

앱이 보내는 모든 외부 요청을 프록시로 보냅니다. 끄면 Windows 시스템 프록시 설정을 따릅니다. 앱이 실행한 브라우저, 게임, 스크립트에는 적용되지 않습니다.

| 설정 | 설명 |
|---|---|
| `프록시 사용` | 프록시를 켜거나 끕니다. |
| `유형` | `HTTP`, `SOCKS5`, `SOCKS5h` 중에서 선택합니다. `SOCKS5`는 대상 이름을 로컬에서 확인하고, `SOCKS5h`는 프록시에서 확인합니다. |
| `호스트 (스킴 제외)` | 스킴, 경로, 포트를 제외한 프록시 호스트입니다. |
| `포트` | 1부터 65535까지의 정수입니다. |
| `사용자 이름 (선택)` | 비밀번호를 설정하면 필요합니다. |
| `비밀번호 (선택)` | `비밀번호 삭제`는 저장할 때 저장된 비밀번호를 삭제하고, `저장된 비밀번호 유지`는 유지합니다. |

`저장`을 눌러 저장합니다. 프록시 변경 사항은 앱을 다시 시작한 뒤 적용되며, `다시 시작이 필요합니다` 다이얼로그에서 `다시 시작`을 선택할 수 있습니다.

저장된 프록시 구성을 읽을 수 없으면, 올바른 구성을 입력하거나 프록시를 끄고 저장한 뒤 다시 시작할 때까지 외부 요청이 차단됩니다.

### GitHub 토큰

토큰이 없으면 GitHub API 요청은 IP 주소당 시간당 60회로 제한됩니다. 개인용 액세스 토큰을 사용하면 시간당 5,000회로 늘어납니다. 앱은 공개 저장소만 읽으므로 세분화된 토큰에 추가 권한이 필요하지 않습니다.

1. `GitHub에서 토큰 만들기`를 눌러 토큰을 만듭니다.
2. `개인용 액세스 토큰`에 입력하고 `저장`을 누릅니다.

토큰은 현재 Windows 사용자 기준으로 암호화하여 저장합니다. `토큰 삭제`로 삭제합니다. GitHub가 저장된 토큰을 거부하거나 현재 Windows 사용자로 토큰을 복호화할 수 없으면, 새 토큰을 입력할 때까지 인증 없이 요청합니다.

## 나히다 에이전트 {#nahida-agent}

나히다 에이전트가 사용할 모델을 설정합니다. 공급자와 모델을 설정하면 내비게이션 레일에 나히다 에이전트가 표시됩니다.

### LLM 공급자

| 설정 | 설명 |
|---|---|
| `공급자` | 모델 목록에 있는 기본 제공 공급자 또는 `사용자 지정`을 선택합니다. 자격 증명이 저장된 공급자에는 `연결됨`이 표시됩니다. |
| `모델` | 목록에서 모델을 선택하거나 모델 ID를 입력합니다. 필드 아래에 모델 목록 날짜가 표시되며, `모델 목록 새로 고침`으로 갱신합니다. |
| `추론` | 추론 수준입니다. 기본 제공 공급자는 모델이 지원하는 수준만 표시합니다. |
| `에이전트 스크립트를 묻지 않고 실행` | 에이전트가 작성한 Python과 PowerShell 스크립트를 매번 승인을 받지 않고 실행합니다. 스크립트는 Windows 계정의 권한으로 실행되며 에이전트 폴더로 제한되지 않습니다. |
| `API 키` | `현재 값 유지`(또는 `설정된 키 유지`), `교체`, `삭제` 중에서 선택합니다. ChatGPT 로그인을 지원하는 공급자는 `ChatGPT Pro/Plus`도 제공합니다. `ChatGPT로 로그인`을 누르고 브라우저에서 로그인을 마치세요. 브라우저가 열리지 않으면 `링크 복사`를 사용합니다. |

`사용자 지정`을 선택하면 다음 설정도 표시됩니다. 기본 제공 공급자는 이 값을 모델 목록에서 가져옵니다.

| 설정 | 설명 |
|---|---|
| `프로토콜` | `OpenAI Responses`, `OpenAI-compatible`, `Anthropic Messages` 중에서 선택합니다. |
| `엔드포인트` | API 기본 URL입니다. |
| `모델이 이미지 입력을 지원` | 첨부한 이미지와 도구가 반환한 스크린샷을 모델에 보냅니다. 모델이 이미지 입력을 지원할 때만 켜세요. |
| `컨텍스트 윈도우`, `최대 출력 토큰` | 모델의 토큰 한도입니다. |
| `사용자 지정 헤더` | 사용자 지정 엔드포인트로 보내는 요청에만 붙는 헤더입니다. `암호화하여 저장`을 선택하면 값을 암호화합니다. |

`연결 테스트`는 테스트 요청을 보내고 모델과 응답 시간을 표시합니다. `저장`을 눌러 공급자 설정을 저장합니다.

### MCP

에이전트가 도구로 사용할 MCP 서버를 추가합니다. 활성화한 MCP 도구는 자동으로 실행되며, Nahida의 파일 샌드박스 밖의 권한을 가질 수 있습니다.

`서버 추가`를 누르고 `전송 방식`을 선택합니다.

- `stdio`: `실행 파일`, `인수 (한 줄에 하나)`, `작업 디렉터리`를 입력합니다.
- `Streamable HTTP`: 서버 URL을 입력합니다.
- `Blender (내장)`: 로컬 소켓으로 Blender MCP 애드온에 연결합니다. 먼저 Blender에서 애드온 환경설정의 브리지 서버를 시작하세요.

`항목 추가`로 이름과 값을 추가하며, `암호화하여 저장`을 선택하면 값을 암호화합니다. `활성화`를 켜고 `저장`을 누릅니다. 저장한 서버의 `연결 테스트`는 서버가 제공하는 도구 수를 표시합니다.

### 스킬

기본 제공 스킬과 사용자 스킬을 표시합니다. 스킬은 모델이 요청할 때 불러옵니다. `사용자 스킬 폴더 열기`는 사용자 스킬 폴더를 열고, `다시 검색`은 폴더를 다시 읽습니다.

## 고급 {#advanced}

저장된 모든 설정을 키와 값으로 표시합니다. `설정 키 검색...`으로 키를 검색하고, `편집` 버튼으로 원시 값을 변경합니다.

::: warning
여기에 입력한 값은 그대로 저장됩니다. 잘못된 값은 앱 동작을 바꿀 수 있습니다.
:::

프록시와 GitHub 토큰은 목록에 없으며 [네트워크](#network)에서 변경합니다. 키에 `password`, `token`, `secret`, `credentials`, `api_key`가 들어간 값은 `********`로 표시됩니다.

## 문제 신고 {#report-a-problem}

문제 보고를 개발자에게 보냅니다.

| 항목 | 설명 |
|---|---|
| `분류` | `Desktop 앱 문제`, `Nahida 서비스 문제`, `XXMI 라이브러리 문제` 중에서 선택합니다. |
| `내용` | 무엇이 잘못되었는지와 재현 방법입니다. 필수 항목입니다. |
| `첨부` | `파일 추가`로 이미지, 동영상, 텍스트 파일, zip 압축 파일을 첨부합니다. `모드 폴더 추가`는 문제가 있는 모드의 폴더를 첨부하며, nahida.live 로그인이 필요합니다. 드라이브가 허용하지 않는 형식의 파일은 제외됩니다. |
| `로그 첨부` | 기본으로 켜져 있습니다. 앱 로그를 첨부하며, PC 사용자 이름 같은 민감한 정보는 익명화합니다. |

길이와 첨부 한도는 서버에서 불러와 각 항목 옆에 표시합니다. `보내기`를 눌러 보내며, 보내는 중에는 `취소`로 중단할 수 있습니다.
