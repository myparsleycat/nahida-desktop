# d3d11.dll 빌더

원신에서는 불법 프로그램 감지 오류인 `4001` 문제가 계속 보고되고 있습니다.
기존에는 클라우드 제공업체 플래그를 적용하는 방식 등으로 대응할 수 있었지만, 최근에는 이전 방식으로 해결되지 않는 사례가 늘고 있습니다.

한국 커뮤니티에서는 XXMI에서 기본 제공되는 DLL 대신 `XXMI-Libs-Package` 저장소를 직접 클론한 뒤 빌드한 DLL을 사용하면, 대부분의 사용자에게서 `4001` 문제가 해결되는 것으로 확인되었습니다.

`d3d11.dll 빌더`는 이 과정을 더 쉽게 진행할 수 있도록 자동화한 기능입니다.

## 필수 빌드 도구 설치

이 기능은 DLL 빌드 과정의 상당 부분을 자동화하지만, DLL을 빌드하는 데 필요한 빌드 도구는 사용자가 직접 설치해야 합니다.

1. [Visual Studio 다운로드 페이지](https://visualstudio.microsoft.com/downloads/)에 접속해 **Visual Studio Community**를 다운로드한 뒤 설치합니다.
2. Visual Studio Installer에서 **C++를 사용한 데스크톱 개발** 워크로드를 선택합니다.
3. 개별 구성 요소에 다음 항목이 포함되어 있는지 확인한 뒤 설치합니다.
   - **x64/x86용 MSVC 빌드 도구(최신)**
   - **Windows 11 SDK**
   - **MSVC v143 - VS 2022 C++ x64/x86 빌드 도구 (v14.44-17.14)**

::: warning
빌드 도구 설치에는 약 10GB 이상의 저장 공간이 필요할 수 있습니다. 설치를 진행하기 전에 충분한 디스크 여유 공간을 확보해 주세요.
:::

## XXMI 경로 설정

이 기능을 사용하기 위해선 XXMI 경로를 설정해야 합니다. [XXMI 연결하기](/ko/others/set-up-xxmi#경로-설정하기) 페이지에서 자세히 알아보세요.

## DLL 빌드

![이미지](/features/mod-tools/dll-builder/page.png)

빌드 화면에서 다음 옵션을 설정할 수 있습니다.

- **제공자**:
  빌드에 사용할 `XXMI-Libs-Package` 저장소 제공자를 선택합니다.

  ::: warning
  `myparsleycat` 제공자의 저장소는 더 이상 유지보수되지 않으므로 선택하지 마십시오.
  :::

- **버전**:
  빌드할 XXMI 라이브러리 버전을 선택합니다.

- **대상 Importer**:
  빌드된 DLL을 사용할 Importer를 선택합니다.
  `4001` 오류는 현재 원신에서만 발생하므로 **GIMI**를 선택하세요.

옵션을 모두 선택한 뒤 **빌드 시작** 버튼을 누르면 DLL 빌드가 진행됩니다.

## 비보안 모드

![image](/features/mod-tools/dll-builder/unsafe.png)

XXMI 런처는 공식적으로 제공되는 DLL이 아닌, 확인되지 않은 DLL을 사용할 경우 경고 메시지를 표시합니다.

DLL 빌더를 통해 빌드하면 **비보안 모드**가 자동으로 활성화됩니다. 다만 자동 활성화가 정상적으로 적용되지 않은 경우, DLL 서명이 유효하지 않다는 경고 메시지가 표시될 수 있습니다.

`d3d11.dll` 서명이 유효하지 않다는 경고가 표시된다면, XXMI 런처 설정에서 **비보안 모드**를 직접 활성화해 주세요.

비보안 모드를 활성화한 뒤 다시 Importer를 실행하면 빌드한 DLL을 사용할 수 있습니다.
