# 토글 영구 저장

3DMigoto는 `persist`로 지정된 토글 변수의 상태를 `d3dx_user.ini`에 저장해, 게임을 다시 실행해도 이전 토글 상태를 유지합니다.

하지만 이 값은 모드 INI 파일이 아니라 `d3dx_user.ini`에만 저장됩니다. 따라서 모드를 비활성화한 상태로 Reload(F10)를 실행하면 해당 토글 값이 제거될 수 있으며, 이후 모드를 다시 활성화했을 때 이전 상태가 아닌 모드 INI 파일의 기본값이 적용될 수 있습니다.

## 기능 설명

이 기능을 활성화하면 나히다 데스크탑이 각 Importer의 `d3dx_user.ini` 변경 사항을 감시합니다.

인게임에서 토글을 변경한 뒤 Reload(F10)로 인해 `d3dx_user.ini`가 갱신되면, `d3dx_user.ini`에 저장된 토글 값을 해당 모드의 INI 파일에 자동으로 반영합니다.

그 결과 모드를 비활성화하거나 다시 불러온 뒤에도 이전 토글 상태를 계속 유지할 수 있습니다.

## 복사한 모드와 namespace

나히다 데스크탑은 `namespace = ...`로 직접 지정한 이름을 포함해, 각 persist 변수를 선언한 INI를 실제 namespace 기준으로 찾습니다. 본체와 help·메뉴 INI가 서로 다른 변수를 선언한다면 같은 namespace를 사용해도 각각 저장됩니다.

여러 INI가 같은 namespace에서 같은 변수를 선언하면 해당 변수의 저장을 건너뛰고, 충돌한 파일 경로를 토글 저장 로그에 기록합니다. 비활성 복사본은 3DMigoto가 불러오지 않으므로 충돌 검사에서 제외합니다. 충돌하지 않는 다른 변수는 계속 저장됩니다.

폴더 이름을 바꿔도 직접 지정한 namespace는 바뀌지 않습니다. 복사본의 인게임 상태를 독립적으로 유지하려면 각 복사본에 서로 다른 namespace를 지정하고, help·메뉴 INI의 관련 참조도 함께 변경해야 합니다. 나히다 데스크탑은 namespace나 참조를 자동으로 재작성하지 않습니다.
