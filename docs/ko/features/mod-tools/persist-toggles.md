# 토글 영구 저장

3DMigoto는 `persist`로 지정된 토글 변수의 값을 모드 INI 파일이 아닌 `d3dx_user.ini`에 저장합니다. 따라서 모드를 비활성화한 상태에서 Reload(`F10`)를 실행하면 값이 제거될 수 있으며, 모드를 다시 활성화하면 모드 INI 파일의 기본값이 적용됩니다.

## 기능 설명

이 기능을 켜면 나히다 데스크탑이 각 Importer의 `d3dx_user.ini` 변경을 감시하고, 저장된 토글 값을 해당 모드의 INI 파일에 반영합니다. 모드를 비활성화하거나 다시 불러와도 토글 상태가 유지됩니다.

## 복사한 모드와 namespace

값을 기록할 INI는 각 변수를 선언한 INI의 namespace(`namespace = ...`로 직접 지정한 이름 포함)로 찾습니다. 여러 INI가 같은 namespace에서 같은 변수를 선언하면 해당 변수는 저장하지 않고, 충돌한 파일 경로를 로그에 기록합니다. 비활성화된 모드는 이 검사에서 제외됩니다.

폴더 이름을 바꿔도 직접 지정한 namespace는 바뀌지 않습니다. 복사한 모드의 토글 상태를 독립적으로 유지하려면 각 복사본에 서로 다른 namespace를 지정하고 help·메뉴 INI의 참조도 함께 수정해야 합니다. 나히다 데스크탑은 namespace와 참조를 수정하지 않습니다.

도구 페이지에서 `토글 영구 저장`을 열고 스위치를 켭니다. 스위치 아래의 로그에 저장된 값과 건너뛴 변수가 표시됩니다.

::: warning
