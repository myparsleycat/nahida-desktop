# 상세 기능

좌측 내비게이션 레일에서 열 수 있는 각 화면을 설명합니다.

## 전송 {#transfers}

다운로드와 업로드의 전송 현황을 표시합니다. 전송을 일시정지, 재개, 재시도할 수 있습니다. 동시 전송 수와 다운로드 대역폭 제한은 [설정 → 전송](/ko/features/settings#transfer)에서 지정합니다.

## [게임바나나](/ko/features/gamebanana)

웹 브라우저를 열지 않고 게임바나나 모드를 탐색하고 다운로드합니다. 로그인은 선택 사항이며, 좋아요처럼 계정이 필요한 동작에서만 필요합니다.

## [모드 매니저](/ko/features/mod-manager/)

등록된 게임별로 모드를 활성화, 비활성화, 정리하고 [미리보기](/ko/features/mod-manager/previews)를 표시합니다. [프리셋과 토글 프리셋](/ko/features/mod-manager/presets)을 관리하며, 선택한 모드에 대해 [모델 뷰어](/ko/features/mod-manager/model-viewer)를 포함한 [모드 도구](/ko/features/mod-manager/mod-tools)를 열 수 있습니다.

## 도구

여러 모드를 대상으로 하는 도구를 표시합니다.

- [4001 Fixer](/ko/features/mod-tools/dll-builder)
- [토글 영구 저장](/ko/features/mod-tools/persist-toggles)
- XXMI 메뉴 메이커
- Toggle Viewer 생성기
- Fix Tool Manager
- 이진 탐색
- 체형 변경 (베타)
- 터치 프로필 (베타)
- [Blender 실시간 미리보기 (베타)](/ko/features/mod-manager/blender-live-preview)

모델 뷰어, 텍스처 리사이저, Vulkan 외곽선 보정, 액체 분사 부착점, 충돌 모드 찾기처럼 하나의 모드를 대상으로 하는 [모드 도구](/ko/features/mod-manager/mod-tools)는 모드 매니저에서 해당 모드의 컨텍스트 메뉴로 엽니다.

## 나히다 에이전트

모드 작업을 돕는 앱 내 어시스턴트입니다. [설정 → 나히다 에이전트](/ko/features/settings#nahida-agent)에서 공급자와 모델을 설정하면 내비게이션 레일에 표시됩니다.

## [XXMI](/ko/others/set-up-xxmi)

게임을 내장 런처로 실행할지 설치된 XXMI 런처로 실행할지 선택하고, Importer 패키지, XXMI 라이브러리, ReShade, 게임별 설정을 관리합니다.

## 드라이브, 공유 드라이브, 백업 {#drive}

나히다 드라이브에 파일을 업로드하거나 다운로드하고, 공유 드라이브 링크를 내 드라이브로 가져오며, 모드 폴더를 일정에 따라 백업합니다. 이 화면들은 nahida.live 계정으로 로그인하면 표시됩니다.

## [설정](/ko/features/settings)

앱 동작, 업데이트, 드라이브, 전송, 네트워크 프록시, GitHub 토큰, 나히다 에이전트, 문제 신고를 설정합니다. 모드 매니저 설정은 [모드 설정](/ko/features/mod-manager/settings)에 있습니다.
