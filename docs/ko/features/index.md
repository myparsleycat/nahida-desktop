# 상세 기능

상세 기능 섹션에서는 나히다 데스크탑에서 사용할 수 있는 기능들에 대해 설명합니다.

## 전송

![전송](/features/index/transfer-ko.png)
나히다 데스크탑의 각종 다운로드 및 업로드의 전송 현황을 확인하고 관리할 수 있는 페이지입니다. 전송의 일시정지, 재시작 및 실패한 전송의 재시도 등을 지원합니다.

## [게임바나나](/ko/features/gamebanana)

![게임바나나](/features/index/gamebanana-ko.png)
나히다 데스크탑은 게임바나나 API를 사용하여 웹 브라우저를 이용하지 않고 게임바나나 모드를 탐색하고 다운로드 할 수 있는 기능을 제공합니다.
해당 기능을 사용하려면 게임바나나에 필수적으로 로그인 해야 합니다.

## 모드매니저

![모드매니저](/features/index/modmanager-ko.png)
모드를 관리할 수 있는 나히다 데스크탑의 핵심 기능 중 하나입니다. 단순 모드 활성화 및 비활성화 뿐만 아니라 모드 툴 및 기타 기능들과 연계하여 높은 사용자 경험을 제공합니다.
