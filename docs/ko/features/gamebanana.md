# 게임바나나

나히다 데스크탑은 웹 브라우저를 열지 않고도 앱 안에서 게임바나나 모드를 탐색하고 다운로드할 수 있는 기능을 제공합니다.

이 문서에서는 게임바나나 페이지에서 모드를 탐색하고 다운로드하는 방법을 설명합니다.

## 시작하기

![이미지](/features/gamebanana/login1.png)

게임바나나 기능을 사용하려면 게임바나나 로그인이 필요합니다.

![이미지](/features/gamebanana/login2.png)

좌측 사이드바에서 게임바나나 페이지로 이동하면, 로그인이 필요한 경우 게임바나나 로그인 창이 표시됩니다.

사용자는 Username 또는 Email 등 원하는 로그인 방식을 선택하여 로그인할 수 있습니다.

![이미지](/features/index/gamebanana-ko.png)

로그인이 정상적으로 완료되면 로그인 창이 자동으로 닫히고, 게임바나나 페이지의 메인 화면이 표시됩니다.

## 탐색

![이미지](/features/gamebanana/browsing.gif)

게임바나나 페이지에서는 다음 방법으로 모드를 탐색할 수 있습니다.

- 좌측 상단에서 탐색할 게임을 선택합니다.
- 우측에서 원하는 카테고리를 선택합니다.
- 모드 카드를 클릭하여 상세 페이지로 이동합니다.

## 다운로드

![이미지](/features/gamebanana/download.gif)

모드 상세 페이지의 우측 다운로드 카드에서 해당 모드의 파일 목록을 확인할 수 있습니다.

다운로드할 파일을 클릭한 뒤 다운로드 방식을 선택하면 다운로드가 시작됩니다.

다운로드가 완료되면 해당 모드의 대표 이미지가 자동으로 함께 다운로드되며, 압축 해제된 모드 폴더에 저장됩니다.
