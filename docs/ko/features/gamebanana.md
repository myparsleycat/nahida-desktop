# 게임바나나

웹 브라우저를 열지 않고 앱 안에서 게임바나나 모드를 탐색하고 다운로드합니다.

## 로그인

로그인은 선택 사항입니다. 게임바나나 계정 없이도 모드를 탐색하고, 로그인이 필요하지 않은 모드를 다운로드할 수 있습니다.

로그인 창은 게임바나나 페이지의 로그인 버튼을 누르거나 모드에 좋아요를 누를 때처럼 로그인이 필요한 경우에만 표시됩니다.

::: info
로그인 창은 Microsoft Edge WebView2 Runtime을 사용합니다. 인스톨러는 이를 함께 설치하며, 포터블 실행 파일은 미리 설치되어 있어야 합니다.
:::

## 탐색

게임과 카테고리를 선택한 뒤 모드를 클릭하면 상세 페이지가 열립니다. 이환을 포함해 모드 매니저가 지원하는 모든 게임을 탐색할 수 있습니다.

## 다운로드

모드 상세 페이지에 해당 모드의 파일 목록이 표시됩니다. 파일을 클릭하고 다운로드 위치를 선택하면 다운로드가 시작되며, 다운로드 항목은 전송 페이지에 표시됩니다.

다운로드가 완료되면 압축 파일이 선택한 모드 폴더에 압축 해제되고, 모드의 대표 이미지가 해당 폴더에 미리보기로 저장됩니다.
