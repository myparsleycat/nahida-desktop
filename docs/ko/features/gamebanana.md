# 게임바나나

나히다 데스크탑은 웹 브라우저를 이용하지 않고도 나히다 데스크탑 내에서 게임바나나 모드들을 탐색하고 다운로드 할 수 있는 기능을 제공합니다. 이 문서는 해당 기능의 가이드를 제공합니다.

## 시작하기

![이미지](/features/gamebanana/login1.png)
해당 기능은 게임바나나 로그인이 필수적으로 필요합니다.

![이미지](/features/gamebanana/login2.png)
좌측 사이드바를 통해 게임바나나 페이지에 진입할 시 로그인이 필요한 경우 게임바나나 로그인 창이 표시됩니다. 사용자는 Username 또는 Email 등 원하는 방식을 이용해 로그인을 진행할 수 있습니다.

![이미지](/features/index/gamebanana-ko.png)
정상적으로 로그인이 진행된다면 로그인 창은 자동으로 닫힌 후 게임바나나 페이지의 메인 화면이 표시됩니다.
