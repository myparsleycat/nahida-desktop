# 캐릭터 데이터

모델 뷰어는 모드에 지정된 캐릭터의 게임 데이터를 사용하여 다음 기능을 제공합니다.

- **캐릭터 모션**: 게임의 캐릭터 모션을 모드에 재생합니다.
- **원본 게임 데이터**: 모드가 포함하지 않은 얼굴, 머리카락, 텍스처를 게임 원본으로 채웁니다.
- **표정**: 원본 얼굴에 표정과 눈 깜빡임을 적용합니다.
- **캐릭터별 툰 스타일**: 캐릭터의 재질 값으로 툰 셰이딩을 표시합니다.

지원하는 게임은 원신(GIMI), 붕괴: 스타레일(SRMI), 젠레스 존 제로(ZZMI), 명조(WWMI), 명일방주: 엔드필드(EFMI)입니다. 데이터가 제공되는 캐릭터에서만 사용할 수 있습니다.

## 캐릭터 지정

모델 뷰어에서 `모델` → `캐릭터 지정…`을 열고 게임과 캐릭터를 선택한 뒤 `저장`을 누릅니다. 선택은 현재 모드 폴더의 `nhd.json`에 저장되며, 모드를 다시 열 때 적용됩니다. `직접 지정 해제`를 누르면 폴더에 지정된 캐릭터를 다시 사용합니다.

폴더 안 모드에 적용할 기본 캐릭터를 지정하려면 다음 단계를 따릅니다.

1. 모드 매니저의 사이드바에서 폴더를 우클릭한 뒤 `캐릭터 지정…`을 선택합니다.
2. `게임`과 `캐릭터`를 선택하고 `저장`을 누릅니다.

모드에 직접 지정된 캐릭터가 없으면 가장 가까운 상위 폴더의 캐릭터를 사용합니다. [Blender 실시간 미리보기](/ko/features/mod-manager/blender-live-preview)에서는 연결 목록에서 캐릭터를 선택합니다.

## 다운로드

캐릭터 데이터는 처음 사용할 때 nahida.live 서버에서 다운로드되며, 이후에는 저장된 파일을 사용합니다. 다운로드 중에는 [재생 컨트롤러](/ko/features/mod-manager/model-viewer#playback)에 진행률이 표시됩니다.

## 캐릭터 모션 {#character-motion}

`모델` 메뉴의 `캐릭터 모션`을 켜면 캐릭터의 게임 모션을 모드에 재생합니다. 지정된 캐릭터에 모션 데이터가 있고 모드 메시에 본 가중치가 있을 때 표시되며, 기본적으로 켜져 있습니다.

- 모션은 재생 컨트롤러의 별도 줄에 표시되며, 대기 동작 클립부터 재생합니다. 클립 메뉴에서 다른 클립을 선택하면 현재 자세에서 부드럽게 전환됩니다.
- 모드 자체에 애니메이션이 있으면 모드 애니메이션과 함께 재생됩니다.
- 모션 줄의 `캐릭터 모션 끄기` 버튼을 누르면 현재 뷰어에서만 모션을 끕니다.

## 원본 게임 데이터 {#original-data}

`모델` 메뉴의 `원본 게임 데이터`를 켜면 모드에 게임 원본 데이터를 함께 표시합니다. 지정된 캐릭터에 원본 데이터가 있을 때 표시되며, 기본적으로 켜져 있습니다.

- 모드가 게임에 맡기는 얼굴과 머리 부위를 원본 모델로 표시합니다. 모드에 얼굴 텍스처가 있으면 원본 얼굴에 적용합니다.
- 모드 메시의 비어 있는 텍스처 슬롯을 원본 텍스처로 채웁니다.
- `누락된 부위` 하위 메뉴에서 모드에 없는 원본 부위를 개별적으로 표시하거나 숨깁니다. 게임이 계속 그리는 머리카락 부위는 처음부터 표시됩니다.

## 표정 {#expression}

원본 게임 데이터가 켜져 있고 표시된 부위에 표정 데이터가 있으면 `모델` 메뉴에 `표정` 하위 메뉴가 표시됩니다.

- `기본`, `미소`, `화남`, `곤란`, `놀람`, `윙크`, `눈 감기` 중에서 표정을 선택합니다. 표시된 부위에 적용할 수 있는 표정만 표시됩니다.
- `눈 깜빡임`: 자동 눈 깜빡임을 켜거나 끕니다.

캐릭터 모션 클립에 표정이 포함되어 있으면 클립의 표정을 재생합니다. `표정`에서 `기본` 이외의 표정을 선택하면 선택한 표정이 우선합니다.

## 캐릭터별 툰 스타일 {#toon-style}

캐릭터가 지정된 모드는 [툰 스타일](/ko/features/mod-manager/model-viewer#toon-style) 하위 메뉴 상단에 `{캐릭터 이름} 스타일`이 표시되고, 캐릭터의 재질 값으로 툰 셰이딩을 표시합니다.

- `셰이딩` 하위 메뉴에서 캐릭터 재질에서 가져온 값에는 `캐릭터 재질`이 표시됩니다.
- 원신에서는 `그림자 램프`의 `자동 ({캐릭터 이름})`이 해당 캐릭터의 램프를 사용합니다.
- 툰 스타일에서 변경한 값은 캐릭터별로 저장됩니다. `조명 카메라 추종`과 원신 텍스처 폴더는 게임별로 저장됩니다.
- `캐릭터 스타일 초기화`를 누르면 해당 캐릭터에 저장한 값을 초기화합니다.
