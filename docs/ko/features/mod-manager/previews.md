# 미리보기

모드 매니저는 모드와 사이드바 폴더에 이미지 또는 동영상 미리보기를 표시합니다.

지원하는 파일 형식은 `png`, `jpg`, `jpeg`, `gif`, `webp`, `bmp`, `avif`, `avifs`, `mp4`, `webm`, `avi`, `mkv`, `mov`입니다. 동영상은 소리 없이 반복 재생됩니다.

## 모드 미리보기

모드 매니저는 모드 폴더와 그 하위 폴더에서 미리보기로 사용할 파일을 다음 순서로 찾습니다.

1. 모드 폴더에 바로 있는 파일
2. 하위 폴더에 있는 파일
3. 비활성화된(`DISABLED`) 하위 폴더에 있는 파일

같은 위치에 파일이 여러 개 있으면 파일명이 `preview`로 시작하는 파일, 파일명에 `preview`가 포함된 파일, 그 밖의 파일 순으로 선택합니다. 대소문자는 구분하지 않습니다. 파일명에 `normal`, `light`, `material`, `diffuse`가 포함된 파일은 텍스처로 간주하여 제외합니다.

모드에 이미지가 여러 개 있으면 격자 보기의 미리보기에 `이전 미리보기 이미지`와 `다음 미리보기 이미지` 버튼이 표시됩니다. 선택한 이미지는 모드 폴더의 `nhd.json`에 저장되어 다음에도 표시됩니다.

## 폴더 미리보기

사이드바 폴더의 미리보기는 폴더에 바로 있는 이미지 또는 동영상 파일을 사용합니다. 사이드바를 `미리보기 그리드`로 표시하면 폴더 미리보기가 크게 표시됩니다.

::: info
[모드 설정](/ko/features/mod-manager/settings)의 `하위 폴더에서 미리보기 검색`을 켜면, 폴더에 미리보기가 없을 때 폴더 안의 모드 폴더에서도 미리보기를 찾습니다.
:::

## 미리보기 보기

- `크게 보기`: 미리보기를 앱 창 위에 크게 표시합니다. 격자 보기에서 미리보기를 우클릭하여 선택합니다. 목록 보기에서는 썸네일을 클릭합니다.
- `뷰어로 열기`: 미리보기 파일을 Windows에서 연결된 프로그램으로 엽니다. 모드 메뉴의 `미리보기` 구역 또는 격자 보기의 미리보기 메뉴에서 선택합니다.

## 미리보기 지정 및 교체

- **모드**: 이미지 파일, 이미지 URL, 또는 이미지를 클립보드에 복사한 뒤, 모드를 우클릭하고 `미리보기` 구역의 `붙여넣기`를 선택합니다. 격자 보기에서 미리보기가 없는 모드에는 미리보기 영역에 `붙여넣기` 버튼이 표시됩니다. 동영상 파일은 붙여넣을 수 없습니다.
- **사이드바 폴더**: 이미지 또는 동영상 파일 1개를 사이드바의 폴더에 드래그 앤 드롭합니다.
- **모델 뷰어**: [모델 뷰어](/ko/features/mod-manager/model-viewer)에서 `기타` → `캡처 후 미리보기 지정`을 선택합니다.

기존 미리보기가 있으면 덮어쓰기 전에 확인 메시지가 표시됩니다.

모드 메뉴의 `미리보기` 구역에서 `미리보기 삭제`를 선택하면 현재 미리보기 파일이 휴지통으로 이동합니다.

## 모델 미리보기 {#model-preview}

[모드 설정](/ko/features/mod-manager/settings#layout)의 `미리보기가 없는 모드에 모델 미리보기 표시`가 켜져 있으면, 격자 보기에서 이미지나 동영상이 없는 모드에 현재 토글 상태의 모델 이미지를 표시합니다. 이환 모드에는 표시되지 않습니다.

모델 미리보기를 우클릭하면 `모델 뷰어로 열기`와 `붙여넣기`를 선택할 수 있습니다.
