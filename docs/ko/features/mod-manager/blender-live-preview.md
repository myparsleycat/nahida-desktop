# Blender 실시간 미리보기

Blender 실시간 미리보기는 Blender에서 편집 중인 XXMI 모드를 내보내지 않고 [모델 뷰어](/ko/features/mod-manager/model-viewer)에 실시간으로 표시합니다. 원신(GIMI), 붕괴: 스타레일(SRMI), 젠레스 존 제로(ZZMI) 모드를 지원합니다.

도구 화면에서 `Blender 실시간 미리보기 (베타)`를 선택하여 엽니다.

::: info
Blender 3.6 이상과 Nahida Live Link 애드온이 필요합니다.
:::

## 애드온 설치

`애드온 (포함 버전 X)` 항목에는 PC에서 찾은 Blender 3.6 이상의 설치 목록과 각 Blender의 애드온 설치 상태가 표시됩니다. 목록이 최신 상태가 아니면 `새로 고침`을 누릅니다.

- `설치`, `업데이트`, `다시 설치`: 앱에 포함된 버전의 애드온을 설치하고 Blender에서 활성화합니다. 설치에 성공하면 Blender 실시간 미리보기가 켜집니다.
- `제거`: 애드온을 제거합니다.

다음 경우에는 설치할 수 없습니다.

- 해당 버전의 Blender가 실행 중인 경우: Blender를 종료한 뒤 다시 시도합니다.
- 다른 위치에 애드온 사본이 설치되어 있는 경우: 먼저 Blender에서 해당 사본을 제거합니다.
- 애드온 폴더가 다른 폴더에 연결되어 있는 경우: 연결된 폴더에서 업데이트합니다.

Blender 실행 파일을 찾지 못한 경우에는 애드온 파일만 설치됩니다. Blender의 편집 > 환경 설정 > 추가 기능에서 Nahida Live Link를 활성화합니다.

## 연결

1. 화면 상단의 스위치로 Blender 실시간 미리보기를 켭니다.
2. Blender에서 Nahida Live Link 애드온이 활성화되어 있으면 `연결된 Blender` 목록에 Blender가 표시됩니다.
3. 연결된 Blender에서 다음 항목을 지정하고 `모델 뷰어에서 열기`를 누릅니다.
   - `게임`: 모드의 게임을 선택합니다. 씬에서 게임을 알 수 있으면 자동으로 지정됩니다.
   - `게임 모션에 사용할 캐릭터`: [캐릭터 데이터](/ko/features/mod-manager/character-data)에 사용할 캐릭터를 선택합니다. 오브젝트 이름에서 캐릭터를 추정하여 미리 선택합니다.

연결된 애드온이 앱에 포함된 버전보다 오래되었으면 경고와 함께 업데이트 버튼이 표시됩니다.

## 실시간 반영

모델 뷰어가 열려 있는 동안 Blender에서 편집한 메시와 텍스처가 뷰어에 바로 반영됩니다. 새 오브젝트를 추가하는 등 구조가 바뀌면 씬을 다시 불러옵니다.
