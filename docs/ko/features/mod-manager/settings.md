# 모드 설정

설정 → 모드에서 모드 매니저의 동작을 지정합니다.

## 모드 관리

| 설정 | 기본값 | 설명 |
|---|---|---|
| `압축 해제 경로 방식` | `최상위 폴더 제거` | 압축 파일 안에 최상위 폴더가 하나만 있을 때의 처리 방식입니다. |
| `압축 해제 후 삭제` | 켜짐 | 압축 파일을 모드 폴더에 해제한 뒤 원본 압축 파일을 삭제합니다. |
| `폴더 복사 대신 이동` | 켜짐 | 폴더를 모드 폴더에 드롭할 때 복사하지 않고 이동합니다. |
| `모드 추가 시 Fix 필요 여부 자동 검사` | 켜짐 | 다운로드하거나 추가한 모드에 수정이 필요한지 검사하고 알립니다. |
| `활성화 시 ShaderFixes 복사` | 켜짐 | 모드를 활성화할 때 모드 안의 ShaderFixes 파일을 임포터의 ShaderFixes 폴더로 복사합니다. |
| `비활성 모드 접두사 형식` | `DISABLED (공백)` | 모드를 비활성화할 때 폴더 이름 앞에 붙이는 접두사입니다. 활성화할 때는 두 형식을 모두 인식합니다. |
| `하위 폴더에서 미리보기 검색` | 꺼짐 | 사이드바 폴더에 미리보기가 없으면 폴더 안의 모드 폴더에서 미리보기를 찾습니다. |
| `토글 프리셋 저장 위치` | `선택 안 함` | [토글 프리셋](/ko/features/mod-manager/presets#toggle-presets)의 저장 위치입니다. 변경하면 기존 프리셋을 이동합니다. |
| `다운로드 대상 폴더 자동 선택` | 꺼짐 | 다운로드 이름과 비슷한 이름의 모드 폴더를 자동으로 선택합니다. 적용할 다운로드 출처(`GameBanana`, `나히다 라이브`, `Hui`, `드라이브`)를 선택하며, 기본값은 `GameBanana`입니다. |

`압축 해제 경로 방식`의 옵션은 다음과 같습니다.

- `최상위 폴더 제거`: 최상위 폴더를 제거하고 그 안의 내용을 해제합니다. 예: `mod.zip/a/b/mod.ini` → `b/mod.ini`
- `압축 내부 경로 유지`: 압축 파일 안의 경로를 그대로 유지합니다. 예: `mod.zip/a/b/mod.ini` → `a/b/mod.ini`
- `매번 확인`: 모드를 추가할 때마다 `압축 해제 경로 선택` 다이얼로그에서 선택합니다.

## 레이아웃 {#layout}

| 설정 | 기본값 | 설명 |
|---|---|---|
| `사이드바 레이아웃` | `행 목록` | 사이드바를 `행 목록` 또는 정사각형 `미리보기 그리드`로 표시합니다. |
| `미리보기가 없는 모드에 모델 미리보기 표시` | 켜짐 | 격자 보기에서 이미지나 동영상이 없는 모드에 현재 토글 상태의 모델 이미지를 표시합니다. |
| `모드 그리드 레이아웃` | `반응형` | 격자 보기의 카드 너비와 열 개수를 정하는 방식입니다. |

`모드 그리드 레이아웃`의 옵션은 다음과 같습니다.

- `반응형`: `반응형 기준 카드 너비`(240~640, 기본값 400)를 기준으로 화면 너비에 맞는 열 개수를 계산합니다.
- `고정 카드 너비`: 카드 너비(240~640, 기본값 360)를 고정하고 열 개수만 변경합니다.
- `고정 열 개수`: 가능한 경우 지정한 열 개수(1~8, 기본값 4)를 사용합니다.

## 모드 압축

모드 파일을 압축하여 디스크 공간을 줄입니다. `모드 압축 활성화` 스위치로 켜고 끄며, 진행 상황이 함께 표시됩니다.

- `압축 방식`: 기본값은 `XPRESS4K`입니다.
  - `Zstd`: 비활성화된 모드의 큰 파일만 압축합니다. 모드를 활성화하면 먼저 원본 파일로 복원합니다.
  - `XPRESS4K`: Windows 파일 압축으로 모든 모드 파일의 크기를 줄입니다. 압축된 상태에서도 모드를 사용할 수 있습니다.
- `압축 크기 기준`: `Zstd`에서 압축을 시도할 최소 파일 크기입니다. 범위는 1~64 MiB이며, 기본값은 1 MiB입니다.
