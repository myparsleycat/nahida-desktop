# 프리셋

모드 매니저에는 두 종류의 프리셋이 있습니다.

- **프리셋**: 게임에서 어떤 모드가 활성화되어 있는지를 저장합니다.
- **토글 프리셋**: 한 모드의 토글 값을 저장합니다.

## 프리셋

프리셋 선택기는 사이드바 하단의 게임 선택기 옆에 있습니다.

- **저장**: 프리셋 선택기 옆의 `+` 버튼(`새 프리셋 생성`)을 누르고 이름과 `설명 (선택 사항)`을 입력합니다. 현재 활성화된 모드 구성이 저장됩니다.
- **적용 및 삭제**: 프리셋 선택기에서 프리셋을 선택하면 프리셋 이름과 설명이 다이얼로그로 표시됩니다. `적용` 또는 `삭제`를 선택합니다.

프리셋을 적용할 때 찾을 수 없거나 상태를 변경하지 못한 모드가 있으면 그 수가 알림으로 표시됩니다.

`DISABLED` 접두사만 다른 폴더는 같은 모드로 취급됩니다. 이런 폴더가 있으면 프리셋을 저장할 때 `중복 모드 항목이 발견되었습니다` 다이얼로그가 표시되며, `비활성 중복 폴더 이름 변경 후 계속`을 선택하면 비활성 폴더의 이름을 바꾼 뒤 프리셋을 저장합니다.

이전 버전에서 만든 프리셋에는 `레거시`가 표시되며 적용할 수 없습니다. 삭제한 뒤 다시 만들어야 합니다.

## 토글 프리셋 {#toggle-presets}

토글 프리셋은 한 모드의 토글 값을 이름을 붙여 저장하고, 저장한 값을 다시 적용합니다.

### 여는 방법

- 모드를 우클릭한 뒤 `토글 프리셋`을 선택합니다.
- 격자 보기의 카드에서 INI 목록 상단의 토글 프리셋 버튼을 클릭합니다. 저장된 프리셋 목록과 `프리셋 관리…`가 표시됩니다.
- [모델 뷰어](/ko/features/mod-manager/model-viewer)의 `토글` 메뉴에서 `프리셋으로 저장` 또는 `프리셋 적용`을 선택합니다.

INI 파일이 있는 모드에서만 사용할 수 있으며, 이환 모드에서는 사용할 수 없습니다.

### 저장 위치

토글 프리셋을 처음 사용할 때 `토글 프리셋 저장 위치`를 선택합니다.

- `모드 폴더 (nhd.json)`: 모드 폴더의 `nhd.json`에 저장합니다. 폴더 이름을 바꾸거나 폴더를 이동해도 프리셋이 유지되며, 폴더를 공유할 때 프리셋도 함께 전달됩니다.
- `앱 데이터베이스`: 앱 데이터베이스에 저장합니다. 모드 폴더는 변경하지 않지만, 폴더 이름을 바꾸거나 폴더를 이동하면 프리셋을 찾을 수 없습니다.

저장 위치는 토글 프리셋 다이얼로그의 `저장 위치` 또는 [모드 설정](/ko/features/mod-manager/settings)의 `토글 프리셋 저장 위치`에서 변경합니다. 변경하면 기존 프리셋이 새 위치로 이동합니다.

### 저장과 적용

토글 프리셋 다이얼로그에서 프리셋 이름을 입력하고 `현재 값 저장`을 선택합니다. 저장된 프리셋은 목록에서 적용하거나 이름을 변경하거나 삭제합니다.

- **값을 읽는 위치**: 게임이 실행 중이고 앱과 연결되어 있으면 실행 중인 게임에서 값을 읽습니다. 그렇지 않으면 모드의 INI 파일과 `d3dx_user.ini`에서 값을 읽습니다.
- **적용**: 프리셋 값을 모드의 INI 파일에 기록합니다. 게임이 실행 중이고 앱과 연결되어 있으면 실행 중인 게임에도 바로 적용합니다.

::: warning
토글 프리셋을 저장하거나 적용하려면 게임을 내장 런처와 myparsleycat XXMI 라이브러리로 실행하도록 [XXMI](/ko/others/set-up-xxmi)를 설정해야 합니다. 그렇지 않으면 `내장 런처와 myparsleycat 라이브러리가 필요합니다`가 표시되고 저장과 적용이 비활성화됩니다.
:::
