# 모델 뷰어

모델 뷰어는 게임을 실행하지 않고 모드의 모델, 텍스처, 토글 상태를 표시합니다.

::: warning
일부 모드는 뷰어에서 열리지 않거나, 모델 또는 텍스처가 비정상적으로 표시될 수 있습니다.
:::

## 지원되는 게임

- `원신` (GIMI)
- `붕괴: 스타레일` (SRMI)
- `젠레스 존 제로` (ZZMI)
- `명조` (WWMI)
- `명일방주: 엔드필드` (EFMI)

## 모델 뷰어 열기

모드 매니저에서 모드를 우클릭한 뒤 `모델 뷰어`를 선택하거나, 그리드 레이아웃의 모드 카드에서 `모델 뷰어로 열기` 버튼(큐브 아이콘)을 클릭합니다.

## 메뉴바

- **모델**: 모델을 회전하고 모델 또는 카메라를 초기화합니다.
- **텍스처**: `양면 렌더링`은 각 폴리곤의 양면을 모두 렌더링합니다.
- **렌더링**: 톤 매핑, 환경광, 노출을 변경하고 노멀 맵을 켜거나 끕니다. 지원되는 게임에서는 `툰 그림자`와 게임별 툰 스타일 하위 메뉴로 외곽선과 자체 그림자를 포함한 툰 셰이딩을 변경합니다.
- **토글**: 토글이 있는 모드에서 표시됩니다.
  - `INI에 저장`: 현재 토글 값을 모드의 INI 파일에 기록합니다.
  - `초기화`: INI 파일의 기본값으로 되돌립니다.
  - `프리셋으로 저장` / `프리셋 적용`: 현재 값을 [토글 프리셋](/ko/features/mod-manager/#toggle-presets)으로 저장하거나 저장된 프리셋을 적용합니다.
  - `가리킨 값을 게임에서 미리 보기`: 커서가 가리키는 값을 실행 중인 게임에 표시합니다.
  - `뷰어에 오버레이 표시`: 모드의 인게임 토글 오버레이를 뷰어 안에 표시합니다. 드래그하여 이동하고, `Ctrl` + 마우스 휠 또는 우하단 모서리로 크기를 조절합니다.
- **기타**:
  - `캡처 후 미리보기 지정`: 뷰포트를 정사각형 `preview.png`로 모드 폴더에 저장합니다. 모드에 이미 미리보기가 있으면 교체하기 전에 확인 메시지가 표시됩니다.

## 게임 연동

모드의 Importer가 내장 런처와 myparsleycat XXMI 라이브러리를 사용하면 `프리셋으로 저장`, `프리셋 적용`, `가리킨 값을 게임에서 미리 보기`를 사용할 수 있습니다. 해당 게임이 실행 중이면 토글 뷰어 상단의 `게임에 적용`으로 현재 값을 게임에 적용합니다.

## 토글 뷰어

토글이 있는 모드는 우측 토글 뷰어에 각 토글이 표시됩니다. 값을 변경하면 해당 상태에 맞춰 모델이 다시 그려집니다. 분할선을 드래그하여 패널 크기를 조절하거나, 클릭하여 패널을 표시하거나 숨길 수 있습니다.

뷰어가 그리지 않는 텍스처나 효과만 바꾸는 값에는 `뷰어에 표시되지 않음`이 표시되며, 이러한 값도 프리셋에는 저장됩니다.

## 애니메이션 재생

모드에 애니메이션이 포함되어 있으면 뷰어 하단에 재생 바가 표시됩니다. 재생 바에서 애니메이션 재생과 일시 정지, 클립 선택, 재생 속도 변경, 프레임 이동을 할 수 있습니다.
