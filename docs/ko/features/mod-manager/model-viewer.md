# 모델 뷰어

![이미지](/features/mod-manager/model-viewer/0.png)

모델 뷰어를 사용하면 게임을 실행하지 않고도 모드의 모델과 텍스처, 토글 상태를 미리 확인할 수 있습니다.

::: warning
이 기능은 아직 개발 중입니다. 일부 모드는 뷰어에서 열리지 않거나, 모델 또는 텍스처가 비정상적으로 표시될 수 있습니다.
:::

## 지원되는 게임

현재 다음 게임의 모드를 지원합니다.

- `원신`
- `붕괴: 스타레일`
- `젠레스 존 제로`
- `명조`

## 모델 뷰어 열기

![이미지](/features/mod-manager/model-viewer/1.png)
카드 레이아웃에서는 모드 카드 헤더의 모델 뷰어 버튼을 눌러 뷰어를 열 수 있습니다.

![이미지](/features/mod-manager/model-viewer/2.png)
리스트 레이아웃에서는 모드를 우클릭한 뒤 `모델 뷰어` 메뉴를 선택하면 됩니다.

## 상단 메뉴바

- **모델**: 모델 회전, 모델 초기화, 카메라 초기화 같은 기본 조작을 제공합니다.
- **텍스처**: 텍스처 관련 표시 옵션을 변경합니다.
  - `Double Sided`: 폴리곤의 앞면과 뒷면을 모두 렌더링합니다.
- **렌더링**: 렌더링 방식을 변경해 모델 상태를 다른 방식으로 확인할 수 있습니다.
- **토글**: 현재 토글 상태를 저장하거나 초기화합니다.
  - `INI에 저장`: 토글 뷰어에서 선택한 현재 상태를 INI에 반영합니다.
  - `초기화`: 토글 상태를 INI 기본값으로 되돌립니다.
- **기타**: 현재 모드에 대한 추가 작업을 제공합니다.
  - `캡처 후 프리뷰 지정`: 현재 보이는 뷰어 화면을 가운데 기준 1:1 정사각형 PNG로 캡처해 현재 모드 폴더의 `preview.png`로 저장합니다.

## 뷰어에서 프리뷰 캡처하기

현재 뷰어 화면을 모드 프리뷰로 쓰고 싶다면 `기타` → `캡처 후 프리뷰 지정`을 선택하세요.

캡처에는 활성 3D 뷰어 영역만 포함됩니다. 메뉴바나 우측 토글 패널은 이미지에 들어가지 않습니다.

모드에 이미 `preview.*` 파일이 있다면, 새 `preview.png`로 교체하기 전에 확인 메시지가 표시됩니다.

## 우측 토글 뷰어

토글이 포함된 모드는 우측 토글 뷰어에서 상태를 직접 바꿔 볼 수 있습니다. 값을 변경하면 해당 상태에 맞춰 모델이 다시 렌더링됩니다.

![이미지](/features/mod-manager/model-viewer/3.png)
인게임 토글 뷰어를 사용하는 모드라면, 관련 UI 에셋도 함께 표시될 수 있습니다.

![이미지](/features/mod-manager/model-viewer/4.gif)
슬라이더를 사용하는 모드라면, 토글 뷰어에 조작 가능한 슬라이더가 함께 표시됩니다.

## 애니메이션 재생

모드에 애니메이션이 포함되어 있다면 뷰어 하단에 애니메이션 재생 패널이 나타납니다.

재생 컨트롤을 사용하여 애니메이션을 재생, 일시 정지하거나 초기화할 수 있으며, 슬라이더를 드래그하여 특정 프레임으로 이동할 수 있습니다.
