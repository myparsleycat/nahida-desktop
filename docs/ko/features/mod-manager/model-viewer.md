# 모델 뷰어

모델 뷰어는 게임을 실행하지 않고 모드의 모델, 텍스처, 토글 상태를 표시합니다.

::: warning
일부 모드는 뷰어에서 열리지 않거나, 모델 또는 텍스처가 비정상적으로 표시될 수 있습니다.
:::

## 지원되는 게임

- 원신 (GIMI)
- 붕괴: 스타레일 (SRMI)
- 젠레스 존 제로 (ZZMI)
- 명조 (WWMI, RabbitFX)
- 명일방주: 엔드필드 (EFMI)

이환 모드는 지원하지 않습니다.

## 모델 뷰어 열기

- 모드를 우클릭한 뒤 `도구` 구역의 `모델 뷰어`를 선택합니다.
- 격자 보기의 모드 카드에서 `모델 뷰어로 열기` 버튼(큐브 아이콘)을 클릭합니다.
- 격자 보기의 [모델 미리보기](/ko/features/mod-manager/previews#model-preview)를 우클릭한 뒤 `모델 뷰어로 열기`를 선택합니다.
- Windows 파일 탐색기에서 모드 폴더를 우클릭한 뒤 `모델 뷰어로 보기`를 선택합니다. 설치판에서만 표시되며, 모델 뷰어가 별도 창으로 열립니다.
- [Blender 실시간 미리보기](/ko/features/mod-manager/blender-live-preview)에서 `모델 뷰어에서 열기`를 선택합니다.

## 조작

- **회전**: 마우스 왼쪽 버튼으로 드래그합니다.
- **이동**: 마우스 오른쪽 또는 가운데 버튼으로 드래그하거나, `Shift`를 누른 채 왼쪽 버튼으로 드래그합니다.
- **확대·축소**: 마우스 휠을 사용합니다.
- **축 방향 보기**: 뷰포트 우상단의 축 표시에서 축 끝을 클릭하면 해당 축 방향에서 모델을 봅니다.
- **폼**: 폼이 여러 개인 모드는 뷰포트 좌상단에 `폼` 목록이 표시됩니다. 폼을 선택하면 해당 폼만 표시하고, `전체`를 선택하면 모든 폼을 표시합니다.

## 메뉴바

### 모델

- `회전`: `왼쪽으로 90°`, `오른쪽으로 90°`, `위로 90°`, `아래로 90°`, `180° 뒤집기`로 모델을 회전합니다.
- `초기화`: 모델의 회전과 카메라를 처음 상태로 되돌립니다.
- `캐릭터 지정…`: 현재 모드에 캐릭터를 지정합니다. `직접 지정 해제`를 누르면 폴더에 지정된 캐릭터를 다시 사용합니다.
- `캐릭터 모션`, `원본 게임 데이터`, `누락된 부위`, `표정`: 지정된 캐릭터와 모델에서 지원되는 항목이 표시됩니다. [캐릭터 데이터](/ko/features/mod-manager/character-data)를 참고하세요.

### 텍스처

- `양면 렌더링`: 각 폴리곤의 양면을 모두 렌더링합니다.

### 렌더링

- `톤 매핑`: `뉴트럴`, `ACES Filmic`, `없음` 중에서 선택합니다.
- `환경광`: `스튜디오`, `부드러움`, `없음` 중에서 선택합니다.
- `노출`: `-0.1`, `+0.1` 버튼 또는 입력란으로 노출을 0~4 범위에서 변경합니다. `초기화`를 누르면 기본값으로 되돌립니다.
- `툰 그림자`: 툰 셰이딩을 켜거나 끕니다.
- 툰 스타일 하위 메뉴: 게임에 따라 `원신 툰 스타일`, `스타레일 툰 스타일`, `젠레스 존 제로 툰 스타일`, `명조 툰 스타일`, `툰 스타일`(엔드필드)로 표시됩니다. [툰 스타일](#toon-style)을 참고하세요.
- `노멀 맵`: 노멀 맵이 있는 모드에서 노멀 맵을 켜거나 끕니다.

### 토글

토글이 있는 모드에서 표시됩니다.

- `INI에 저장`: 현재 토글 값을 모드의 INI 파일에 기록합니다. 모드를 불러온 게임이 실행 중이고 앱과 연결되어 있으면 게임에도 적용합니다.
- `초기화`: INI 파일의 기본값으로 되돌립니다.
- `프리셋으로 저장` / `프리셋 적용`: 현재 값을 [토글 프리셋](/ko/features/mod-manager/presets#toggle-presets)으로 저장하거나 저장된 프리셋을 적용합니다. 프리셋을 적용하면 INI 파일에 기록하고, 연결된 게임에도 적용합니다.
- `마우스를 올린 값을 게임에서 미리보기`: 토글 뷰어에서 마우스를 올린 값을 실행 중인 게임에 표시합니다.
- `뷰어에 오버레이 표시`: 모드의 인게임 토글 오버레이를 뷰어 안에 표시합니다. 끄면 오버레이가 토글 뷰어 상단에 표시됩니다.
- `오버레이 위치 및 크기 초기화`: 뷰어 안 오버레이의 위치와 크기를 처음 상태로 되돌립니다.

뷰어 안의 오버레이는 드래그하여 이동하고, `Ctrl` + 마우스 휠 또는 우하단 모서리로 크기를 조절합니다.

### 기타

- `캡처 후 미리보기 지정`: 뷰포트 중앙을 투명 배경의 정사각형 `preview.png`로 모드 폴더에 저장합니다. 모드에 이미 미리보기가 있으면 교체하기 전에 확인 메시지가 표시됩니다.
- `PNG로 저장`: 현재 화면을 뷰포트 크기의 1배, 2배 또는 4배 해상도로 투명 배경의 PNG 파일로 저장합니다. 하위 메뉴의 각 항목에 저장될 크기가 표시되며, 저장 위치는 저장 대화상자에서 지정합니다.

## 툰 스타일 {#toon-style}

`렌더링` 메뉴의 툰 스타일 하위 메뉴에서 다음 항목을 변경합니다.

- `외곽선`, `자체 그림자`, `조명 카메라 추종`
- `얼굴 평면 음영`: 엔드필드에서만 표시됩니다.
- `셰이딩`: `그림자 임계값`, `그림자 밝기`, `외곽선 색상` 등 게임별 셰이딩 값을 조절합니다. `셰이딩 초기화`를 누르면 기본값으로 되돌립니다.
- 원신에서는 다음 항목이 추가로 표시됩니다.
  - `원신 텍스처 폴더...`: 원신 툰 텍스처가 있는 폴더를 지정합니다. `텍스처 폴더 해제`로 지정을 해제합니다.
  - `그림자 램프`: `자동`, `내장`, 또는 텍스처 폴더에 있는 램프 중에서 선택합니다.
  - `얼굴 그림자 맵`: 얼굴이 표시되는 경우 `자동`, `소년`, `소녀`, `성인 여성`, `로리`, `성인 남성` 중에서 선택합니다.

캐릭터가 지정된 모드는 해당 캐릭터의 툰 스타일을 사용하며, 변경한 값도 캐릭터별로 저장됩니다. 그 밖의 모드는 게임별로 저장됩니다. [캐릭터 데이터](/ko/features/mod-manager/character-data#toon-style)를 참고하세요.

## 토글 뷰어

토글이 있는 모드는 우측 토글 뷰어에 각 토글이 표시됩니다. 값을 변경하면 해당 상태에 맞춰 모델이 다시 그려지며, 값에 마우스를 올리면 그 값이 적용된 모델을 미리 표시합니다.

- 현재 조합에서 효과가 없는 값은 비활성화됩니다. 값에 마우스를 올리면 함께 변경해야 하는 변수가 표시되며, `이 조합 적용`으로 필요한 변수를 함께 변경합니다.
- 뷰어가 그리지 않는 텍스처나 효과만 바꾸는 값은 `뷰어에 표시되지 않음`에 표시되며, 이러한 값도 프리셋에는 저장됩니다.
- 분할선을 드래그하여 패널 크기를 조절하거나, 클릭하여 패널을 표시하거나 숨깁니다. 분할선에 포커스가 있을 때 `Enter` 또는 `Space`로 패널을 표시하거나 숨기고, `←`/`→`로 크기를 조절합니다.

## 재생 컨트롤러 {#playback}

모드에 애니메이션이 있거나 [캐릭터 모션](/ko/features/mod-manager/character-data#character-motion)을 재생할 때 뷰포트 하단에 재생 컨트롤러가 표시됩니다. 캐릭터 데이터 다운로드 상태와 [텍스처 선택](#texture-choice) 항목도 이 컨트롤러에 표시됩니다.

- 모드 애니메이션과 캐릭터 모션은 각각의 줄에 표시됩니다. 각 줄에서 `재생`/`일시 정지`, 클립 선택, `처음으로`, `끝으로`, 재생 속도(0.25×~2×)를 조작합니다.
- 프레임 슬라이더를 드래그하여 원하는 프레임으로 이동합니다. 슬라이더에 포커스가 있을 때 `←`/`→`로 한 프레임씩, `Home`/`End`로 처음과 끝으로 이동합니다.
- 재생 속도 메뉴의 `프레임 보간`을 켜면 프레임 사이를 보간하여 부드럽게 재생합니다.
- 컨트롤러 왼쪽의 손잡이(`컨트롤러 이동`)를 드래그하여 컨트롤러를 이동합니다. 손잡이를 더블클릭하거나 손잡이에 포커스가 있을 때 `Home`을 누르면 원래 위치로 돌아갑니다.

## 텍스처 선택 {#texture-choice}

INI가 텍스처를 해시로 교체하는 모드는 일부 부위가 어떤 텍스처를 사용하는지 알 수 없어, 해당 부위가 게임 원본 텍스처로 표시됩니다. 이런 부위가 있으면 재생 컨트롤러에 `게임 원본 텍스처를 사용하는 부위 N개`가 표시됩니다.

이 항목을 클릭하면 다음 항목이 표시됩니다.

- `강조 표시`: 게임 원본 텍스처를 사용하는 부위를 강조합니다.
- `텍스처 선택`: 부위마다 `게임 원본 텍스처` 또는 같은 모델의 다른 부위 텍스처를 선택합니다. 선택은 모드 폴더의 `nhd.json`에 저장되며, 격자 보기의 모델 미리보기에도 적용됩니다.

## 게임 연동

모드의 임포터가 내장 런처와 myparsleycat XXMI 라이브러리를 사용하면 `프리셋으로 저장`, `프리셋 적용`, `마우스를 올린 값을 게임에서 미리보기`를 사용할 수 있습니다. 해당 모드를 불러온 게임이 실행 중이면 토글 뷰어 상단의 `게임에 적용`으로 현재 값을 게임에 적용합니다.
