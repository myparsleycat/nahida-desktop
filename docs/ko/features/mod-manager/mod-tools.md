# 모드 도구

모드 도구는 모드 하나 또는 선택한 모드들을 대상으로 작업합니다. 대부분은 모드 메뉴의 `도구` 구역이나 격자 보기 카드의 `모드 도구` 버튼에서 엽니다. 이환 게임에서는 `도구` 구역에 `나히다 에이전트`만 표시됩니다.

## 도구 목록

| 도구 | 대상 게임 | 설명 |
|---|---|---|
| `나히다 에이전트` | 전체 | 선택한 모드를 대상으로 나히다 에이전트를 엽니다. |
| [`모델 뷰어`](/ko/features/mod-manager/model-viewer) | 이환 제외 | 모드의 3D 모델과 토글 상태를 표시합니다. 카드에서는 `모델 뷰어로 열기` 버튼으로 엽니다. |
| `텍스처 리사이저` | 전체 | 모드의 DDS 텍스처 크기를 변경하고 원본 파일에 저장합니다. |
| `XXMI 메뉴 메이커` | 전체 | 모드의 토글로 게임 내 메뉴를 생성합니다. 도구 화면에서 열립니다. |
| `체형 변경 (베타)` | 전체 | 칠한 영역이나 본 가중치를 기준으로 모드의 메시를 조정합니다. |
| `터치 프로필 (베타)` | 전체 | 터치 영역을 지정하여 터치에 반응하는 모드로 변환합니다. |
| `Vulkan 외곽선 보정` | EFMI | [Vulkan 외곽선 보정](#vulkan-outline-fix)을 참고하세요. |
| `액체 분사 부착점 (베타)` | EFMI, GIMI, SRMI, WWMI, ZZMI | 모드의 메시에 액체 분사 부착점을 지정하고 INI에 연결합니다. |
| `충돌 모드 찾기` | 전체 | [충돌 모드 찾기](#find-conflict)를 참고하세요. |
| [`토글 프리셋`](/ko/features/mod-manager/presets#toggle-presets) | 이환 제외 | 모드 메뉴에서만 표시됩니다. |

## 모드 병합 (베타) {#merge}

여러 모드를 하나의 모드로 합쳐 게임 안에서 키로 전환할 수 있게 합니다. GIMI, SRMI, ZZMI, HIMI, WWMI, EFMI 게임에서 사용할 수 있습니다.

1. 모드 목록 상단의 `더 보기` 메뉴에서 `모드 병합 (베타)`를 선택합니다.
2. 병합할 모드를 2개 이상 클릭하여 선택하고 `다음`을 누릅니다. `병합 취소` 또는 `Esc`로 병합 모드를 종료합니다.
3. `모드 병합` 다이얼로그에서 다음 항목을 지정하고 `병합`을 누릅니다.
   - `이름`: 병합된 모드의 이름입니다.
   - `다음 키` / `이전 키`: 게임 안에서 모드를 전환하는 키입니다.
   - `저장 위치`: `기존 위치` 또는 `새 폴더`를 선택합니다.
   - `병합 방식`: `일반` 또는 `네임스페이스`를 선택합니다. 일반 병합을 적용할 수 없는 모드가 포함되어 있으면 `네임스페이스`만 선택할 수 있습니다.
   - `바닐라 슬롯 포함`: 모드를 적용하지 않은 상태를 전환 대상에 추가합니다. `네임스페이스` 방식에서만 사용할 수 있습니다.
   - 모드 목록: 위아래 버튼으로 전환 순서를 변경합니다. `다음 모드와 묶기`를 누르면 해당 모드와 다음 모드를 하나의 하위 그룹으로 묶고, `묶음 해제`를 누르면 하위 그룹을 해제합니다.

## 충돌 모드 찾기 {#find-conflict}

선택한 모드를 활성화한 채로 다른 모드를 절반씩 비활성화하면서, 이 모드와 충돌하는 모드를 찾습니다. 모드가 비활성화되어 있으면 먼저 활성화해야 합니다.

## 수정 {#fix}

모드 메뉴의 `수정` 구역과 카드의 `모드 도구` 메뉴에서 수정 도구를 실행합니다. 실행 결과는 로그 다이얼로그에 표시되며, 입력이 필요한 도구는 로그 다이얼로그 하단에서 입력합니다.

- `프리셋`, `수정 도구`: 도구 화면의 Fix Tool Manager에 등록한 프리셋과 수정 스크립트를 모드에 실행합니다. Python 수정 도구를 실행하려면 Python이 설치되어 있어야 합니다.
- **Wuwa Mod Fixer**: WWMI 게임과 임포터가 `없음`인 게임에서 표시됩니다. 처음 실행할 때 설치하며, 새 버전이 있으면 업데이트를 안내합니다. `모드 수정` 탭에서 옵션을 선택하여 실행하고, `롤백` 탭에서 백업으로 되돌립니다.
- **ZZMI Mod Fixer**: ZZMI 게임에서 표시됩니다. `Hash Fix`, `Jane Remap`, `Dialyn Remap`, `롤백` 탭이 있습니다.

Wuwa Mod Fixer와 ZZMI Mod Fixer는 사이드바 폴더 메뉴의 `도구`와 모드 목록 상단 `더 보기` 메뉴의 `도구`에서 폴더 전체에 실행할 수도 있습니다.

[모드 설정](/ko/features/mod-manager/settings)의 `모드 추가 시 Fix 필요 여부 자동 검사`가 켜져 있으면, 다운로드하거나 추가한 모드에 수정이 필요할 때 알림이 표시됩니다. 알림의 `Fixer 열기`를 선택하면 해당 Fixer가 열립니다.

## Vulkan 외곽선 보정 {#vulkan-outline-fix}

명일방주: 엔드필드(EFMI) 모드 전용입니다. Vulkan에서는 모드의 일부 부품이 외곽선 패스에서 한 번 더 렌더링되어 불투명하게 표시됩니다. 이 도구는 INI 파일별로 해당 부품을 표시하며, 외곽선 패스에서 제외할 부품을 선택하여 적용합니다.

- `되돌리기`: 원본 파일로 되돌립니다.
- 적용한 뒤 파일을 직접 수정한 경우 `직접 수정됨`이 표시됩니다. 다시 적용하거나 되돌리려면 `현재 파일을 원본으로 사용`을 선택합니다.

적용한 뒤 게임에서 `F10`을 눌러 모드를 다시 불러옵니다.

## 캐릭터 지정 {#set-character}

사이드바 폴더에 캐릭터를 지정하면, 해당 폴더와 그 하위 폴더의 모드가 [모델 뷰어](/ko/features/mod-manager/model-viewer)에서 그 캐릭터의 툰 스타일, 모션, 원본 데이터를 사용합니다. 자세한 내용은 [캐릭터 데이터](/ko/features/mod-manager/character-data)를 참고하세요.

1. 사이드바에서 폴더를 우클릭한 뒤 `캐릭터 지정…`을 선택합니다.
2. `게임`과 `캐릭터`를 선택하고 `저장`을 누릅니다.

지정을 해제하려면 같은 다이얼로그에서 `지우기`를 누릅니다.

## 그 밖의 모드 메뉴 항목

- `이름 변경`: 모드 폴더의 이름을 변경합니다.
- `CMD 열기`: 모드 폴더에서 명령 프롬프트를 엽니다.
- `GameBanana에서 보기`: 게임바나나에서 다운로드한 모드의 게임바나나 페이지를 엽니다.
