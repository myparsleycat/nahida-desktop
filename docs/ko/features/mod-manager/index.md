# 모드 매니저

모드 매니저는 등록된 게임별로 모드를 활성화·비활성화하고 그룹으로 정리하며, 미리보기와 프리셋을 관리합니다.

모드 매니저 페이지는 좌측 사이드바와 우측 모드 리스트로 나뉩니다. 게임 선택기와 프리셋 선택기는 사이드바 하단에 있습니다.

## 게임 추가

게임 선택기 옆의 `+` 버튼을 눌러 게임 추가 다이얼로그를 엽니다.

- **게임 이름**: 게임 선택기에 표시될 이름입니다.
- **임포터**: 게임이 모드를 불러오는 방식을 선택합니다.
  - XXMI Importer(`GIMI`, `SRMI`, `WWMI`, `ZZMI`, `HIMI`, `EFMI`): 해당 Importer의 Mods 폴더를 모드 폴더로 사용합니다. Importer 목록은 [XXMI를 연결](/ko/others/set-up-xxmi)한 뒤 표시됩니다.
  - `NTE`: 이환 설치 폴더를 선택합니다. 사용자 지정 모드 폴더를 선택할 수도 있으며, 이 경우 게임의 Mods 폴더가 해당 폴더에 연결됩니다. 나히다 데스크탑이 게임에서 모드를 불러오는 데 필요한 파일을 설치합니다.
  - `없음`: 원하는 폴더를 모드 폴더로 선택합니다. 나히다 데스크탑에서 게임을 실행할 수 없습니다.

나중에 게임 정보를 변경하려면 게임 선택기를 열고 게임 옆의 연필 버튼을 클릭합니다. `게임 설정` 다이얼로그에서는 게임의 표시 순서를 변경하거나 게임을 삭제할 수도 있습니다.

## 폴더 구조

권장하는 모드 폴더 구조는 다음과 같습니다.

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
사이드바에는 모드 폴더 바로 아래의 폴더가 표시됩니다. 모드는 모드 폴더에 직접 두지 않고 `Character`, `Enemy`, `NPC` 같은 분류 폴더 안에 두는 것을 권장합니다.

- 권장: `Mods\Character\SomeCharacterMod`
- 권장하지 않음: `Mods\SomeCharacterMod`
:::

### 서브 그룹

사이드바의 폴더는 하위 폴더를 아래에 펼쳐 표시할 수 있습니다. 사이드바에서 폴더를 우클릭한 뒤 `하위 폴더로 탐색`을 선택하면 하위 폴더가 표시되고, `하위 폴더로 지정`을 선택하면 계속 표시됩니다. 하위 폴더가 표시되거나 지정된 폴더를 클릭하면 접거나 펼치고, 그 밖의 폴더를 클릭하면 해당 폴더가 선택됩니다.

`Ctrl`을 누른 채 폴더를 클릭하면 폴더가 펼쳐지면서 선택됩니다. `Alt`를 누른 채 폴더를 클릭하면 상위 폴더를 접거나 펼칩니다.

모드 리스트의 폴더도 서브 그룹으로 취급할 수 있습니다. 해당 폴더를 우클릭한 뒤 `하위 그룹으로 지정`을 선택하고, 해제하려면 사이드바 폴더 메뉴에서 `수동 하위 그룹 지정 해제`를 선택합니다.

### 분류 기준

사이드바의 `더보기` 메뉴에 있는 `분류 기준`을 사용하면 게임의 폴더를 폴더 단위가 아니라 직접 정의한 분류별로 묶을 수 있습니다. `분류 관리…`를 선택해 분류를 만든 뒤, 사이드바에서 폴더를 우클릭하고 `분류`에서 지정합니다.

## 모드 추가

사이드바에서 폴더를 선택한 상태에서 다음 방법으로 모드를 추가합니다.

- [게임바나나](/ko/features/gamebanana)에서 모드를 다운로드합니다.
- 모드 폴더 또는 압축 파일을 모드 리스트에 드래그 앤 드롭합니다.
- 모드 리스트 상단의 `...` 버튼을 클릭한 뒤 `다운로드`를 선택하고, 다운로드할 파일 URL을 입력합니다.

## 검색

`Ctrl+F`를 눌러 현재 게임의 모드를 검색합니다. 한글 이름은 초성으로도 검색할 수 있습니다.

## 미리보기

모드 매니저는 모드 폴더 안에서 대소문자를 구분하지 않고 파일명이 `preview`인 이미지 또는 동영상 파일을 모드의 미리보기로 사용합니다. 이 파일이 없으면 폴더 안에서 처음 발견된 지원 미디어 파일을 사용합니다.

::: info
설정 → 모드의 `하위 폴더에서 미리보기 검색` 옵션이 켜져 있으면 하위 폴더까지 탐색합니다.
:::

설정 → 모드의 `미리보기가 없는 모드에 모델 미리보기 표시` 옵션이 켜져 있으면, 미리보기가 없는 모드는 그리드에 현재 토글 상태의 모델 이미지를 표시합니다.

### 미리보기 지정 및 교체

- 사이드바의 폴더에는 이미지 또는 동영상 파일을 드래그 앤 드롭합니다.
- 모드의 경우 이미지 또는 동영상 파일을 복사한 뒤, 모드를 우클릭하고 `미리보기` 아래의 `붙여넣기`를 선택합니다. 미리보기가 없는 모드는 미리보기 영역에도 `붙여넣기` 버튼이 표시됩니다.
- [모델 뷰어](/ko/features/mod-manager/model-viewer)에서 `기타` → `캡처 후 미리보기 지정`을 선택합니다.

같은 메뉴의 `미리보기 삭제`를 선택하면 현재 미리보기가 삭제됩니다.

## 프리셋

프리셋은 활성화된 모드 구성을 저장하고 복원합니다. 프리셋 선택기 옆의 `+` 버튼을 눌러 현재 상태를 저장하고, 프리셋을 선택해 적용하거나 삭제합니다.

## 토글 프리셋 {#toggle-presets}

토글 프리셋은 한 모드의 토글 값을 저장합니다. 모드를 우클릭한 뒤 `토글 프리셋`을 선택하여 현재 값을 저장하거나 저장된 프리셋을 적용합니다. 프리셋은 모드 폴더(`nhd.json`) 또는 앱 데이터베이스에 저장할 수 있습니다.

실행 중인 게임에서 값을 읽으려면 내장 런처와 myparsleycat XXMI 라이브러리가 필요합니다. 그렇지 않으면 모드의 INI 파일과 `d3dx_user.ini`에서 값을 읽습니다.

## 게임 실행

게임 선택기에서 게임을 선택하고 플레이 버튼을 클릭하면 모드가 적용된 상태로 게임이 실행됩니다. XXMI 게임은 [XXMI](/ko/others/set-up-xxmi) 페이지에서 선택한 런처를 사용합니다. 이환은 처음 실행할 때 게임의 런처 경로를 지정합니다.
