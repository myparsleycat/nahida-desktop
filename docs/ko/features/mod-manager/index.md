# 모드 매니저

모드 매니저는 등록된 게임별로 모드를 활성화·비활성화하고 폴더 단위로 정리합니다. [미리보기](/ko/features/mod-manager/previews), [프리셋](/ko/features/mod-manager/presets), [모드 도구](/ko/features/mod-manager/mod-tools), [모델 뷰어](/ko/features/mod-manager/model-viewer)도 이 화면에서 엽니다.

## 화면 구성

모드 매니저 화면은 좌측 사이드바와 우측 모드 목록으로 나뉩니다.

- **사이드바**: 모드 폴더 바로 아래의 폴더가 표시됩니다. 각 폴더에는 활성 모드 수와 전체 모드 수가 표시됩니다. 상단에는 폴더 검색창과 `더 보기` 메뉴가 있고, 하단에는 게임 선택기와 프리셋 선택기가 있습니다.
- **모드 목록**: 사이드바에서 선택한 폴더의 모드가 표시됩니다. 다운로드 중인 모드와 활성화된 모드가 먼저 표시됩니다.

사이드바와 모드 목록 사이의 경계를 드래그하여 사이드바 너비를 조절합니다. 경계에 포커스가 있을 때 `←`/`→`, `Shift+←`/`Shift+→`, `Home`/`End`로도 조절할 수 있습니다.

### 모드 목록 상단

| 항목 | 설명 |
|---|---|
| 검색창 | 선택한 폴더의 모드를 검색합니다. [검색](#search)을 참고하세요. |
| 정렬 | `이름`, `날짜`, `크기` 중 정렬 기준을 선택합니다. 옆의 `정렬 순서` 버튼으로 오름차순과 내림차순을 전환합니다. |
| `목록 보기` / `격자 보기` | 모드 목록의 표시 방식을 전환합니다. |
| `폴더 열기` | 선택한 폴더를 파일 탐색기에서 엽니다. |
| `더 보기` | `모두 활성화`, `모두 비활성화`, `모드 병합 (베타)`, `다운로드`, `도구`를 표시합니다. `모드 병합 (베타)`는 GIMI, SRMI, ZZMI, HIMI, WWMI, EFMI 게임에서만, `도구`는 Wuwa Mod Fixer 또는 ZZMI Mod Fixer를 지원하는 게임에서만 표시됩니다. |

### 목록 보기와 격자 보기

- **목록 보기**: `이름`, `크기`, `날짜` 열을 표시합니다. 열 머리글을 클릭하면 해당 기준으로 정렬하고, 다시 클릭하면 순서를 뒤집습니다.
- **격자 보기**: 모드를 카드로 표시합니다. 카드 너비와 열 개수는 [모드 설정](/ko/features/mod-manager/settings#layout)의 `모드 그리드 레이아웃`에서 지정합니다.

카드 색은 모드 상태를 나타냅니다. 초록색은 활성화, 빨간색은 비활성화, 노란색은 활성화되어 있지만 필요한 의존성이 임포터에 없는 상태입니다.

카드 머리글에는 `나히다 에이전트`, `모드 도구`, `모델 뷰어로 열기`, `삭제`, `폴더 열기` 버튼이 있습니다. 체형 변경, 터치 프로필, 액체 분사 부착점이 적용된 모드에는 해당 아이콘이 표시됩니다.

카드 오른쪽에는 모드의 INI 파일과 토글 섹션 목록이 표시됩니다. 토글 섹션의 키는 [단축키 변경](#keys)에서 설명하는 방법으로 변경합니다. `INI 파일 열기`로 INI 파일을 열고, `INI 목록 접기`로 목록을 접습니다.

## 게임 {#games}

### 게임 추가

게임 선택기 옆의 `+` 버튼(`게임 추가`)을 눌러 게임 추가 다이얼로그를 엽니다.

- **게임 이름**: 게임 선택기에 표시될 이름입니다.
- **임포터**: 게임이 모드를 불러오는 방식을 선택합니다. 기본값은 `없음`입니다.
  - `없음`: 원하는 폴더를 `모드 폴더 경로`로 선택합니다. 나히다 데스크탑에서 게임을 실행할 수 없습니다.
  - XXMI 임포터(`GIMI`, `SRMI`, `WWMI`, `ZZMI`, `HIMI`, `EFMI`): 해당 임포터의 Mods 폴더를 모드 폴더로 사용합니다. 설치되지 않은 임포터에는 `설치되지 않음`이 표시되며 선택할 수 없습니다. [XXMI를 연결](/ko/others/set-up-xxmi)하기 전에는 `임포터 설정 열기` 버튼이 표시됩니다.
  - `NTE`: `NTE 설치 폴더`를 선택합니다. 게임 이름은 `이환`으로 고정됩니다. `사용자 지정 모드 폴더`를 선택하면 게임의 Mods 폴더가 해당 폴더에 연결됩니다. 나히다 데스크탑이 게임에서 모드를 불러오는 데 필요한 파일을 설치합니다.

### 게임 설정

게임 선택기를 열고 게임 옆의 연필 버튼(`게임 설정`)을 클릭합니다. 다이얼로그에서 임포터와 모드 폴더 경로를 변경하고, `표시 순서`로 게임 선택기에서의 순서를 변경합니다. 게임 이름은 변경할 수 없습니다.

`게임 삭제`를 선택하면 게임이 목록에서 삭제됩니다. 해당 게임의 프리셋도 함께 삭제되며, 이 작업은 되돌릴 수 없습니다.

### 게임 실행

게임 선택기에서 게임을 선택하고 `게임 실행` 버튼을 클릭하면 모드가 적용된 상태로 게임이 실행됩니다.

- XXMI 게임은 [XXMI](/ko/others/set-up-xxmi) 페이지에서 선택한 런처를 사용합니다. 실행 전에 모드 적용을 방해하는 게임 설정이나 압축되지 않은 텍스처가 발견되면 확인 다이얼로그가 표시됩니다.
- 이환은 처음 실행할 때 `런처 경로 지정` 다이얼로그에서 게임의 런처 경로를 지정합니다.
- 임포터가 `없음`인 게임은 실행할 수 없습니다.

## 폴더 구조

권장하는 모드 폴더 구조는 다음과 같습니다.

```txt
Character
├─ Aino
│  ├─ AinoMod1
│  └─ AinoMod2
└─ Amber
   ├─ AmberMod1
   └─ AmberMod2
Enemy
└─ EnemyMod1
NPC
└─ Katheryne
   └─ KatheryneMod1
```

::: info
사이드바에는 모드 폴더 바로 아래의 폴더가 표시됩니다. 모드는 모드 폴더에 직접 두지 않고 `Character`, `Enemy`, `NPC` 같은 분류 폴더 안에 두는 것을 권장합니다.

- 권장: `Mods\Character\SomeCharacterMod`
- 권장하지 않음: `Mods\SomeCharacterMod`
:::

## 사이드바

### 폴더 메뉴

사이드바에서 폴더를 우클릭하면 다음 항목이 표시됩니다.

| 항목 | 설명 |
|---|---|
| `모두 활성화` / `모두 비활성화` | 폴더 안의 모든 모드를 활성화하거나 비활성화합니다. |
| `폴더 활성화` / `폴더 비활성화` | 폴더 자체를 활성화하거나 비활성화합니다. |
| `파일 탐색기에서 열기` | 폴더를 파일 탐색기에서 엽니다. |
| `새 폴더 만들기` | 폴더 안에 새 폴더를 만듭니다. |
| `삭제` | 폴더를 휴지통으로 이동합니다. |
| `하위 폴더 펼치기` / `하위 폴더 항상 펼치기` | [서브 그룹](#subgroups)을 참고하세요. |
| `캐릭터 지정…` | 폴더의 모드에 사용할 캐릭터를 지정합니다. [캐릭터 지정](/ko/features/mod-manager/mod-tools#set-character)을 참고하세요. |
| `분류` | 폴더를 분류 기준의 그룹에 지정합니다. [분류 기준](#group-by)을 참고하세요. |
| `도구` | 폴더 전체에 Wuwa Mod Fixer 또는 ZZMI Mod Fixer를 실행합니다. 지원하는 게임에서만 표시됩니다. |

### 더 보기 메뉴

사이드바 상단의 `더 보기` 메뉴에는 다음 항목이 있습니다.

- `새 폴더 만들기`: 모드 폴더 바로 아래에 새 폴더를 만듭니다.
- `폴더 정렬`: `이름`, `전체 모드 수`, `활성 모드 수` 중 정렬 기준과 `오름차순` 또는 `내림차순`을 선택합니다.
- `분류 기준`: [분류 기준](#group-by)을 참고하세요.
- `빈 폴더 숨기기`: 모드가 없는 폴더를 숨깁니다.
- `미리보기 그리드로 전환` / `행 목록으로 전환`: 사이드바를 정사각형 미리보기 그리드 또는 행 목록으로 표시합니다.

`폴더 정렬`과 `빈 폴더 숨기기`는 앱을 다시 시작하면 초기화됩니다.

### 서브 그룹 {#subgroups}

사이드바의 폴더는 하위 폴더를 아래에 펼쳐 표시할 수 있습니다. 폴더를 우클릭한 뒤 `하위 폴더 펼치기`를 선택하면 하위 폴더가 표시되고, `하위 폴더 항상 펼치기`를 선택하면 앱을 다시 시작해도 계속 표시됩니다.

하위 폴더가 펼쳐진 폴더를 클릭하면 접거나 펼치고, 그 밖의 폴더를 클릭하면 해당 폴더가 선택됩니다. `Ctrl`을 누른 채 폴더를 클릭하면 폴더가 펼쳐지면서 선택됩니다. `Alt`를 누른 채 폴더를 클릭하면 상위 폴더를 접거나 펼칩니다.

모드 목록의 폴더도 서브 그룹으로 취급할 수 있습니다. 해당 폴더를 우클릭한 뒤 `하위 그룹으로 지정`을 선택하면 상위 폴더가 접혀 있어도 사이드바에 표시됩니다. 해제하려면 사이드바 폴더 메뉴에서 `수동 하위 그룹 지정 해제`를 선택합니다.

### 분류 기준 {#group-by}

`더 보기` 메뉴의 `분류 기준`을 사용하면 사이드바의 폴더를 직접 정의한 분류별로 묶을 수 있습니다.

1. `분류 기준` → `분류 관리…`를 선택하고, `새 분류 기준`을 눌러 분류 기준과 그룹을 만듭니다.
2. 사이드바에서 폴더를 우클릭하고 `분류`에서 그룹을 지정합니다.
3. `분류 기준`에서 만든 분류 기준을 선택하면 사이드바가 그룹별로 나뉩니다. 그룹에 지정되지 않은 폴더는 `미분류`에 표시됩니다.

`분류 기준` → `폴더`를 선택하면 다시 폴더 단위로 표시됩니다.

## 모드 추가

사이드바에서 폴더를 선택한 상태에서 다음 방법으로 모드를 추가합니다.

- [게임바나나](/ko/features/gamebanana)에서 모드를 다운로드합니다. `경로 선택` 다이얼로그에서 `모드 매니저`를 선택하면 `다운로드 확인` 화면에서 파일 이름과 다운로드 위치를 지정합니다.
- 모드 폴더 또는 압축 파일(`.zip`, `.rar`, `.7z`)을 모드 목록에 드래그 앤 드롭합니다. 압축 파일은 자동으로 압축 해제됩니다.
- 모드 목록 상단의 `더 보기` 메뉴에서 `다운로드`를 선택하고, `URL로 다운로드` 다이얼로그에 파일의 직접 다운로드 URL을 입력합니다. http 및 https URL만 지원하며, 웹 페이지 URL은 사용할 수 없습니다.

압축 파일 안에 최상위 폴더가 하나만 있을 때의 처리 방식은 [모드 설정](/ko/features/mod-manager/settings)의 `압축 해제 경로 방식`에서 지정합니다. `매번 확인`을 선택하면 추가할 때마다 `압축 해제 경로 선택` 다이얼로그가 표시됩니다.

## 모드 활성화 및 비활성화

- 모드를 클릭하면 활성화하거나 비활성화합니다.
- `Ctrl`을 누른 채 모드를 클릭하거나, 모드에 포커스가 있을 때 `Ctrl+Enter`를 누르면 같은 폴더의 다른 모드를 모두 비활성화하고 해당 모드만 활성화합니다. 해당 모드가 이미 활성화되어 있으면 비활성화합니다.
- 모드 검색창에서 검색 결과가 하나뿐일 때 `Enter`를 누르면 해당 모드에 위와 같은 동작을 적용하고 검색어를 지웁니다.

필요한 의존성이 임포터에 없는 모드를 활성화하면 `필요한 의존성이 없습니다` 다이얼로그가 표시됩니다. `무시하고 켜기`를 선택하면 그대로 활성화합니다.

## 검색 {#search}

사이드바 상단에는 폴더 검색창이, 모드 목록 상단에는 모드 검색창이 있습니다. `Ctrl+F`를 누르면 폴더 검색창으로 이동하고, 폴더가 선택된 상태에서 다시 누르면 모드 검색창으로 이동합니다.

- **폴더 검색**: 폴더 이름에 검색어가 포함된 폴더를 표시합니다. 결과가 하나뿐이면 해당 폴더가 자동으로 선택됩니다.
- **모드 검색**: 선택한 폴더 안의 모드를 검색합니다. 한글 이름은 초성과 입력 중인 글자로도 검색할 수 있습니다.

## 단축키 변경 {#keys}

카드의 INI 목록에는 토글 섹션마다 다음 값으로 전환하는 키와 이전 값으로 전환하는 키가 표시됩니다. 지정되지 않은 키는 `키 추가` 또는 `이전 키 추가`로 표시됩니다.

키를 클릭하면 단축키 변경 다이얼로그가 열립니다. 설정할 단축키 조합을 누르거나 `직접 편집`에 `ctrl alt no_shift vk_up` 형식으로 입력합니다.

이환 모드는 INI 목록 대신 입력 키 목록이 표시됩니다. 보조 키 없이 키 하나만 지정할 수 있으며, 같은 모드에서 이미 사용하는 키는 지정할 수 없습니다.

## 모드 메뉴

모드를 우클릭하면 다음 항목이 표시됩니다. 일부 항목은 게임이나 모드에 따라 표시되지 않습니다.

| 구역 | 항목 |
|---|---|
| (상단) | `GameBanana에서 보기` |
| `미리보기` | `뷰어로 열기`, `붙여넣기`, `미리보기 삭제` ([미리보기](/ko/features/mod-manager/previews)) |
| `수정` | `프리셋`, `수정 도구`, Wuwa Mod Fixer, ZZMI Mod Fixer ([모드 도구](/ko/features/mod-manager/mod-tools#fix)) |
| `모드` | `CMD 열기`, `폴더 열기`, `하위 그룹으로 지정`, `이름 변경` |
| `도구` | `나히다 에이전트`, `모델 뷰어`, `토글 프리셋` 및 그 밖의 [모드 도구](/ko/features/mod-manager/mod-tools) |
| (하단) | `삭제`: 모드를 휴지통으로 이동합니다. |
