# 나히다 데스크탑에 대해

나히다 데스크탑은 XXMI Importer(GIMI, SRMI, WWMI, ZZMI, HIMI, EFMI)를 사용하는 게임과 이환을 위한 Windows용 모드 매니저입니다.

모드 관리, XXMI를 통한 게임 실행, GameBanana 모드 탐색 및 다운로드를 지원하며, 모드를 확인하고 편집하고 수정하는 도구를 포함합니다. nahida.live 계정이 있으면 나히다 드라이브와 백업도 사용할 수 있습니다.

소스 코드는 [GitHub](https://github.com/myparsleycat/nahida-desktop)에 [GNU GPLv3](https://github.com/myparsleycat/nahida-desktop/blob/main/LICENSE) 라이선스로 공개되어 있습니다.

::: info
이 문서는 작성 중이며, 일부 기능은 아직 설명되어 있지 않습니다.
:::
