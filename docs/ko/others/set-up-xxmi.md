# XXMI 연결하기

내비게이션 레일의 XXMI 페이지에서는 게임을 실행하는 방식을 선택하고 XXMI Importer를 관리합니다. 모드 매니저에 XXMI 게임을 추가하거나 XXMI가 필요한 도구를 사용하려면 먼저 이 페이지를 설정해야 합니다.

## 게임 런처 선택하기

XXMI 페이지 상단의 `게임 런처`에서 다음 중 하나를 선택합니다.

- **내장**: 나히다 데스크탑이 Importer 패키지와 XXMI 라이브러리를 직접 설치하고 업데이트하며 게임을 실행합니다.
- **XXMI 런처**: 나히다 데스크탑이 설치된 XXMI 런처를 사용합니다.

런처를 전환해도 두 방식의 설정은 각각 유지됩니다.

## 내장 런처

1. `임포터 루트 폴더`를 설정합니다. 각 Importer는 이 폴더 아래의 개별 하위 폴더에 설치됩니다.
2. 아직 구성된 Importer가 없을 때 설치된 XXMI 런처가 발견되면 해당 설정을 가져올 수 있습니다. 패키지와 XXMI 라이브러리는 새로 설치되며, `Mods`와 `d3dx_user.ini`를 XXMI 런처 폴더에 그대로 둘지 새 Importer 폴더로 옮길지 선택할 수 있습니다.
3. 사이드바에서 Importer를 선택하고 `일반` 탭에서 게임 폴더를 설정한 뒤, `패키지` 탭에서 해당 Importer의 패키지를 설치합니다.

각 Importer 페이지에는 다음 탭이 있습니다.

- **일반**: 게임 폴더, 모드 폴더, Importer 아이콘, 게임 실행 방식(직접 실행, Steam, Epic Games, 사용자 지정 명령), DLL 인젝션 옵션을 설정합니다.
- **패키지**: Importer 패키지와 XXMI 라이브러리 버전을 설정합니다. 라이브러리 제공자로 SpectrumQT 또는 myparsleycat 포크를 선택할 수 있습니다.
- **게임 설정**(GIMI, SRMI, HIMI, WWMI만 해당): FPS 제한 해제, HDR, 텍스처 품질 등 게임별 옵션을 설정합니다. 원신은 GI FPS Unlocker를 사용합니다.
- **고급**: 헌팅 모드, 안전하지 않은 모드, 로그 수준, 모드 키 바인딩, 사용자 지정 명령 등 3DMigoto 옵션을 설정합니다.
- **d3dx.ini**: `d3dx.ini` 설정을 편집합니다.
- **도구**: Quick Start 바탕 화면 바로가기를 만들고, 런타임 또는 패키지를 복구하고, 모드 INI 파일을 최적화합니다. 문제 신고에 쓸 로그와 크래시 덤프를 수집하는 로깅 모드도 여기에서 켭니다.
- **런타임**(런타임이 있는 Importer만 해당): 도구가 게임의 Mods 폴더에 설치하는 전역 모드입니다. 게임을 실행할 때 자동으로 업데이트됩니다.

`ReShade` 페이지에서는 ReShade와 공식 이펙트 패키지를 설치하고 공유 프리셋 폴더를 설정합니다.

`관리`에서는 대기 중인 업데이트, 전역 옵션, 실행 전 검사, 캐시 정리를 관리하고 내장 런처를 초기화합니다.

### DLL 인젝터

Importer 페이지 `일반` 탭의 `DLL 인젝터`는 런타임 DLL을 불러오는 방식을 정합니다.

- `기존 런처 방식`: 기본값입니다. 런타임 자체의 훅이나 로더로 불러옵니다.
- `Native`: 훅 대신 64비트 게임에 런타임과 추가 DLL을 직접 주입합니다.

`주입 방식`이 `Bypass`이면 추가 DLL만 주입합니다.

`Native`는 XXMI 로더(`3dmloader.dll`)나 Legacy 3DMigoto 로더가 필요하지 않으므로, Legacy 런타임에서도 XXMI 라이브러리 없이 추가 DLL을 주입할 수 있습니다. 64비트 게임에서만 동작하며, 게임 프로세스와 각 DLL 로드를 `게임 시작 제한 시간(초)`까지 기다립니다.

## XXMI 런처

1. `XXMI 경로`에 XXMI 런처 폴더를 입력한 뒤 `저장`을 클릭합니다. 설치 경로를 변경하지 않았다면 XXMI 런처는 일반적으로 다음 경로에 있습니다.

   ```txt
   %AppData%\XXMI Launcher
   ```

2. 설치 위치를 모르는 경우 `자동 탐색`을 클릭합니다.

::: warning
`자동 탐색`은 모든 드라이브에서 XXMI 런처를 찾습니다. XXMI 런처가 여러 개 설치되어 있으면 다른 설치 경로가 선택될 수 있으므로 탐색된 경로를 확인해야 합니다.
:::

경로를 저장하면 활성화된 Importer 목록이 표시되며, XXMI DLL과 Importer 패키지 버전을 변경할 수 있습니다.

## 실행 전 검사

두 런처 모두 게임을 시작하기 전에 문제를 검사할 수 있습니다. 검사 항목은 원신의 캐릭터 동적 해상도, NVIDIA 부드러운 모션, 3DMigoto 로깅, 압축되지 않은 텍스처입니다.
