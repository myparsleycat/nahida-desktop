# XXMI 연결하기

XXMI 런처 경로를 설정하는 방법과, 경로 설정 후 사용할 수 있는 부가 기능을 설명합니다.

## 경로 설정하기

![이미지](/others/set-up-xxmi/xxmi-page.png)

1. 좌측 사이드바에서 설정 아이콘을 클릭하여 설정 페이지로 이동합니다.
2. 설정 페이지의 섹션 사이드바에서 `XXMI`를 선택합니다.
3. `XXMI 경로 설정` 입력란에 XXMI 런처 경로를 입력한 뒤 저장 버튼을 클릭합니다.

정상적인 경로가 입력되었고 XXMI 런처에서 사용 중이던 Importer가 있는 경우, 별도의 오류 메시지 없이 활성화된 Importer 목록이 표시됩니다.

XXMI 런처는 설치 경로를 변경하지 않았다면 기본적으로 다음 경로에 설치되어 있습니다.

```txt
%AppData%\XXMI Launcher
```

기본 경로에 XXMI 런처가 없거나 설치 위치를 기억하지 못하는 경우, `자동 탐색` 기능을 사용할 수 있습니다.

::: warning
자동 탐색 기능은 활성화된 모든 드라이브를 탐색하여 XXMI 런처를 찾습니다.

XXMI 런처가 두 개 이상 존재하는 경우 의도한 경로가 선택되지 않을 수 있으므로, 자동 탐색된 XXMI 경로를 한 번 더 확인하는 것을 권장합니다.
:::

## 경로 설정 후 사용할 수 있는 기능

XXMI 경로를 설정하면 다음 기능을 사용할 수 있습니다.

- 게임 빠른 실행
- d3d11.dll 빌더
- 토글 영구 저장
- 토글 뷰어 생성기
