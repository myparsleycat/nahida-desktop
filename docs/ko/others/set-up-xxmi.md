# XXMI 연결하기

XXMI 런처 경로를 설정하는 방법과, 경로 설정 후 사용할 수 있는 부가 기능을 설명합니다.

## 경로 설정하기

![이미지](/others/set-up-xxmi/xxmi-page.png)

1. 좌측 사이드바에서 설정 아이콘을 클릭하여 설정 페이지로 이동합니다.
2. 설정 페이지의 섹션 사이드바에서 `XXMI`를 선택합니다.
3. `XXMI 경로 설정` 입력란에 XXMI 런처 경로를 입력한 뒤 저장 버튼을 클릭합니다.

정상적인 경로가 입력되었고 XXMI 런처에서 사용 중이던 Importer가 있는 경우, 별도의 오류 메시지 없이 활성화된 Importer 목록이 표시됩니다.

XXMI 런처는 설치 경로를 변경하지 않았다면 기본적으로 다음 경로에 설치되어 있습니다.

```txt
%AppData%\XXMI Launcher
```

기본 경로에 XXMI 런처가 없거나 설치 위치를 기억하지 못하는 경우, `자동 탐색` 기능을 사용할 수 있습니다.

::: warning
자동 탐색 기능은 활성화된 모든 드라이브를 탐색하여 XXMI 런처를 찾습니다.

XXMI 런처가 두 개 이상 존재하는 경우 의도한 경로가 선택되지 않을 수 있으므로, 자동 탐색된 XXMI 경로를 한 번 더 확인하는 것을 권장합니다.
:::

## 경로 설정 후 사용할 수 있는 기능

XXMI 경로를 설정하면 다음 기능을 사용할 수 있습니다.

- 게임 빠른 실행
- d3d11.dll 빌더
- Importer 패키지 버전 변경
- 토글 영구 저장

## 내장 런처의 DLL 인젝터 선택하기

내장 런처에서 Importer 설정의 `일반` 탭을 열고 `DLL 인젝터`를 선택한 뒤 저장합니다.

- `기존 런처 방식`: 기본값입니다. XXMI 런타임은 기존 훅 또는 `3dmloader.dll`의 `Inject` export를 사용하고, Legacy 런타임은 기존 로더를 사용합니다.
- `Native (Go)`: x64 게임에 `LoadLibraryW`를 호출하는 원격 스레드 방식으로 런타임 DLL과 추가 DLL을 직접 주입합니다. 기존 훅 방식 대신 직접 주입하며, 인젝션에 `3dmloader.dll`이나 Legacy 로더 실행 파일이 필요하지 않습니다. 런타임 패키지 설치는 여전히 필요합니다.

사용자 지정 실행의 `Bypass`를 선택하면 Native에서도 런타임 DLL을 자동으로 주입하지 않고, 설정한 추가 DLL만 주입합니다. Native를 선택한 Legacy 런타임에서는 추가 DLL 주입을 위해 XXMI 라이브러리를 별도로 설치할 필요가 없습니다.

Native는 x64 런처와 x64 대상 프로세스를 지원합니다. DLL 로드 대기에는 설정한 프로세스 제한 시간이 적용되며, 대기가 취소되거나 제한 시간을 초과해도 이미 시작한 원격 DLL 로드는 계속될 수 있습니다. 대상이 사용 중인 버퍼는 스레드 또는 프로세스가 종료된 뒤 정리합니다.
